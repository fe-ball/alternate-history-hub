## 1. Core doctrine — no single giant AA circle

Japan does **not** place twelve battleships, eight carriers and all escorts into one compact U.S.-style AA task force.

Reasons:
- Japanese radar / fighter direction is improved but still not U.S.-CIC quality;
- excessive concentration worsens maneuver conflict and friendly-fire / target-assignment problems;
- surface missions differ;
- relief needs a threat-side mobile layer;
- carrier flight operations need their own wind / maneuver freedom.

Selected method:
**multiple mutually supporting maneuver boxes** with common raid numbering / bearings / altitude bands / timestamped reports.

The system improves:
- warning handoff;
- CAP vectoring;
- sector assignment;
- avoidance of duplicated fire;
- damaged-ship support.

It does **not** create:
- VT;
- Bofors / Mk51 ecosystem;
- automatic radar gun-laying parity;
- seamless cross-box CIC.

## 6. CAP engagement method

Selected chain:

1. first warning narrows raid sector;
2. surface CAP moves 20–35 nmi toward the raid;
3. first merge attacks bombers / torpedo elements before escort can fully settle;
4. fighters do not pursue deep after one pass;
5. surviving CAP is re-vectored toward the actual target box;
6. local / reserve fighters may make a second merge 8–15 nmi out;
7. terminal fighters break away before entering dense friendly AA where possible.

Branch improvement:
- better target / sector numbers;
- fewer fighters lost to chasing decoys / stragglers;
- better re-vector discipline.

Still inferior to U.S. CIC:
- slower track refresh;
- less precise altitude / vector control;
- weaker recovery of a fragmented interception.

## 7. Shipboard AA formation rules

### Outer DD / cruiser ring
Practical DD stations:
**~3–6 nmi class** from principal battleships in each small box.

Tasks:
- lookout / radar warning;
- smoke only after terminal attack / damaged-ship need, not as default before AA engagement;
- heavy / medium AA where fitted;
- force torpedo aircraft to maneuver around screen;
- rescue.

### Heavy-AA sectors
Use common raid number and sector assignment:
- ships are told which raid / side they own;
- avoid every battery shifting to the first visible aircraft;
- adjacent ship heavy-AA fire can overlap only where arcs are safe.

This is a major procedural improvement over uncoordinated local firing.

### Inner 25-mm layer
Retains physical weaknesses:
- short effective range;
- vibration / sight / traverse / magazine burden;
- no Bofors-like terminal system.

Branch improvement:
- ready-ammunition discipline;
- calibration;
- local director / voice order;
- fewer dead arcs from poor stationing.

### Maneuver
Do **not** turn a whole box simultaneously unless required.

Attack-side battleship pair:
- begins combing / turn-away;
- opposite-side escort opens sea room;
- adjacent box keeps more stable AA solution if possible.

This trades:
- individual torpedo avoidance
against
- formation AA coherence.
