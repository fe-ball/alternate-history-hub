## 1. Institutional finding

By mid-1944 the Branch Japanese Army/Navy already has a real **counterlanding / relief culture**.

This is not one lesson from Guadalcanal.

The lineage is cumulative:

### Attu 1943
Selected Branch center already used:
- conditional counterlanding as a serious operational option;
- friendly-held harbor reception rather than blind opposed landing;
- ~1,700–1,900 planned first echelon;
- ~1,500–1,750 actually landed center;
- ~120–180 t high-value cargo;
- separate carrier cover;
- cruiser bombardment / diversion;
- DD / CL transport;
- explicit second-night escalation of another ~1,500–2,000 men if the first day worked.

This is already a template for:
**temporary local sea control -> fresh troop injection -> release veteran defenders for counterattack -> reassess before second night.**

### Gilberts 1943
Relief becomes tiered and conditional:
- R1 high-value cargo / specialists;
- R2 ~100–200 personnel;
- R3 several hundred + heavier counterlanding;
- loaded cargo does not compel penetration;
- SG screen / ISR freshness determine release.

This institutionalizes:
**prepare relief before the corridor exists, release only if the corridor becomes real.**

### New Caledonia / Santo lineage
Japanese amphibious planning had already learned:
- first-touch headcount is not enough;
- engineers / signals / AT / artillery / beach control must arrive in the first cycles;
- multiple landing axes / receiving lanes;
- fire-support / air / naval cover must be synchronized;
- heavy landing craft / road clocks / counterattack windows are planned before execution;
- transport and combat power are cross-loaded to avoid one-ship failure.

This institutionalizes:
**combined-arms lift as a system, not a pile of infantry on ships.**

This is the same institutional logic already seen at Attu and Gilberts, scaled to the strategic importance of Marianas.

The purpose is not:

## 9. Risk logic

“Spread risk with blood” is not modeled as sacrificing troops to save ships.

It means:
- the fleet already creates an expensive local sea-control / interdiction window;
- multiple transport groups convert that same window into more ground combat value;
- cross-loading means one transport loss does not erase the whole payoff;
- Army manpower / equipment shares the operational risk instead of making the fleet itself the only thing at stake.

This changes the bet from:
**large fleet exposure for a small cargo pulse**
to:
**large fleet exposure for a real theater-level ground reinforcement attempt.**
