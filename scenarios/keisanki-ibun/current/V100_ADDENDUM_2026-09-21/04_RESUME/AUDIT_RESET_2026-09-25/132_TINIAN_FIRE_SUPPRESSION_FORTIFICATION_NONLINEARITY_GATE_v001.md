# 4. Nonlinear mechanism

Fortification does not simply add X% more shells.

It changes the state transition:

## Historical-like
U.S. detects battery
-> destroyer/artillery counterfire
-> battery silenced
-> long/indefinite local quiet.

## Better-fortified Branch
battery fires
-> U.S. counterbattery/suppression
-> gun cell ceases
-> crew/observer survives or shifts
-> alternate position / duplicate OP / wire route remains
-> battery or another cell reappears hours/later night.

The nonlinear effect is:
> **suppression becomes a recurring service requirement rather than a one-time solution.**

That taxes:
- destroyer ammunition/time;
- Saipan artillery missions;
- observation aircraft;
- CVE sorties;
- counterbattery radar/observation;
- engineering dispersal;
- base work stoppages.

**priority changes more confidently than exact W-Day.**
