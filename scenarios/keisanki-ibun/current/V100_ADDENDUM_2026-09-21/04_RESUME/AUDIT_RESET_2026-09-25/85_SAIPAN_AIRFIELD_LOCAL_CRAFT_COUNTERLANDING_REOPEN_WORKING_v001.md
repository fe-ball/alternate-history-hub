## 3. Airfield denial / abandonment doctrine

When a Saipan strip can no longer be held:

Priority sequence:
1. fly out serviceable aircraft if route / warning allows;
2. remove specialist crews, radios, tools, engine / weapon spares;
3. move fuel / ammunition only if safe and useful;
4. crater / obstacle runway and taxi paths;
5. destroy fixed fuel / workshop items that cannot be removed;
6. preserve dispersed engineer plant if it can still serve roads / receiving / field defenses.

This matters because:
**capturing a runway surface is not the same as capturing an instantly useful air base.**

Current Aslito replay already treats physical occupation != operational security.
Future ground/air files must also price deliberate Japanese denial.

## 4. Local craft are not either “all hidden” or “all used”

The best doctrine is a **rotating reserve**.

Large craft have three simultaneous missions:

A. **RELIEF RESERVE**
- preserved for a fleet-created reinforcement / evacuation window;
- dispersed / camouflaged / maintained;
- crews rehearse but do not expose the whole wallet.

B. **LOCAL / INTER-ISLAND SERVICE**
- Saipan-Tinian personnel / spares / wounded / signals / boat repair movement;
- coastal redistribution;
- urgent ammunition / water / engineer movement where land routes are exposed.

C. **TACTICAL COASTAL MANEUVER**
- infiltration / local flank movement;
- casualty extraction;
- offensive counterlanding when a temporary sea / fire window exists.

Do not use every mission-ready boat every night.
Do not keep every boat inert if the island battle needs movement.

## 7. “True” offensive counterlanding synchronized with relief

A thick incoming reinforcement creates a second use for local boats:

**not only receive friendly troops, but move Japanese troops by sea onto an enemy flank / rear at the same time.**

This can use:
- terrain-experienced Saipan veterans extracted from Japanese-held coast;
- selected fresh incoming troops if an opposed / contested landing lane is worth the risk;
- Tinian-origin troops / specialists only if the channel is genuinely open.

### Preferred manpower logic

Attu lesson remains controlling:

- fresh arrivals primarily backfill / rebuild / create reserve;
- local veterans who know routes / U.S. patterns / terrain conduct the harder counterstroke.

Therefore the center “true counterlanding” force should be:
**mostly selected existing Saipan troops**, not the entire fresh reinforcement.

Fresh troops can:
- hold the receiving sector;
- replace exhausted line units;
- provide a second echelon;
- reinforce success after the coastal envelopment lands.

## 8. Offensive counterlanding mission types

### OCL-1 — coastal flank insertion
Move a selected veteran force from Japanese-held north/east coast to:
- a U.S. flank;
- road / artillery rear;
- division seam;
- beach-to-inland logistics corridor.

Purpose:
- force U.S. reserves / illumination / naval fire to split;
- destroy / displace support nodes;
- create temporary local encirclement risk.

### OCL-2 — contested-shore reinforcement
Land fresh / mixed troops at a sector not firmly held by Japan but not fully organized by U.S. forces.

Higher risk.
Use only if:
- naval / artillery suppression is current;
- local boats can approach;
- a land link-up is plausible within hours.

### OCL-3 — Tinian-to-Saipan strike
Use Tinian as a launch / staging node for a small offensive packet.

This is attractive only if:
- U.S. southern DD / radar coverage is displaced;
- it does not consume the same craft needed for the main reinforcement shuttle.

The thick operation should be conceived as three simultaneous sea movements:
