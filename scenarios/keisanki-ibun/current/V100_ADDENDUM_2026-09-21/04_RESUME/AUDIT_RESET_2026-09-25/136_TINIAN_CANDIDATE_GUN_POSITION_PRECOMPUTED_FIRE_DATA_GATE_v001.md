Purpose:
clarify that the Tinian "calculation advantage" is not merely better fortification or more accurate firing from occupied positions.

The specific Branch gain is:

> **candidate gun positions can be surveyed and supplied in advance with provisional firing data / position cards before a gun is physically moved into them.**

---

# 0. Core distinction

Do not read the Branch advantage as:
- every gun has magically perfect live firing data;
- every candidate position is already a complete battery;
- arithmetic replaces survey or observation.

Read it as:

1. survey likely / useful candidate positions in advance;
2. assign precise local coordinates / datum / altitude / principal azimuth;
3. precompute bearing/range/elevation families to fixed reference points and priority target boxes;
4. prepare Army/Navy common-grid conversion and position cards;
5. store / duplicate those cards with battery and sector staffs;
6. when a gun actually occupies the candidate site, only the **residual corrections** must be closed.

This reduces the time from:
> move -> survey from scratch -> orient -> calculate -> register

to:
> move -> verify datum/orientation -> apply actual gun/charge/met corrections -> fire.

---

# 1. Why Tinian benefits unusually strongly

Tinian has unusually stable geometry during the Saipan battle.

Fixed / semi-fixed reference targets include:
- Saipan Channel;
- Agingan / Nafutan-side coast;
- Aslito / Isely runway and support geometry;
- southern Saipan roads;
- known sea approach / support-ship lanes;
- Tinian own coastal sectors;
- Ushi Point / Tinian Town / Asiga reference network.

These do not move because the U.S. front moves.

Therefore a large amount of useful **geometric work can be completed before combat**.

The calculation advantage is strongest where:
- target area is geographically fixed;
- candidate gun position is already surveyed;
- only current target occupancy / met / gun state needs updating.

This is exactly Tinian's case.

---

# 2. Candidate-position packet

For a priority mobile / semi-mobile artillery position, the Branch can plausibly prepare:

- surveyed position coordinate;
- altitude;
- principal azimuth stakes / reference marks;
- route / access notes;
- concealment / revetment work order;
- range/bearing to fixed map references;
- precomputed firing data to selected target boxes;
- map-grid conversion;
- expected dead ground / masked sectors;
- no-fire / friendly-risk sectors;
- alternate OP pairing;
- communication hookup plan;
- ammunition first-load plan.

For several candidate positions around one sector, this creates a **position family**, not one battery tied to one pit.

---

# 3. Residual work still required after occupation

Precomputation does NOT eliminate:

- actual gun orientation check;
- barrel wear / muzzle-velocity correction;
- charge-lot differences;
- propellant temperature;
- current meteorology;
- current observation;
- exact target location;
- damaged / shifted datum;
- communication failure;
- crew alignment / laying errors.

Therefore first fire from a precomputed candidate position is faster and more reliable,
not magically first-round-perfect.

---

# 4. Weapon-class effect

## Mobile 75-mm / field artillery
**LARGEST combat mobility gain**

These guns can actually move among surveyed candidate sites.

Precomputed position cards can reduce useful-return time materially.

## Medium / semi-mobile artillery
**HIGH gain where towing / emplacement is physically feasible**

Movement is slower,
but moving into a pre-surveyed site avoids rebuilding the entire technical solution.

## Heavy fixed coast-defense guns
**DIFFERENT gain**

A fixed heavy gun cannot simply jump to another candidate emplacement during battle.

For these guns the computation advantage instead applies to:
- choosing / finalizing the best emplacement before invasion;
- multiple OP candidates;
- alternate observation geometry;
- precomputed target sectors;
- fire transfer between OPs;
- dummy-position / false-signature planning;
- nearby auxiliary/mobile guns tied to the same survey net.

Do not describe fixed 140/152-mm mounts as casually relocating between prepared pits.

---

# 5. Tinian-specific nonlinear result

The important object becomes:

> **a surveyed candidate-position network with latent firing data**

rather than:
> one gun = one position = one fire table.

For mobile batteries, suppression of one known site can produce:

1. cease fire;
2. displace to candidate site B;
3. verify orientation / residual corrections;
4. reconnect to alternate OP;
5. resume useful fire faster than historical improvised relocation.

Thus U.S. counterbattery faces:
- the physical gun;
- the current position;
- the survey network;
- the observation network;
- the prepared position family.

Destroying one pit is less likely to destroy the battery's **future useful-fire state**.

---

# 6. Why this may matter more on Tinian than Saipan during the Saipan battle

Saipan candidate positions progressively lose value as:
- U.S. troops occupy the ground;
- routes are cut;
- OPs are overrun;
- ammunition access collapses.

Tinian candidate positions remain in Japanese territory throughout the Saipan campaign.

Therefore:
- more of the precomputed position family remains physically usable;
- survey marks / route plans remain valid longer;
- the same technical preparation can support repeated reactivation over weeks.

This makes the calculation gain unusually persistent on Tinian.

# 8. Final close

For Tinian during the Saipan campaign:

> **computation converts surveyed empty ground into latent artillery capacity.**

That is the specific technical advantage.

It is strongest for:
- mobile / semi-mobile artillery;
- OP relocation;
- fixed geographic target boxes across Saipan Channel.

It is weaker for:
- a truly fixed heavy coast-defense mount that cannot physically relocate.

This should be carried into any later Tinian battery arc / range / suppression audit.
