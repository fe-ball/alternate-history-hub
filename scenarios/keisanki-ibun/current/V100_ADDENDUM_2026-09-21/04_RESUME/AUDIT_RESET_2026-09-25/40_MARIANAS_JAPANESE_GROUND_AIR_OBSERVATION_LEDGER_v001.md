## 1. Observation hierarchy

Japanese ground observation on Saipan is a layered system:

1. fixed / alternate ground OPs;
2. infantry/tank/patrol reports;
3. flash/sound and local visual reports;
4. water-air / short-range aerial observation;
5. fast photo / confirmation runs by D4Y when the target merits the risk;
6. higher command plot/correlation.

Aerial observation is **not** a substitute for ground OPs.

Ground OP strengths:
- persistent presence;
- direct phone/wire/radio connection;
- can observe small terrain changes continuously;
- can correct fire repeatedly if not suppressed.

Air-observation strengths:
- sees beyond local reverse slopes / ravines / urban masking;
- can update moving U.S. artillery / armor / road traffic;
- can check whether an old target box is still occupied;
- can rebuild a target picture after an OP is destroyed or displaced;
- can photograph broad changes and support later map/grid work.

Air-observation weaknesses:
- intermittent;
- vulnerable to F6F/CAP and AA;
- weather/cloud/smoke dependent;
- short station time;
- radio/report latency;
- often insufficient for continuous minute-by-minute adjustment.

## 4. What aerial observation can actually provide

### Level G1 — broad activity
Examples:
- major road traffic;
- tank concentration;
- artillery area active/inactive;
- beach unloading congestion;
- smoke / fire / construction;
- U.S. movement into/out of Aslito margins.

Useful for:
- choosing where ground OPs/patrols focus;
- deciding which old target boxes to retire;
- selecting sectors for new registration.

### Level G2 — target-box refinement
With known grid / landmark / photo mosaic:
- locate an artillery/vehicle/road activity box well enough for indirect-fire planning;
- support transfer from known registered points;
- improve the search box for ground observers.

Not necessarily precise enough for first-round effects.

### Level G3 — fire correction
Requires:
- stable visual of impacts and target;
- working radio/report path;
- weapon/battery ready to accept corrections;
- enough station time.

This is feasible for short windows, especially against:
- visible artillery positions;
- road junctions;
- armor in open/airfield terrain;
- fixed facilities.

It is not a universal continuous capability.

## 5. Integration with fire-data ledger 39

Aerial observation can update:
- TARGET REGISTRATION;
- OBSERVATION PATH;
- target freshness/confidence.

It does **not** automatically repair:
- lost BALLISTIC TABLE;
- lost SITE SURVEY;
- unknown GUN CORRECTION.

Example:
an F1M reports a U.S. 105-mm battery shifted 400 m east.
That can invalidate an old target box and create a new G2 target box.
The battery still needs its own current site survey / gun data to fire accurately.

## 7. Counter-observation interaction

U.S. fighter superiority matters.

Japanese ground-observation aviation creates a U.S. tax:
- CAP must intercept low/medium-altitude observers;
- observation aircraft may transmit before being shot down;
- F6F sorties/fuel spent on observer denial are not free.

Japanese counter-recon also matters:
- local fighters / water fighters can attempt to cut U.S. observation aircraft;
- this should be modeled separately from maritime search and fleet CAP.

But neither side has permanent uncontested observation.

## 8. Ground/air command path

Do not assume a modern real-time CAS net.

Selected Japanese path:
air observer -> formatted short report / correction -> local Navy or Army air/ground receiver -> sector plot / artillery liaison -> battery fire order.

For prearranged spotting missions:
- target number and battery are assigned before takeoff;
- corrections can be much faster.

For ad-hoc sightings:
- report must be correlated before artillery acts;
- latency is longer and friendly-fire/no-fire rules matter.

Army/Navy common grids and target numbers reduce translation friction but do not erase separate command chains.

## 9. Operational value

Japanese aviation in the Marianas has at least six distinct functions beyond fleet-decisive attack:

1. maritime search / recontact;
2. battlefield observation / artillery spotting;
3. photo reconnaissance / target-board renewal;
4. liaison / inter-island and sector communication;
5. counter-recon / observer denial;
6. runway-independent water-air continuity / SAR / local warning.

The ground-observation function was previously underrepresented.

Its main effect is not direct aircraft kill count.
It improves the **freshness and survivability of the ground fire-control system** while forcing the U.S. to spend fighter sorties suppressing observation.
