## 0. Purpose

Define what can happen after a Japanese observer sees a target.

Observation -> report -> correlation -> weapon/aircraft preparation -> launch/fire -> transit -> target update.

A target can disappear from usefulness before the attack arrives.

## 1. Target freshness classes

### FRESH-10
Useful for:
- moving landing craft;
- exposed vehicle convoy;
- small ship maneuver;
- artillery firing location.

Must act within roughly 10–20 min or reacquire.

### FRESH-30
Useful for:
- tank/artillery assembly;
- LST/LCM handling concentration;
- beach unloading cluster;
- road junction traffic.

Typically 20–45 min useful window if activity persists.

### FRESH-60
Useful for:
- transport anchorage;
- large supply dump;
- airfield repair area;
- fixed artillery park;
- bridge/road choke.

Can support a slower strike, but target activity may still change.

### FIXED
- airfield;
- pier;
- major road junction;
- known battery emplacement;
- large depot.

Location remains valid; activity state still needs current observation.

## 2. Reaction methods

### Ground artillery / mortar
If battery fire data is CURRENT and observer produces G2/G3 target:
- prearranged target: ~5–15 min to first useful fire;
- ad-hoc target within survey grid: ~10–30 min;
- if new registration is required: 20–60+ min.

This is often the fastest exploitation method for a fresh beach/road observation.

### Coastal battery against ships
Requires:
- current bearing/range/course or a usable tracked sector;
- battery ready / unsuppressed;
- observer/radio path.

Aerial spotting can improve correction but ship motion ages the solution quickly.
Do not use a 30-min-old single sighting as a precise moving-ship solution.

### Armed water-air already airborne
If carrying suitable light ordnance:
- can attack during same pass / within minutes;
- but attack compromises observation mission and exposes a scarce ISR asset;
- best against small craft, vehicles, exposed handling, not heavily defended major ships.

### Alert D4Y with bomb
Cold-start timing must include base geometry:
- Tinian / Saipan-adjacent launch: roughly **30–60 min** observation-to-target class;
- Guam launch to Saipan area: roughly **55–95 min**.

If the aircraft is prearmed/prebriefed and only awaiting a final go/no-go update, part of this preparation has already been paid.

This is a plausible response to FRESH-30/FRESH-60 ground targets, especially from Tinian-side facilities.

### B6N / torpedo attack
Cold-start torpedo timing:
- Tinian-side: roughly **50–100 min** observation-to-target class;
- Guam-side: roughly **80–140 min**.

Target must be a large/slow ship group with fresh enough position.
This is not a snap response to a fleeting artillery observation.

A preplanned alert package can react faster after the final update because arming/briefing occurred earlier.
Bomb-configured B6N can also react faster if already armed for ground/support attack.

### Preplanned dusk/night package
Best use of older target information:
- target box and route can be briefed before takeoff;
- final observer/ISR update near launch time determines whether to proceed/divert/abort.

This is the most plausible method for repeated harassment of unloading/support areas under U.S. daytime fighter superiority.

## 3. D-day high-value target examples

### LST / LCM reef transfer concentration
Freshness: FRESH-30.
Best exploitation:
- ground/coast fire if in range;
- armed recon/light bomb;
- pre-armed D4Y/B6N if ready.
Poor:
- slow torpedo package launched an hour later without recontact.

### 105-mm artillery assembly
Freshness: FRESH-30 to FRESH-60.
Best:
- Japanese artillery transfer fire;
- D4Y bomb/fast attack if CAP gap;
- night harassment if area remains active.

### Sherman assembly
Freshness: FRESH-30.
Best:
- ground artillery/mortar;
- tank ambush preparation;
- air attack only if exposed and route allows.

### Beach ammunition/fuel handling
Freshness: FRESH-60 / semi-fixed.
Best:
- indirect fire;
- dusk/night bombing;
- observed attack if smoke/fire makes the site identifiable.

### Transport anchorage
Freshness: FRESH-60 but exact ship positions move.
Best:
- preplanned night torpedo/bomb attack;
- current maritime recontact before terminal approach.

## 4. Decision rule

An observed target creates an ATTACK CANDIDATE, not an attack order.

Release only if:

expected operational delay/damage
>
aircraft + crew loss risk
+ opportunity cost of lost ISR/CAP/SAR
+ recovery/base risk.

This is especially important after 12 Jun, when surviving Japanese nonfighter aircraft become information assets as much as weapons.

## 5. Expected Branch effect

Because Branch report formatting, common grids, photo processing and calculation are better:
- observation-to-fire / observation-to-target-box latency is shorter;
- fewer coordinate translation errors;
- preplanned alert missions can be redirected more reliably.

But:
- aircraft preparation, ordnance loading, flight time, U.S. CAP and moving targets remain physical.

Therefore the major gain is **more exploitable opportunity windows**, not instant precision air strike on every sighting.
