## 2. 共通生産の保存則

発動機を単なる系列総数だけで互換扱いしない。series / variant / reduction_gear / propeller_compatibility / accepted_stateを持つ。

使用可能な未装着発動機の期末在庫 = 期首在庫 + 新造受領 + オーバーホール受領 + 移入 - 新造機装着 - 在役機交換用装着 - 試験教育への払出 - 移出 - 廃棄。

取り外した故障発動機は修理仕掛へ入り、修理受領されるまで可用在庫へ戻らない。新造機の完成と、その機に搭載された発動機を別々の戦力増加として二重計上しない。

誉の新造需要は概念上、疾風1基/機、紫電系1、銀河2、流星1、彩雲1を合計し、修理交換・試験教育・予備も同じ財布から払う。v099の月間受領帯は4月280–310、5月320–360、6月370–410基級だが、6月全量を16日へ計上せず、日割り量をそのまま前線即応へ変換もしない。

火星ではG4M/H8K/雷電/強風等との既存配分を保持し、紫雲の特殊減速系・反転プロペラを別の律速項目にする。B6Nは護主線なので、全機火星として需要を重複させない。瑞星、金星、護、液冷、小型発動機も同形式で扱う。

細部はすべて独立台帳にしない。プロペラ、無線、機銃、脚／浮舟、材料、工具等は、それが実際に律速する場合に詳細化する。ただし紫雲の反転装置・浮舟は今回の主要律速候補なので個別に扱う。

## 3. 機体から戦場まで

airframe_state: physical / serviceable / equipped / crewed / mission_ready / immediately_launchable
crew_state: pilot / observer_navigator / radio_operator / type_qualified / ship_or_base_qualified / duty_and_fatigue
support_state: engine_hours / fuel / ordnance / spares / maintainers / handling / communications
location_state: origin / ordered_destination / departure / transit / actual_arrival / acceptance / workup

機体と搭乗組は互換性を確認して組合せる。全国の可動機数と全国の搭乗組数の小さい方をそのまま局地MRにしない。

## 4. 索敵任務燃料と時間

任務燃料 = 始動・上昇 + 往航 + 捜索／触接 + 復航 + 代替回収・予備。

最高速度を巡航速度にしない。最大航続の半分を無条件に任務半径にしない。復航点の母艦移動、風、飛行高度、浮舟、兵装、レーダー、搭乗員酸素／疲労、海況と待機回収を入れる。

「偵察機数」ではなく、誰がどの時刻の位置を観測し、いつ受信され、いつ攻撃級情報になり、交代触接が何時に着くかを出す。飛行艇や大淀の計算装置は空母甲板を使わないが、燃料・乗員・母艦／基地・通信・護衛を使う。

## 5. 接続済み制度を取り落とさない

current50の空地分離・母艦間再配分・自然還流を保持する。日本航空隊を史実的な母艦完全固定へ暗黙に戻して補充上限を決めない。ただしその制度を口実に輸送・受領・艦別慣熟を省かない。

米CVEの存在数のみでCAS供給を確定しない。日本の対地・観測・対艦航空行動と、米CAP/ASW/SAR/回収処理を同じ時計に乗せる。空母以外の米艦載水偵による砲観測も別勘定。陸戦取消しは維持し、海戦監査後に再演する。
