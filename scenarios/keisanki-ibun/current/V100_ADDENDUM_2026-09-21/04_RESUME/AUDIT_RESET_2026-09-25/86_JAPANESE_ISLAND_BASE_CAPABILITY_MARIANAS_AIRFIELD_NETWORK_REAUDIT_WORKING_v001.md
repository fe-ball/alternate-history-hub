## 1. Core finding

The current Branch has generally modeled Marianas aviation as an **archipelago network**, but Saipan itself has often been narrated too much as:
**Aslito + dispersed aircraft + water-air**.

Historical Saipan was already more layered:
- Aslito operational;
- Charan Kanoa emergency strip;
- Marpi Point large field under construction / nonoperational in the historical invasion baseline;
- Flores Point / Tanapag seaplane base operational.

Tinian and Guam were also multi-field / multi-stage base systems.

Therefore the correct 1944 Branch object is not:
**one island = one airfield**.

It is:
**main field + satellite/emergency strips + graded construction sites + water-air base + dispersed maintenance / fuel / warning / boat / road system.**

## 2. Historical capability anchors

### Saipan

U.S. pre-invasion intelligence:
- Aslito Naval Air Station: ~3,600-ft field, fully operational;
- Charan Kanoa: ~3,280-ft emergency landing strip;
- Marpi Point: ~4,300-ft large field still under construction and considered nonoperational;
- Flores Point / Tanapag: major seaplane base considered fully operational.

The USMC operational history also describes Saipan and Tinian together as having multiple land fields plus Saipan's seaplane base.

Meaning:
even the historical Japanese base was not strictly single-runway.

### Tinian

Historical sources show:
- Ushi Point main field operational;
- additional smaller / secondary fields;
- another field under construction;
- U.S. post-capture development reused / expanded Japanese airfield work rather than starting from blank terrain.

Tinian therefore provides the closest Marianas example of:
**several strips at different completion levels on one relatively flat island.**

### Guam

U.S. May-1944 planning intelligence judged:
- two fields operational;
- a third under construction;
- a seaplane base in use.

Post-capture engineering sources show:
- Orote / Sumay field;
- Agana/Tiyan field close enough to completion to become a major U.S. field after development;
- a further northern strip had already been cleared / started.

Again:
**operational + near-operational + construction reserve** existed in one island system.

### Truk

Historical Truk demonstrates the upper multi-field base-network model:
- about five airfields;
- seaplane bases;
- repair / logistics / shore-support infrastructure;
- 300–400 aircraft-class could be present at some points.

Truk also demonstrates the limit:
a large base network still suffers catastrophic losses if aircraft / fuel / ships are concentrated and surprise / massed carrier attack succeeds.

### Rabaul / Bismarcks

Rabaul network practice used several separate airfields such as:
- Lakunai;
- Vunakanau;
- Rapopo;
- Tobera / nearby systems;
plus seaplane / harbor facilities.

Repeated Allied attacks forced:
- field-to-field aircraft redistribution;
- repair / dispersal;
- staged reinforcements.

This is the practical precedent for:
**runway redundancy converts one-field closure into network friction rather than instant air extinction.**

### Peleliu / later island defense

Peleliu is not copied as a June-1944 Saipan construction state.

It is a physical lesson in:
- underground headquarters / stores;
- reverse-slope positions;
- multiple entrances;
- hidden support cells surviving bombardment.

Branch Saipan already uses a less-complete earlier version of this principle.

## 3. Base-capability layers that must be tracked separately

Do not use one aggregate “airfield operational” flag.

### AIRSTRIP PHYSICAL

### FLIGHT USABILITY

### SUPPORT DEPTH
- fuel;
- ordnance;

- firefighting / recovery vehicles.

### DISPERSAL
- revetments;
- satellite parking;
- false aprons / decoys;
- tree-line / cut / covered hides;
- emergency towing routes.

### REGENERATION
- crater repair material;
- graders / rollers / trucks;
- pumps / drainage;
- matting / coral;
- repair teams;
- alternate power / communications.

### WATER-AIR
- seaplane ramp;
- anchorage;
- fuel / ordnance;
- crane / boat / tender handling;
- recovery / repair.

### GROUND / SEA INTEGRATION
- road / rail;
- boat ramps / landing craft;
- stores / caves / distributed dumps;
- observation / radar;
- signals;
- reverse evacuation.

A strip can therefore be:
physically usable but tactically low-value,
or
support-poor but extremely valuable as a diversion / emergency-recovery node.

## 9. What more airfield capacity can and cannot buy

### It CANNOT create
- extra Ki-84 airframes;
- extra Shiden-Kai airframes;
- extra elite pilots;
- extra carrier-qualified crews;
- extra engines / ordnance from nothing.

Top-end aircraft whose production / unit allocation is already closed remain capped.

### It CAN buy
1. **more dispersed parking**
   - fewer aircraft destroyed in one apron strike;

2. **more takeoff / recovery alternatives**
   - damaged returning aircraft are less likely to become write-offs;

3. **more ferry flexibility**
   - Saipan / Tinian / Guam / Rota distribution responds to warning;

4. **more repair conversion**
   - one cratered runway does not trap every repairable aircraft;

5. **more ordinary / upper-middle aircraft forward**
   - only if those aircraft already exist in a dated regional / replacement pool;

6. **higher pilot / airframe survival**
   - because serviceable aircraft can escape before closure;
   - because low-fuel / damaged aircraft have more diversion choices;

7. **more U.S. target burden**
   - carrier strikes must choose among more strips / repair nodes / dispersal areas.

This is exactly the user's distinction:
**high-end counts stay hard; base depth mainly changes distribution, readiness and attrition conversion.**

## 12. Historical / comparative lesson summary

Use the following as the capability envelope:

- **Saipan**: multi-stage land fields + seaplane base;
- **Tinian**: several strips / fields at different completion levels;
- **Guam**: multiple land fields + seaplane base;
- **Truk**: full multi-airfield network;
- **Rabaul**: distributed airfield network under sustained attack;
- **Peleliu**: deep protected support / reverse-slope survival.

The Branch does not become Truk + Peleliu at once.

But by June 1944 it reasonably combines:
- Saipan/Tinian/Guam multi-field geometry;
- better Rabaul-like dispersal / regeneration procedures;
- partial Peleliu-like protected support cells;
- stronger amphibious / boat / reception integration than historical Marianas.
