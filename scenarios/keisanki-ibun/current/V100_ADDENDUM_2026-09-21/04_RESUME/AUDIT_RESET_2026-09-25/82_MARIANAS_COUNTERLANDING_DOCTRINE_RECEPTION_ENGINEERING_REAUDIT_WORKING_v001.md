## 1. The institutional lineage is real and cumulative

### 1942 Santo — first full modern landing lesson
Branch operational practice already learned:
- transport-borne landing craft are a finite wallet, not an abstract throughput multiplier;
- first-wave headcount is deliberately reduced to land engineers / signals / mortars / first guns / ammunition;
- multiple real landing axes are preferable to one overloaded harbor entrance;
- transports remain offshore while landing craft cycle;
- beach-control / boat assignment / load tables matter to cycle time;
- heavy-support loads must arrive before the landing becomes tactically isolated.

Santo closed center:
- ~7,200 booked assault personnel;
- 18 large 14-m Daihatsu-equivalent craft / 16 serviceable;
- 14 smaller powered craft / 12 serviceable;
- first touch ~1,250–1,400 personnel + heavy support;
- main-sector cycle ~85–110 min;
- heavy-support priority:
  1. assault infantry + beach-control engineers / signals;
  2. heavy mortars + first 75-mm guns + ammunition;
  3. remaining guns + prime movers;
  4. trucks / engineer plant / bulk supply.

This is already a doctrine of **combined-arms throughput**, not infantry ferrying.

## 5. Counterlanding packet doctrine by 1944

A Marianas fast-reinforcement packet should be modular and cross-loaded.

### Personnel priority — first packet
1. receiving / beach-control / boat-control teams;
2. signals / artillery liaison / FOs;
3. engineers / pioneers / demolition / route-control;
4. coherent infantry companies / battalion nucleus;
5. mortar / MG / AT / artillery crews;
6. medical / casualty-handling;
7. repair / vehicle / radio / radar / power technicians;
8. experienced NCO / junior command replacements.

Do not maximize anonymous rifle headcount.

### Cargo priority
1. ammunition for weapons that are still physically / tactically alive;
2. mortar / artillery fuzes, propellant, ready ammunition;
3. wire / radios / batteries / power;
4. mines / demolitions / engineer tools;
5. medical;
6. prime-mover / tank / gun / generator spares;
7. selected POL;
8. first gun / AT loads and prime movers where the receiving lane supports them;
9. short-duration food/water only to the extent needed to make the packet independent.

Bulk routine stores follow only if the corridor proves repeatable.

### Outbound priority
Without extending station time materially:
- serious movable wounded;
- recovered / stranded aircrew;
- scarce radar / radio / fire-control / aviation specialists;
- high-value documents / technical material;
- exhausted cadres whose skill is more valuable outside than in the remaining fixed defense.

Counterlanding is therefore a **bidirectional personnel-management system**, not only inbound reinforcement.

## 7. Amphibious vehicles — useful, but not the main answer

Historical Japanese amphibious light tanks physically existed and were present on Saipan.

Known characteristics of the historical amphibious light tank:
- tank-only ~13 t;
- pontons ~3 t;
- water speed ~6 mph;
- crew 5;
- 37-mm gun + MG;
- thin armor.

A photographed example was knocked out by Marine artillery at Saipan.

Therefore:
**an amphibious tank is not a Japanese LVT.**
It is not a high-capacity troop / cargo shuttle.

### Useful roles
- self-propelled crossing of a shallow / reef-limited gap;
- immediate local armored firepoint after landing;
- convoy / receiving-point security;
- flank / infantry-support fire;
- reduce demand for one heavy landing-craft slot in a very specific geometry.

### Poor roles
- first-touch spearhead under intact U.S. artillery;
- frontal anti-Sherman combat;
- substitute for landing-craft mass;
- bulk personnel / ammunition transport.

### Selected Marianas doctrine
Do not put amphibious tanks in the first essential receiving packet.

First packet still prioritizes:
- engineers;
- signals;
- mortars;
- AT / field guns;
- ammunition;
- coherent infantry.

If a traceable amphibious-tank packet and a suitable lane exist:
- use a **small second / third-cycle packet** as local mobile fire support / security;
- do not pre-book an exact 4–8 vehicle count until the 1944 vehicle OOB is traced.

The NC lesson remains controlling:
**guns + engineers + road access before tanks.**

## 9. “Secret Cape” — define the maturity correctly

Do NOT model a secret deep-water port.

A large permanent pier / dredged harbor / obvious road concentration would:
- consume too much work;
- be visible to U.S. photo reconnaissance;
- become an obvious bombardment target.

The useful hidden reception model is a **low-signature prepared cove / cape complex**.

### R0 — ad hoc beach
- no survey;
- no staged teams;
- daylight-style improvisation.

### R1 — surveyed emergency landing point
- hydrographic notes;
- tide / reef window;
- known road / foot exit;
- local guide / pilot.

### R2 — prepared night reception point
- R1 plus:
- primary / alternate approach;
- preassigned boat leaders;
- temporary / shielded night marking plan;
- cached handling tools / fuel;
- receiving party;
- signal path;
- route to concealed first cache / assembly area.

### R3 — “Secret Cape” class
- multiple usable craft lanes;
- wreck bypass;
- heavy-Daihatsu / ramped-craft lane where geography permits;
- concealed local boat pool or rapid boat concentration plan;
- winches / portable derricks / tractors / matting / repair tools;
- beach-control / traffic-control detachment;
- dispersed inland caches;
- covered road / track connection;
- casualty / outbound loading point;
- alternate OP / signal path;
- rehearsed night activation / destruction plan if compromised.

This is not a port.
It is a **prepared low-signature transshipment system**.

### R4 — counterlanding reception network
Not one cove.

R4 requires:
- several R2/R3 points;
- common hydrographic / boat-control plan;
- assigned shipborne + local + shuttle craft;
- floating reserve / alternate route;
- inland assembly / sector-assignment plan;
- artillery / air / naval-support handoff;
- reverse evacuation;
- ability to absorb a battalion/brigade-scale fast reinforcement during a temporary sea-control window.
