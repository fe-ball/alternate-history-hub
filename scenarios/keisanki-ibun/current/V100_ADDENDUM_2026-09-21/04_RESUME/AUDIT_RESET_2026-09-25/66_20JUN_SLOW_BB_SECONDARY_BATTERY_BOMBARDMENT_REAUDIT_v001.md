The earlier 20-Jun Saipan bombardment working line effectively counted:

but did not materially credit the surviving old battleships' **casemate secondary batteries**.

## 2. Fuso / Yamashiro secondary battery

Historical/physical configuration carried into the Branch unless a later Branch refit explicitly removes guns:

- 14 x 15.2-cm/50 41st Year Type after 1930s modernization;
- approximately 7 guns per broadside;
- remaining mounts elevated to **+30 degrees**;
- Common Type 0 HE projectile about 45.4 kg;
- theoretical/effective weapon ROF commonly quoted around 5–6 rpm;
- maximum range at 30 degrees about **19.5 km / 10.5 nmi**.

Working bombardment ROF:
**~2.5–4 rpm per bearing gun** during a short observed shore-fire pulse.

Reason for reducing below gun-book maximum:
- casemate/manual handling;
- fire-control pauses;
- target switching;
- ship maneuver;
- blast / smoke / crew fatigue;
- no assumption that every gun fires continuously for ten minutes.

Historical sanity anchor:
Yamashiro's 15.2-cm secondary battery remained tactically usable against PT boats at Surigao.

## 5. Geometry — main-only line vs secondary-enabled line

### Outer main-battery line
Slow BB target range:
**~11–15 nmi class** depending target / course.

At this distance:
- 35.6-cm main battery works;
- 14/15.2-cm casemate secondary battery generally does not.

### Secondary-enabled close-fire line
For reliable rather than maximum-edge use:
**target range ~8.5–9.5 nmi center**.

Do not center on the absolute 10.3–10.5 nmi maximum.

Aslito / Isley target boxes are roughly ~1 nmi class inland from the west/southwest coast in the relevant geometry.

Thus ship-to-coast distance during the close pass becomes roughly:
**~7–8.5 nmi class**.

This is dangerous.

Costs:
- easier U.S. visual/radar acquisition;
- U.S. CA/DD gun and torpedo geometry improves;
- landed 105/155-mm artillery can attempt seaward fire if observation / fire control supports it;
- evasive sea room shrinks;
- a casemate broadside requires the ship to keep the target on one side for useful intervals.

Therefore the close pass is measured in **minutes**, not an hour.

## 6. Broadside use

### Shore side
Engaged-side casemate guns fire:
- registered artillery / mortar / AA boxes;
- exposed gun crews;
- ammunition-handling / prime-mover areas;
- wire / communications;
- road / vehicle queues;
- reserve / re-entry routes;
- exposed infantry / engineer concentrations.

They are **not** treated as bunker-killing substitutes for 35.6-cm HE.

### Seaward side
Opposite-side secondaries remain available for:
- U.S. DD / PT / close CL contacts;
- illumination / local surface defense where ammunition permits.

This is tactically useful because the secondary battery was originally an anti-destroyer weapon.

Do not assume simultaneous perfect centralized control of both sides.
Fire-control / observer priority still constrains output.

## 7. Observation allocation

Retained Branch fire-support rule:
**target discovery -> target fix -> observer -> ship assignment -> first salvo -> correction -> effect -> retask.**

Secondary batteries do not get extra observation channels for free.

Selected use:
- main batteries receive the highest-value fixed / semi-fixed hard targets;
- CA 20.3-cm retains fresh mobile / artillery / vehicle target work;
- secondary batteries concentrate on **larger already-registered area boxes** whose coordinates are already mature.

This keeps the extra shell volume from becoming a generic accuracy multiplier.

## 9. Selected bombardment sequence

Exact minute is WORKING, but use this structure.

### Phase A — outer heavy opening
~18:20–18:40 class

- Ise / Hyuga + healthy Fuso-class;

~18:40–18:55 class

- Ise / Hyuga close to ~8.5–9.5 nmi target range;
- engaged-side 14-cm batteries fire registered Aslito west/north area boxes;
- main 35.6-cm fire continues on harder targets;
- healthy Fuso-class initially remains slightly farther out as AP / surface-ready heavy reserve.

### Phase C — healthy Fuso-class close pulse / rotation
~18:50–19:08 class

- one Ise-class begins opening / changing role;
- healthy Fuso-class closes enough to use 15.2-cm engaged-side battery;
- second Ise-class can remain in main-fire / surface-ready transition.

This is a rotation, not three ships sitting abeam at the same range.

### Phase D — damaged Fuso-class late join
~19:00–19:20 class sensitivity

- damaged ship reaches outer main-battery firing geometry;
- 35.6-cm limited fire possible;
- no centered secondary-battery close pass;
- if Lee / U.S. cruiser pressure rises, it remains rear / AP-ready instead.

### Phase E — break off shore-fire posture
~19:15–19:30+ class

- slow line opens distance;
- secondary fire ceases first;
- main fire tapers to short final missions;
- ships restore surface-war formation / AP-first readiness.

This preserves the previously identified Japanese ground-system regeneration window after heavy naval fire ends.

## 12. Expected effect category

Do not immediately add the full secondary-shell count linearly to physical destruction.

Primary incremental effects should be:
- more exposed crew casualties;
- more wire / phone / local FDC interruption;
- more ready-ammunition / prime-mover disruption;
- more soft-vehicle damage;
- stronger road / re-entry suppression;
- longer local time before U.S. artillery crews can restore normal firing rhythm.

Smaller incremental effects:
- hard bunker destruction;
- Sherman kills;
- deeply revetted gun destruction.

Therefore the first expected revision is to:
**temporary / system-level interruption**
rather than the physical heavy-gun kill count.

Exact U.S. casualty / gun / vehicle delta remains the next ground-effect adjudication.
