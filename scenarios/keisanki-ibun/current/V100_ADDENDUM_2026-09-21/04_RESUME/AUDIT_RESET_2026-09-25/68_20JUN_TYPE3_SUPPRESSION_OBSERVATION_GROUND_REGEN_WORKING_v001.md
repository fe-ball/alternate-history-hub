## 3. Type 3 Common shell — current doctrine

Type 3 is not restored as a primary heavy-AA solution.

Retain file-60 interpretation:
- anti-aircraft origin;
- Branch fuze/setter/QC improvements reduce bad-lot / bad-setting tails;
- no invented chemistry or fragment-pattern redesign;
- use as specialized incendiary-fragmentation / area-barrier ammunition.

For ground fire:
- Type 0 HE remains primary for gun pits, revetments, structures and hard/semi-hard points;
- Type 3 is used against exposed or re-exposing systems:
  - artillery crews;
  - sights / directors / observers;
  - ready ammunition;
  - prime movers;
  - trucks;
  - radio / wire repair teams;
  - reserve / re-entry routes;
  - road junctions;
  - open vehicle and personnel concentrations.

The intended effect is not simply casualty production.
The major operational value is:
**force cover -> stop handling / observation / movement -> delay re-entry -> make repair/reconstitution visible and costly.**

Do not treat a Type 3 burst as equivalent to a conventional HE direct hit on a dug-in gun.

## 7. Suppression / silence model

Do not convert Type 3 to a fixed kill multiplier.

Use three layers.

### A. Immediate forced-cover effect
Against an exposed artillery / vehicle / communications box:
- crews stop servicing / observing / moving;
- ready ammunition handling pauses;
- repair / wire parties take cover;
- exposed vehicles disperse or halt.

Typical useful duration after a short burst:
**minutes**, not an automatic permanent mission kill.

### B. Mixed HE + Type 3 mission interruption
Type 0 HE attacks the physical firing position / road / vehicle / command point.
Type 3 attacks the exposed human and servicing system around it.

For an already engaged U.S. battery box, the combination can turn:
- physically intact gun
into
- temporarily non-operational gun.

Selected center after the expanded bombardment:
- U.S. 105/155-mm physical destruction / long mission-kill: **~6–10 guns class**;
- additional short/medium non-operational guns from crew / sight / FDC / wire / ammunition / prime-mover disruption: **~12–20 guns class**.

These are concentrated-sector effects and are not the whole island artillery inventory.

### C. Recovery denial
The Type-3 role becomes strongest after the initial heavy HE pulse.

When U.S. batteries / vehicles / repair parties emerge to:
- reconnect wire;
- tow guns;
- move ammunition;
- restore observation;
- re-enter firing pits;
they become valid targets for:
- 20.3-cm Type 3 / HE;
- 35.6-cm Type 3;
- 14-cm Type 3;
- Japanese island artillery / mortars using already registered boxes.

This is how Type 3 helps convert a short physical bombardment into a longer **functional silence**.

## 9. Japanese ground-system regeneration begins during the bombardment

Do not wait until the last naval shell.

Use file-39 clocks:
- pre-surveyed alternate mortar/light cell: ~10–30 min;
- field/medium battery: ~20–60 min;
- heavier battery: ~30–90 min;
- new high-value target box with an observation path: ~10–30 min for mortar/field, ~20–60+ min for medium/heavy.

Selected 20-Jun behavior:

### ~18:15–18:35
While heavy naval fire begins:
- Japanese signal / artillery teams reconnect alternate wire/radio;
- observers update which U.S. artillery / vehicle boxes have stopped, moved or exposed themselves;
- ammunition is moved into ready positions;
- surviving batteries do not all reveal themselves at once.

### ~18:35–19:05
As U.S. counterbattery / observer / support density falls in the hardest-hit boxes:
- selected Japanese mortar / field-artillery cells resume fire;
- already registered Aslito west/north / road / 105-mm assembly boxes are preferred;
- some priority batteries can complete **one additional corrected fire mission** before displacement compared with a no-bombardment case.

### ~19:00–20:15
This is the main Japanese regeneration / exploitation window:
- U.S. repair / re-entry activity itself becomes targetable;
- Japanese firing windows become less constrained by immediate U.S. counterbattery response;
- local tank / AT cells can reoccupy prepared lanes;
- engineers/signals can restore selected OP / communication paths;
- no island-wide counterattack is authorized.

The 45–90 min window is therefore not only “time to recover.”
It is:
**time in which Japanese recovery and renewed fire act on the U.S. recovery process.**
