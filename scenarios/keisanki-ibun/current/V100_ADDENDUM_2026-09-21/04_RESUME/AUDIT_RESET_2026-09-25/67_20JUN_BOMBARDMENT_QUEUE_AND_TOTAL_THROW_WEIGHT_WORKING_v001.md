## 1. Core correction

The bombardment should not be modeled as every available ship firing simultaneously until a density cap arbitrarily reduces total rounds.

The actual limiter is a combination of:
- usable sea room / turn geometry;
- current observer / target channels;
- splash identification;
- ship-to-ship fire deconfliction;
- surface-war readiness;
- ammunition state;
- time before U.S. surface re-interdiction.

Selected solution:
**queue the heavy-fire positions in time.**

This preserves a practical instantaneous density while allowing more total shells over a longer continuous bombardment interval.

---

## 2. Three different kinds of density

### A. Precision / observed heavy-fire density
Most constrained.

High-value hard targets can support only a limited number of simultaneous:
- observer;
- ship;
- correction;
- BDA
chains.

Do not have four battleships and several CAs independently spot the same target at once.

### B. Registered-box area-fire density
Less constrained.

Once a target box is already surveyed / registered:
- 14/15.2-cm secondary batteries;
- selected 20.3-cm missions;
- Type 3 / HE area missions
can fire by preassigned time / sector without requiring one unique observer correction for every salvo.

### C. Sea-room density
A separate limit.

Only a few capital ships can occupy the best close-fire arc without:
- masking each other;
- worsening torpedo geometry;
- reducing maneuver room;
- confusing the surface-defense formation.

This naturally creates a ship queue.

## 4. Why queueing raises total without raising instantaneous density too far

Old density treatment reduced the Ise/Hyuga main-battery total because additional Yamato/Nagato/CA fire was added into the same notional bombardment interval.

Queueing changes that.

The heavy elite pairs fire **short pulses**.
The slow line occupies the close-fire lane sequentially.
CA fire uses separate target boxes / intervals.
Secondary batteries mostly engage pre-registered area boxes.

Therefore:
- the instantaneous number of observed heavy salvos remains bounded;
- total bombardment duration remains roughly 60–80 min class;
- total projectile count can rise.

No generic accuracy gain is awarded from the higher total.

## 8. Instantaneous density — center interpretation

The ~1,300 total is spread over roughly **60–80 min** and multiple target boxes.

Do not model 1,300 / 70 as a uniform 18–19 rounds/min hitting one square.

A practical center pattern:
- long intervals with CA + one slow-BB pair;
- short elite-heavy pulses;
- 10–20 min class secondary-battery bursts;
- pauses for correction / maneuver / target handoff.

Peak local shell arrival in one area box can be high for a few minutes.
Sustained island-wide peak density is not.

This is exactly why queueing is preferable to either:
- an artificial global density cap;
- or simultaneous maximum-rate fire from every ship.

## 9. Observation-channel rule

Retained doctrine:
**target discovery -> identification/fix -> observer -> ship assignment -> first salvo -> correction -> effect -> retask.**

Queueing allows one observer / target chain to be handed from:
Ise pair -> Fuso-class -> CA
without all three competing for simultaneous correction.

Secondary batteries receive:
- pre-registered area boxes;
- time-on-target / sector windows;
- only occasional correction where observation permits.

This converts additional barrels into suppression / system interruption rather than a false precision-kill multiplier.

## 10. Consequence for the night transition

The queue also avoids a hard choice between:
- “Ise/Hyuga bombard”
and
- “Ise/Hyuga return to surface defense.”

The transition is continuous:

1. Ise/Hyuga make the first close pass;
2. healthy Fuso-class inherits the shore-fire lane;
3. Ise/Hyuga reform seaward;
4. damaged Fuso-class contributes only outer main fire;
5. CA continues observed support;
6. slow line collectively restores AP / surface posture by the end of the window.

Therefore the bombardment can remain active **after the Ise pair has begun turning back to sea**.

This is a material reason the total slow-line projectile count can rise despite the same observation / sea-room limits.
