# 紫雲：採用構成・開発経路の選定 v002

Date: 2026-09-25
Status: SELECTED DEVELOPMENT RECONSTRUCTION / WORKING ENGINEERING INPUTS / NO CAMPAIGN PROMOTION
Authority anchor unchanged: Branch B v100 / 1944-06-16T14:15

ユーザーの「多角的に検討し、ここで一つに決める」依頼に対する今回の技術裁定。これは史実の未知の試験成績を発見した文書ではない。採用構成・開発経路を一本に選定するが、性能推定を実測値にせず、6月の現地保有・出撃・戦果を自動付与しない。v001で並列に残した構成候補は、本書の選定へ集約する。戦役正本、取消済み陸戦、廃止資料規則は変更しない。

## 1. 採用する一つの構成

紫雲の開発を継続し、母艦・専用支援拠点で運用する高速・長距離偵察機として限定系列採用する。

| 項目 | 選定 |
|---|---|
| 推進 | 成熟火星二〇型系列を基礎とする特殊反転駆動仕様。離昇1,800～1,850馬力級の設計基準。二重反転2翅＋2翅を維持 |
| 主浮舟 | 通常は装着したまま、射出／離水→偵察→着水→再使用を成立させる |
| 補助浮舟 | 気嚢の膨張・収縮に浮力成立を依存させる原方式は廃止。剛性・定容積の密閉区画型を外部半引込に再設計 |
| 引込の範囲 | 薄翼内部への完全収納を要求しない。翼下に浅い整流外形が残ることを許容し、支持部と取付角による抗力を減らす |
| 緊急投棄 | 主浮舟投棄を独立した搭乗組救済用の緊急機能として維持。通常性能の成立条件にせず、実機安全試験の経路を設ける |
| 乗員 | 操縦員＋航法・観測・無線を担う後席員の2名。三座化しない |
| 防護・装備 | 防火・燃料遮断・局部防護・救命・酸素・無線／航法／写真を優先。後方13mm級単装を標準計画に含め、銃架・弾薬込み重量を払う |
| 追加しない任務 | 前方20mm、急降下爆撃用構造・ブレーキ、通常爆装、常時CAP、機上計算機・捜索電探は付けない |
| 専門任務 | 高速確認、再捜索、交代触接、距離のある索敵線の補完。無制限に敵戦闘機を振り切る機体ではない |

「紫雲・1943年後期標準」は説明用管理名であり、史実制式符号の新設ではない。

## 2. 史実根拠と新しい選択の境界

住友精密工業社史年表は紫雲と強風の反転プロペラを同じ製作項目に載せる。共同する供給者・試験知見の存在は支持するが、両機の減速機完成や互換性を証明しない。[H1]

1940年NACA-SR-157は反転プロペラの効率利益が試験条件により0～6%、翼を置くとその利益がおよそ半分になると報告し、反トルク除去・大出力吸収・低V/nDの利益も挙げる。これは紫雲の実測値ではなく、反転を巨大な速度倍率にしない外部校正である。これらNACA資料がBranch当事者へ自動的に渡ったとはしない。[H2]

NACA-TN-680は補助浮舟の形状・取付角・段差と抗力の関係を扱う。PBYでは1930年代から剛性浮舟を翼端へ引き込む機構が実用化されている。ただし高翼大艇の装置を低翼・折畳翼の紫雲へ移植したことにはしない。今回の半引込は新設計であり、翼桁、格納折畳み、容量、重量、荷重経路の検証を必要とする。[H3][H4]

USNTMJ A-11の大淀航空施設・専用水偵表を参照した。ただし火星14の表、浮舟投棄時の速度記述、後年に流通する量産数値を混ぜて通常性能を作らない。第12偵察隊等のJACAR原画像は今回も取得できず、故障・損失に関する通説を採用理由の確定入力にしない。[H5]

## 3. なぜ反転を残し、気嚢を捨てるか

反転は、最高速の数%だけなら重整備費に見合うとは限らない。保持理由は、単主浮舟の機体で大出力を扱う際の反トルク、水上加速、プロペラ径制約、巡航効率、専門拠点に予備駆動部を集中できる運用を合わせたもの。火星本体の成熟、川西の水上機経験、住友の調速・振動試験を接続する。実測のない故障率を置いて「解決済み」とはしない。

気嚢式は、収納のために浮力を作る構造自体を変形させ、膨張・密閉・収縮・着水荷重を連鎖させる。Branchの試験分離は個別の漏れ・公差・作動不良を改善できても、この依存関係を無料では消さない。よって浮力容積は常に保持し、飛行時の外形位置だけを変える剛性半引込へ選択する。

剛性半引込も故障し得る。展開固定、左右状態確認、非常展開、作動系と着水荷重経路の分離を要求する。故障時に両側を安全な展開固定へ移せる場合は速度・燃料制約付き帰還とし、非対称・固定不成立は通常着水可としない。

完全固定の洗練案は比較基準として有用だが主線には選ばない。小さな最高速差だけでなく長い巡航中の燃料消費と交代触接余裕を得るため、半引込の工数を払う。翼下面から出っ張りを消すために構造・密閉を再び過剰複雑化する設計へ戻さない。

## 4. 主浮舟投棄の選定

通常偵察は浮舟付きで審査する。投棄は遭遇回避・離脱が失敗した場合の最終手段で、航空機一機を恒常的に使い捨てる作戦方式にしない。

選定開発経路には、模型・地上荷重試験に続き、保護海面・救助体制下の実機分離／胴体着水試験を含める。試験用機体の損耗を開発費に含める。成功を史実記録として創作せず、今回のBranch経路として1943年中の限定条件適合を採る。

全速度・姿勢での使用保証や、投棄後に自動的に600km/h超になる性能は付与しない。投棄後の機体は海上回収・損傷判定を経るため、次の通常任務即応から外す。搭乗員2名の回収も別事象。主浮舟に長距離任務の必須燃料を依存させない構成とする。

## 5. 強風・瑞雲ほかとの接続

強風から継承するのは水上荷重、反トルク対策、プロペラ・振動・冷却・腐食・整備の知見であって、一式の互換部品ではない。反転が紫雲で採用されても、強風の量産標準を自動的に反転へ変更しない。頻繁な警戒発進・損傷復帰を行う分散戦闘機と、長時間任務を専門整備で回す偵察機では機構の費用対効果が違う。自動空戦フラップも紫雲へ戦闘機能力として追加しない。

瑞雲の1943年秋実戦化・偵察観測主線は保持。瑞雲の実戦性能が上がれば紫雲との任務重複・調達規模を再評価できるが、紫雲を強く見せるため瑞雲を史実数値へ戻さない。紫雲には瑞雲の急降下攻撃・前方火力を追加しない。

E13A/F1M等には通常索敵・観測、D4Y偵察／彩雲／百式司偵にはそれぞれの基地・資格・長距離ISRを残す。紫雲は万能代替ではなく、母艦から起点を動かせる高速・持続偵察という費用の高い部分を担当する。

二座後席の航法・観測・無線・後方警戒は同時に無制限処理できない。短文第一報、定型の時刻・座標・艦種確度、後続詳細という報告を採る。写真現像を待たずに第一報を送るが、写真で確認した艦名を無線第一報へ先取りしない。

## 6. 選定開発史（新しいBranch裁定）

| 時期 | 一本化した経路 |
|---|---|
| 1939～40 | 高速・長距離要求を受け、川西・三菱・住友の機体／推進／浮舟を並行試験。通常偵察と投棄脱出を別審査 |
| 1941年級 | 原構成の実機試験。初飛行を大幅前倒しせず、飛行安定・フラップ・推進・浮舟不具合を分離 |
| 1942年前半 | 気嚢依存を止め、剛性半引込へ設計変更。単回転／固定浮舟比較は行うが主線は反転＋半引込 |
| 1942年後半～43年前半 | 成熟火星系列と駆動部を統合。構造・作動・塩害・耐久・飛行／水上試験を繰り返す |
| 1943年前半～夏 | 大淀・専用陸上拠点との取扱／報告／回収の実用審査。大淀竣工直後の6機即応は付与しない |
| 1943年秋 | 再使用偵察の制式標準を成立させ、限定系列採用 |
| 1943年末～44年春 | 完全搭乗組・専門整備・予備駆動部を伴う部隊運用を成熟。全国／局地の実数は共通生産・配置表で計上 |

この表は今回選んだ反実仮想の実行経路であり、史実試験成績の報告ではない。F6Fの将来性能を1939年要求へ持ち込まない。戦況と実接触で任務を更新する。

## 7. 性能の共通入力帯

以下は今回の構成に対するWORKINGモデル入力。設計の選択と、未実測の数値の確度を混同しない。

通常状態は主浮舟付き、補助浮舟格納、乗員・防護・無線・救命装備あり、爆装なし。

| 項目 | 作業帯 |
|---|---|
| 通常長距離任務重量 | 4.3～4.6t級 |
| 離昇出力 | 1,800～1,850馬力級 |
| 試作良好最高速度 | 530～545km/h級、5～6km高度 |
| 受領標準最高速度 | 510～530km/h級、同高度 |
| 部隊中央値最高速度 | 500～520km/h級、同高度 |
| 通常の航路巡航 | 真対気速度320～350km/h級、任務燃料依存 |
| 滞空・低消費巡航 | 260～290km/h級を計画比較に使用 |
| 初期の標準任務半径 | 400海里級。現地時間・高速区間・予備燃料を明示 |
| 延伸 | 450海里級は高速区間または現地時間の削減等が必要。500海里を無条件の標準半径にしない |
| 投棄状態 | 通常速度表と分離。固定した脱出速度／生還率を付与しない |

出力・速度は海面から全高度へ一定に適用しない。水面離着水・射出・荒天回収はこの速度表から認証しない。

簡易整合モデルはS=30m²、b=14m、e=0.80、CD0=0.0265、乾燥任務重量3430kg、使用可能燃料980kgを仮定。5.7kmで軸出力1500馬力・推進効率0.79なら最大速度は約515km/h。CD0=0.025～0.028、同高度軸出力1400～1600馬力を振ると約492～538km/h。これは実測でなく、抗力と装着出力が変わると速度帯がどれだけ動くかを示すもの。仮定を選んだ計算を、当該機構の実験的優位の証明に使わない。

燃料例（同モデル・無風・固定回収点）: 始動／上昇65kg、往路340km/h、現地280km/hで60分、高速500km/hで15分、復路320km/h、進入等15kg。400海里では約6時間10分・帰還残約134kg。予備100kgを要求すると成立。450海里では残約63kgで不成立。450海里でも高速15分を省けば残約135kg。風、迂回、動く母艦、着水待ちが加わればさらに狭まる。

従って「最高速530」「最大航続長い」「1時間触接」「遠い母艦へ戻れる」を同時に無料付与しない。

## 8. 量産・整備の裁定

紫雲は一試作イベントで終わらせず、専門支援つきの限定量産系列とする。初期調達設計は量産24機を一単位とし、別に試作・改修・試験用6機級の開発枠を共通生産計画へ要求する。量産24機の使い道は母艦分遣、陸上交代、教育受領、整備交換を含み、全機を前線即応としない。

これは調達・設備需要の選定で、1944年6月までに30機完成したという実績ではない。火星本体、特殊減速部、前後プロペラ、浮舟、予備・修理、教官と燃料を共通勘定で照合して実際の完成・受領・配分を決める。共通供給に収まらなければ引渡し時期・数量を調整し、他機種の既計上資源を黙って流用しない。

整備は発動機・駆動部の交換診断を専門拠点へ集中。船上で毎回精密減速部を開放修理する前提にしない。強風・瑞雲・H8Kの試験設備・専門人員を無料で二重使用しない。量産品質や塩害が悪化した場合には可動率が下がるが、現在その劣化事象を創作して史実失敗へ戻さない。

## 9. 大淀と戦役への接続

大淀は前の選定通り、艦載補助計算装置を伴う航空・無線・作図ノードとして扱う。大和型の弾道補正器をそのまま万能CICにせず、座標換算・時刻差補正・報告照合・交代触接の手順を開発する。

紫雲の半径・速さは探知後の再接触や交代を助ける。大淀の処理は情報遅延・重複・座標の取り違えを減らす。別区間の効果であり、両方を探知確率倍率として二重加算しない。大淀を経由しない第一報・代替経路を残す。

6月の大淀所在、実搭載数、反転系予備品、完全搭乗組、海況、射出／揚収処理は次の配置勘定で埋める。今回の採用決定だけで18日に6機を追加しない。

18日午後の先行発見・攻撃見送りを維持することを設計目的にしない。同じ前提へ依存する16～17日の索敵・艦攻拘束・再生も再監査可。承認済み正本に影響する場合は範囲を明示し、無言の上書きをしない。
