# 1. Institutional premise now controlling the air calculation

By early 1944, Branch IJN carrier aviation is **not** modeled as:

> one carrier hull = one indivisible air group = one indivisible support organization.

The operating system is partially separated into:

1. **Hull-organic layer**
   - flight-deck handling;
   - elevators / hangar cycle;
   - fueling / arming routes;
   - landing signals;
   - ship-air communications;
   - aviation-space damage control.

2. **Mobile flying / direct-maintenance cells**
   - pilots / observers / radio-gunners;
   - flight / strike leaders;
   - type-specific direct maintainers;
   - radio / ordnance / instrument specialists;
   - minimum portable tools / spares.

3. **Carrier-fleet qualification / replacement pool**
   - replacement crews;
   - recovered / convalescent personnel;
   - cross-deck-qualified personnel;
   - search / navigation specialists;
   - secondary-deck / temporary shore personnel;
   - requalification cells.

4. **Training / regeneration layer**
   - conversion / acceptance / ferry organizations;
   - instructors / cadre;
   - new-carrier work-up personnel.

Existing canon/retained institutional line:
- 1942 H2: major-base transfer of flying unit + direct-maintenance detachment begins.
- 1943 H1: mature bases retain more common base-side support.
- 1943 H2: practical air-ground separation becomes standard for major operational units.
- 1944 early: personnel / supply / command-rights are institutionally organized around this portability.

**Guard:** portability is not instantaneous interchangeability.
- Aircraft + carrier-qualified crews != a combat-ready carrier.
- Hull-specific deck teams remain a hard brake.
- Type qualification / navigation / strike leadership / direct-maintenance specialization remain hard brakes.
- B7A and Homare-heavy cells are less portable than mature Zero / D4Y / B6N cells.
