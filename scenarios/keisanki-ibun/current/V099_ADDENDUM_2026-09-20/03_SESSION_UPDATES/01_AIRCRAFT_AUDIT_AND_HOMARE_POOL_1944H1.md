## Anti-rollback rule
Historical values are not default restoration values.

If a Branch design/test/production/maintenance/institutional capability has already matured, it persists until:
- factory damage;
- material/fuel quality decline;
- trained-maintainer loss;
- depot/tool/spares loss;
- training-time collapse;
- long-range deployment burden;
- combat loss of specialist cadres;
or another dated causal mechanism degrades it.

When an exact number is uncertain, widen the band.
