この世界線では未来知識を認めるが、万能知識にはしない。

主人公が無料に近く得られるのは主として、

- 正しい方式選択
- 失敗枝の回避
- 何を測るべきか
- 実験計画
- 量産工程・品質管理の考え方
- 後世に有効と分かっている技術を、現地で成立する形へ早期提案する能力

である。

主人公は、

- 存在しない材料
- 当時加工不能な形状
- まだ存在しない工作機械
- 未測定係数
- 長時間耐久試験

- 軍の予算
- 機体工場
- 搭乗員
- 燃料供給網

を無料で生成しない。

また、史実の発明年・制式年を能力上限として使わない。
その技術を早期に成立させられないと判断する場合は、材料、加工、計測、試験、寿命、供給、重量、容積、搭載等の未払いの物理・産業ゲートを具体的に示すこと。

技術可能性、単体試験成立、発動機完成、量産成立、機体搭載、serviceability、部隊配備、戦術効果、作戦効果、戦略効果を分離する。
試作最良値、公称定格、量産中央値、部隊で実際に使える出力も混同しない。

機体・発動機の選択肢は「未来知識で思いつけるから最初から全部存在する」としない。
要求 → 試作 → 実測 → 新しい要求、という開発史を維持し、実測結果が次の枝を発生させること。
海軍と陸軍が同じ技術へ独立収斂する場合もあれば、実機・図面・試験結果・技術者を通じて相互に学ぶ場合もあるので、伝播経路を明示する。
