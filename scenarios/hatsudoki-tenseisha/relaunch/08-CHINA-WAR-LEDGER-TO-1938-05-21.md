# 支那事変・戦力在庫・兵站台帳 — 1937-07-07 から 1938-05-21

> **Authority:** Relaunch R2
> **Canonical historical clock:** **1938-05-21**
> **Status:** 戦役の主要因果・方向 = CLOSED。数値帯の多くは PROVISIONAL audit range。
> この文書の目的は「会戦ごとに人員・装備が新品へリセットされる」ことを禁止し、損耗・補充・輸入・再編・輸送能力を次戦役へ繰り越すことにある。

## 1. 状態量の原則

以後の会戦は必ず、

前回残高
+ 補充 / 新造 / 輸入
- 戦闘損失
- 非戦闘損耗
- 捕獲 / 遺棄
± 部隊転出入
= 次回残高

で閉じる。

必須分離:
- 在隊人員
- 組織された戦闘人員
- 古参幹部 / 熟練下士官
- 小銃
- 軽/重機関銃
- 迫撃砲 / 歩兵砲
- 野山砲
- 対戦車砲
- 車両 / 牽引車
- 馬匹 / 荷車
- 通信
- 即応弾薬
- 部隊凝集
- 鉄道 / 河川 / 自動車 / 畜力の輸送容量
- 航空: 配備機 / 可動機 / 即時可動 / 予備 / 修理中 / 搭乗員 / 整備 / spare engine / sortie generation

人員補充は熟練度・火砲・車両・通信・凝集を自動回復しない。

## 2. 1937年航空戦の質的切替

史実でも8月後半には日本側航空優勢が成立するが、本世界線では爆撃機・搭乗員損耗が少なく、九六二号/三号とKi-15暁の量が多い。

質的切替:
- **8月:** 日本航空隊が史実より多く生き残る
- **9月:** 中国軍は昼間の空を自由に使いにくくなる
- **10月:** 大規模な昼間後方交通へ継続的な航空課税
- **11月:** 上海撤退で目標が塹壕から道路・鉄道・橋・車列・砲兵・荷駄へ変わり、航空効果が非線形に増す
- **12月:** 航空優勢が地上追撃テンポへ換金される

中国側戦闘機の減少→日本爆撃/偵察自由度増→飛行場/交通攻撃→さらに中国側可動率低下、というfeedbackが発生する。ただしソ連援助で1937末～38前半に航空戦力は再建される。

## 3. 上海撤退から南京

上海撤退の原因自体は杭州湾上陸と地上側面進撃。航空単独で撤退を作ったことにはしない。

航空強化が追加で行うこと:
- retreat routes / bridge / station / canal trafficの反復監視
- road/rail bottleneckへの攻撃
- heavy equipment / ammunition / trucks / horse transportを人員以上に失わせる
- organized withdrawalを分散撤退へ崩す

中央差:
- 中国側追加死傷・行方不明等: **+2.5～4万人級**
- 追加の一時離散・脱走・戦列離脱: **+3～5万人級**
- 日本側人的損耗回避: 上海戦全体で**約6,000～9,000人級**
これらは一点史実値ではなくscenario audit range。

中国側は人間が逃げても火砲・車両・通信を同じ割合では救えず、師団が軽歩兵化する。

## 4. 南京・疎開

国家・軍需の疎開と守備軍の撤退を分ける。

重要工作機械・治工具は史実同様、相当割合を先に西遷できる。世界線では敗北圧力が強いため最優先設備の疎開判断はむしろ早まる余地がある。

central audit:
- 最重要工作機械 / tooling: 90%+救出候補
- important raw/semifinished: 75–85%
- general stock / bulky low-value equipment: 60–75%

ただし輸送capacityを疎開へ優先した分、南京守備軍への短期補給が弱くなる。

南京最終撤退は夜間・混乱で航空の追加殺傷効率は下がる。主効果は「重装備を運べない」こと。
残存重装備の戦列喪失率候補:
- 野山砲 80–90%
- 車両 85–95%
- 迫撃砲 / 重機 60–75%
- 小銃 40–50%

南京・上海残存兵は後に収容されても、砲・通信・車両・古参幹部を自動で取り戻さない。

## 5. 政治社会の扱い

史実ベースラインとして、
- 反蒋派
- 和平派
- 軍閥の自己保存
- 対日協力者 / 協力政権参加者
- 占領地での商業的・政治的機会追求
- 強制・保身・二股

日本軍の残虐行為が存在したことを、これらの政治回路が消滅する万能変数として扱わない。逆に、残虐行為がなかったことにも、被害者の反日感情がなかったことにもしない。

後世の中華人民共和国・台湾・日本の記憶政治を1937–38年のactor knowledgeへ逆流させない。汪兆銘の後年離反が史実に存在することも、早期時点で全員が結果を知ることにはしない。

## 9. 航空と存在戦略

中国・ソ連側の戦闘機が存在するだけで日本側へescort / sweep sortieを強制できるが、存在戦略にも、
- fuel
- engine hours
- maintenance
- pilot fatigue / attrition
- forward airfield
- spare aircraft
の支払いがある。

日本側は1937戦訓から、
- advance sweep
- main bomber + close escort
- trailing sweep / airfield pressure
へ適応する。

敵が出れば消耗を強制し、出なければ一定時間のlocal air superiorityを得る。

1938前半は:
- theater-wide: Japanese air superiority
- Wuhan/Hankou: contested / denial-capable
- Chinese deep rear: time-dependent Chinese operation possible
- over Japanese ground front: strong Japanese advantage
を中央像とする。

I-16/I-15援助によって中国側は「撃たれ放題」から脱するが、三号の速度・航続と日本側の熟練搭乗員残存により史実ほど航空均衡へ戻らない。

## 11. 兵站は一つの壁ではない

幹線・末端・航空・敵抵抗を分ける。

航空基地は幹線からfuel / bombs / sparesを消費する一方、
- enemy artillery suppression
- reinforcement interdiction
- road/rail movement disruption
- reconnaissance
によって前線のammunition consumption、vehicle/horse loss、road work disruptionを減らす。

戦闘が軽くなって生じた輸送余裕の一部を、
- rail
- sleepers
- bridge material
- cement
- gravel
- road repair
- telephone wire
へ回すことで、数%の余裕が特定bottleneckの数日～数週間前倒しへ変換されることを認める。

しかし large bridge / locomotive / signal systemはengineer / specialist律速を強く受ける。

以後、transport ledgerを:
- consumable military freight
- aviation freight
- transport-capacity investment
- commercial/local-economy freight
へ分ける。

「兵站だから史実日付まで待つ」も「航空があるから無限進撃」も禁止。
一時的な航空支援突出圏を認め、最終的には幹線容量・道路・天候・fuelへ頭を押さえられる。

中国側は台児荘大捷を得ないため、史実より若干早いwithdrawal判断へ傾く。
central:

- 5th/10th divisions and southern forces less attrited
-末端補給capacity historical-equivalent比 +5～10%程度

historical-like bad weather / dust around 5/18 remains a major escape aid。航空優勢だけで完全包囲殲滅にはしない。
