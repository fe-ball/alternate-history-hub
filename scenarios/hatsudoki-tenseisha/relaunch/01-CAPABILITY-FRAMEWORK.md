# 能力収斂・余裕配分フレーム

> **Status: CLOSED for method / OPEN for most numeric coefficients**

本稿はリランチ後の発動機・生産・機体性能を作るための上流規則。
浅井側の capability-convergence / future-CAD benchmark の方法論を参照するが、人物・企業・数値は移植しない。

## 1. 100% benchmark

100% benchmark は「未来工場の召喚」ではない。

その年の日本で現実に使える次の条件は固定する。

- 材料・素材品質
- 燃料
- 工作機械
- 工員・技能
- 工場・電力
- 計測器
- 資金・調達
- 試験設備
- creep / 疲労 / 腐食 / 摩耗 / qualification に必要な実時間

理想化するのは設計室である。

**現代級の設計知識・解析能力・生産技術・故障知識を持つ専門家集団が、その現地条件で作れる最善の青写真、公差、工程、検査、試験、failure-mode一覧、trade study を返す状態**を100%とする。

したがって100%でも、現地で溶かせない合金、加工不能な形状、測れない現象、まだ回していない長時間耐久データは得られない。

## 3. 能力を一つの倍率にしない

監査座標を最低でも三本に分ける。

- **Gp / performance gain capture:** 100%設計なら得られる性能差の回収率。
- **Gd / development gain capture:** 試作、人日、手戻り、誤方式の削減率。
- **Gq / quality gain capture:** 寿命、信頼性、歩留まり、個体差、整備性の改善回収率。

Gp=80% を出力+80%としてはならない。
先に史実的基準設計と100% benchmarkの物理差を求め、その差の回収率として使う。

## 4. 問題クラス

| Class | 典型 | 未来知識の効き方 |
|---|---|---|
| L0 | 方式選択、気筒数、ボア/ストローク、空冷/液冷、系列構成 | 非常に強い。失敗枝をほぼ除ける |
| L1 | CR、減速比、基本熱収支、弁径概算 | 紙計算で100%へ近い |
| L2 | ポート、混合分配、点火MAP、過給機map、冷却ΔP | 試験が必要だがDOE・正しい計測で高速収斂 |
| L3 | 捩り振動、二次不釣合い、動弁サージ、熱変形、過渡制御 | 計装・反復・動的解析が必要 |
| L4 | 疲労寿命、焼付き、腐食、デポジット、軸受寿命、量産歩留まり | 実時間を大きく踏み倒せない |

年代一律の「現実%」は使わない。

## 6. 余裕通貨

技術項目ごとの「+3%」「+5%」を単純加算しない。
最終的に次の物理財布へ集約する。

- ノック余裕
- 充填余裕
- 熱余裕
- rpm / 機械応力余裕
- 摩擦損失
- 重量余裕
- 冷却抗力余裕
- 排気エネルギー回収
- 寿命余裕
- 量産ばらつき余裕

その後、製品で初めて次へ配分する。

- ピーク出力
- 5分 / 30分 / 最大連続
- 高空出力
- 低質燃料耐性
- 酷暑余裕
- TBO / inspection interval
- 重量
- 冷却抗力
- BSFC
- 量産保証
- 将来成長余地

一度配分した余裕を別用途へ満額二重計上しない。

## 7. 軸出力と搭載利得を分離

軸出力の上限は概念的に、

`BMEP_rated = min(air, knock, thermal, mechanical)`

で考える。

搭載状態は別勘定で、

`P_effective = propulsive use of shaft power + exhaust thrust × V - cooling drag × V`

とする。

排気推力、冷却抗力、プロペラ効率は発動機hpへ混ぜない。

## 8. 生産チート

主人公の強みは「ヤスリ職人国家を近代化」ではない。
当時の日本は既に近代工業であり、未来知識は次へ効く。

- 機能に効かない厳公差を解放
- 基準面の統一
- セットアップ回数削減
- 治具化
- 高頻度部品のみ専用化
- 低量部品は柔軟な汎用高級機
- 管理図で工程ドリフトを早期検出
- 全数後選別より工程内作り込み
- lot traceability
- 設計変更・工程変更管理
- supplier quality
- field failure feedback
- 設計と生産技術の同時進行

100% benchmarkと当時の優秀な航空発動機メーカーとの差として、成熟量産原価で **-15〜25%級候補**を監査対象とする。
実際の主人公会社が回収できる差は時期別に別途評価する。

## 9. 時間の規律

主人公の未来視は無限ではない。

- 甲設計時には乙を強く見通してよい。
- 乙設計時には寿・光世代を倒し、数年後に栄級要求と戦うところまでを強く見る。
- 甲の段階から誉・ハ43級、1944年要求までを完全に逆算しない。
- 乙より後の大型系列は、1935年以後に育った組織能力と新しい軍要求から再設計する。

この制約は物理制約ではなく、主人公という人物の情報処理・注意・事業判断の制約である。
