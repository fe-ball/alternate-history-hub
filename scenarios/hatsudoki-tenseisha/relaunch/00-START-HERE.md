# 発動機転生者・リランチ正本

> **Authority:** 2026-09-21 以後の再構築は本ディレクトリを正本とする。
> 旧 `current/` 技術台帳・`archive/` 引き継ぎ書は **pre-relaunch 参考資料**。旧数値・旧製品系列は、ここで再採用しない限り正準へ自動継承しない。

## 目的

旧体系の「1944年の18気筒要求から1932年の気筒寸法を逆算する」方式をいったん破棄し、
主人公がその時点で現実的に見通せる近未来と、当時の日本の産業条件から、能力・製品・機体史を再生成する。

再構築の順序は次のとおり。

1. 転生知識・設計能力・生産能力・試験能力を定義する。
2. 各時点の capability frontier を作る。
3. その時点の会社戦略・軍要求・市場・実測結果から製品と研究枝を生成する。
4. 製品の余裕はピーク出力だけへ丸めず、定格時間・燃料耐性・寿命・重量・冷却抗力・量産再現性などへ配分する。
5. 機体史は発動機能力から再構築し、旧機体性能を守るために発動機を弱めない。
6. 現行品、改良型、次世代研究は直列ではなく、合理的な範囲で時間的に並行させる。

## 現在の正準範囲

現時点で閉じるのは、甲から初期乙までの再構築方針と、1937年7月までのO2/暁搭載機中央ケース。

- **甲:** 軍への参入・信用形成だけでなく、乙と共通の気筒・燃焼・弁・リング・油・冷却・加工工程を量産で熟成する前駆商品。
- **乙:** 1935年の九六・九七式世代を明確に狙う主力商品。寿・光世代に対する明確な性能優位を狙い、とくに寿との比較では重量増という選択コストが残りうる。発展系列ではその後数年の栄級要求を明確に上回ることまでを成長責任とする。
- 甲の設計時点から誉・ハ43級までを同一気筒の完成要求として固定しない。これは主人公がその先を全く知らないからではなく、会社規模、軍の信頼、資金、工場、将来要求がまだ不確実だからである。
- 乙の開発開始後は、乙そのものの成熟と並行して、乙小改・高度性能枝・post-O2 architecture studyを検討してよいし、むしろ検討しない方が不自然である。
- 後世の大型系列は、会社自主研究、乙の実測、軍要求、当時までに育った組織能力が接続した時点で正式計画へ昇格させる。

## 必須の発展史ガード

このシナリオを **「甲完成→乙を考える→乙完成→丙を考える」** という直列史として読まない。

製品ごとに、最低でも次を分ける。

1. idea / paper study
2. trade study
3. 人員・予算付与
4. rig / single-cylinder / mock-up
5. prototype
6. endurance / ground test
7. flight installation
8. qualification
9. company proposal / military requirement
10. adoption
11. serial production
12. allocation / serviceability / deployment

未来知識はidea gateを非常に強く開くが、physical / industrial gateを無料では開かない。
逆に、物理・産業ゲートが払われている結果を「史実より早い」「強すぎる」という理由だけで史実中央値へ戻さない。

次期製品の起点は三種類を認める。

- **COMPANY-ORIGIN:** 尾張発動機が未来需要・成長限界・市場機会を見て自主研究する。
- **MILITARY-ORIGIN:** O1/O2で信頼した軍が具体的要求を出す。
- **MIXED:** 会社の先行研究へ軍要求が接続して正式計画になる。

後続研究の基本ループは、
**要求・仮説 → 設計 → rig / prototype → 実測 → failure / margin発見 → 要求修正 → 次の枝**
とする。

後年の成功型・戦訓・量産結果を早期checkpointへ逆流させない。
ただし主人公自身の未来知識は `SCENARIO-RULES.md` の有限未来視規律に従う。

長時間を要する疲労、摩耗、腐食、過給、軸受、工程能力、field-return等は、主人公が必要性を早く認識し、実際に予算・人員・rig・試験を開始したなら、その時点から時計を進める。
一度獲得した試験設備、QC、failure taxonomy、工程能力、技術者集団等は、因果的に共通する限り次製品へ継承し、史実日本の平均へ自然に巻き戻さない。

## 採否の規律

本ディレクトリに記載されても、次のラベルを区別する。

- **CLOSED:** 今後の計算入力として採る。
- **PROVISIONAL:** 現時点の最良案。物理監査・機体計算で変更しうる。
- **OPEN:** 未決。
- **REFERENCE:** 旧体系または比較用。正準値ではない。

特に性能値は、離昇・30分定格・常用最大・巡航・試験上端・条件付き定格を混ぜない。公称定格は指定条件で試験認定された使用上限として扱い、旧03の「最悪条件保証」的な読みは03Aで上書きする。
排気推力などの搭載利得は軸出力へ合算せず、独立した物理量として保持する。

current snapshotは「その時点の結果」であって、発展過程そのものの代用品ではない。
O2Bやpost-O2候補を扱う場合は、現在値を読むだけでなく、**いつ誰が何を理由にその枝を開始したか**を時系列で再構築する。
