# 名称・会社・制式呼称規則

> **Status:** naming policy = CLOSED
> **Authority:** Relaunch R2
> individual later model designationは採用時までOPENのものを含む。

## 1. 会社

前身は **株式会社尾張織機製作所**。

航空発動機部門がO1/旭の成功で独立し、1930年代初頭に **尾張発動機株式会社** となる。

尾張織機製作所は消滅せず姉妹会社として存続する。
- textile / weaving machineryが主力
- spinning / winding関連
- replacement / spares
- modest special-purpose machines / fixtures / gauges
- general machine-tool giantや自動車会社へはしない
- 航空側で育ったdatum / gauges / interchangeable parts / bearing / lubrication / vibration / QCが織機側へ逆伝播する
- 航空critical partsの自動qualified sourceにはしない

group salesの監査目安:
- Owari Engine 65–75%
- loom company 20–30%
- special machinery 5–10%
loom company内部はtextile 80–90%、special machinery 10–20%。

## 2. 三層名称

- 甲/乙/丙等: 会話・監査コード
- O1/O2/O3...: 尾張発動機社内型式
- 旭/暁/岳/昴/峰: 世界内製品名

current mapping:

| 監査/系列 | 社内型式 | 世界内名 |
|---|---|---|
| 甲 | O1 | **旭** |
| 乙初期 | O2 | **暁一一型** |
| 乙小改 | O2B | **暁一二型** |
| 乙二速主力 | O2C | **暁二一型** |
| 乙super-limit | O2D | **暁二二型** |
| large-cylinder 14 | O3 | **岳** |
| small-cylinder 18 | O4 | **昴** |
| large-cylinder 18 | O5 | **峰** |

岳の初期軍用型番号は岳一一型候補、昴の初期productは昴一一型、峰の初期productは峰一一型候補。正式採用時に最終確認する。

海軍試験符号や陸軍ハ番号は既存通し番号体系との整合を確認するまで先付けしない。

## 3. 機体名称

史実相当の要求・系列が残る場合は史実の試作番号・略符号・制式名称を優先。

- A4N相当 → A4N / 九五式艦上戦闘機
- A5M相当 → 九試単座戦闘機 / A5M / 九六式艦上戦闘機
- Ki-15相当 → Ki-15 / 九七式司令部偵察機
- Ki-21相当 → Ki-21
- Ki-43 / Ki-44 / Ki-45 / Ki-46相当は要求と設計系列が史実相当性を保つ限り同番号を使う

発動機換装・性能上昇・前倒しだけで新番号を作らない。

完全新要求または系列が史実相当性を失った場合だけ新番号を検討。

## 4. 海軍一号/二号/三号

1930年代半ばの海軍では、一号・二号・三号が小改修だけを意味するとは限らない。

本世界線:
- 九六式一号艦戦: 寿系軽量本流
- 九六式二号艦戦: O2前提に前胴・翼・prop・coolingを再設計した実用枝
- 九六式三号艦戦: 引込脚・閉鎖風防・高速化を進めた上位枝

を許容する。

番号は採用結果から決め、prototype段階で予約しない。

## 5. 二桁式

後年の一一/二一/三二式表示を1934–37へ無理に逆輸入しない。

二桁式を使う年代では、
- 十の位: airframe major generation
- 一の位: engine major generation
を意識する。

「O2Bを積んだから自動的に○○二一型」とはしない。

1937時点の九六三号について「三号二一」「三号三一」等は分析用便宜語に留め、正式名称化しない。

## 6. 発動機model number

暁は一一→一二→二一→二二を使用してよい。

- 一一: 初期一段一速
- 一二: 同architecture mature
- 二一: 二速主力
- 二二: 二速high-boost limit

岳・昴・峰は正式採用時に同様のmodel designationを閉じる。

## 7. 監査名の侵入禁止

甲/乙/丙、乙先進、暁18、岳18等は分析上の系譜名で、軍公文書・商品名へ自動変換しない。
主人公・会社の社内呼称、軍の制式名、後世の分析語が一致しないことを正常とする。
