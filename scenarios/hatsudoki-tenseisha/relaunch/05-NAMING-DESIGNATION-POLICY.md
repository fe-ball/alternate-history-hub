# 名称・会社・制式呼称規則

> **Status:** naming policy = CLOSED / individual later model names = OPEN until adoption
> 浅井世界線の命名方法論を参照するが、固有名称・番号は本世界線独自。

## 1. 会社

前身を **株式会社尾張織機製作所** とする。

航空発動機部門が甲/O1の成功で独立し、1930年代初頭に **尾張発動機株式会社** となる。

主人公の姓は未確定で、社名とは切り離す。

## 2. 三層の名称を分離する

- **甲 / 乙 / 乙改 / 乙先進:** 会話・監査用コード。世界内名称ではない。
- **O1 / O2 / O2B ...:** 尾張発動機の社内型式。
- **旭 / 暁:** 軍採用後の世界内発動機名。

現時点の対応:

| 監査名 | 社内型式 | 世界内呼称 |
|---|---|---|
| 甲 | **O1** | **旭** 系 |
| 乙 | **O2** | **暁** 系 |
| 乙小改 | **O2B** | **暁一二型** 候補 |
| 本格的な次世代乙改 | 未確定 | 採用時に型番号を決める |

海軍試験符号はメーカー符号の正式割当を確認してから閉じる。
仮のOK1/OK2を正準番号として先付けしない。

陸軍ハ番号も通し番号体系へ影響するため、採用時までOPENとする。

## 3. 機体名称の原則

史実相当の要求・機体系列が残る場合は、史実の試作番号・略符号・制式名称を優先する。

- A4N相当はA4N / 九五式艦上戦闘機系列。
- Ka-14 / A5M相当は九試単座戦闘機 → A5M / 九六式艦上戦闘機系列。
- Ki-15相当はKi-15 / 九七式司令部偵察機系列。
- Ki-21相当はKi-21系列。

発動機換装・性能上昇・登場前倒しだけを理由に、新しい機体番号を作らない。

例:
- **九五式艦上戦闘機・O2搭載試験機**
- **九試単座戦闘機・O2搭載型**
- **Ki-15・O2搭載試験機**

完全な新規要求、または構造・用途・系列が史実相当性を失う独立設計になった場合だけ、新しい試作番号を検討する。

## 4. 海軍の「同じ○式なのに別物」を許す

1930年代半ばの海軍では、一号・二号・三号等が必ずしも小改良だけを意味しない。
メーカーや基本構成が異なる機体が同一制式用途の別号として存在することも許す。

したがって世界線で、

- 九六式艦上戦闘機一号: 寿系の軽量本流
- 九六式艦上戦闘機二号: O2搭載に合わせて前胴・翼・propeller・coolingを再設計した実用枝
- 九六式艦上戦闘機三号: 独立設計に近い高速研究枝が正式採用された場合

のような系譜は命名上成立しうる。

ただし番号は**採用結果から後付け**し、試作段階で先に予約しない。

## 5. 後年の二桁型式表示

後年の「一一型・二一型・三二型」式の体系を1934–36年へ無理に逆輸入しない。

二桁式を使う年代になった場合、

- 十の位: 機体側の大改修世代
- 一の位: 発動機側の大改修世代

という意味を踏まえ、旧一号/二号呼称との読み替えを整理する。

したがって「O2を積んだから自動的に二一型」とはしない。

## 6. 現在の表記

1937年7月までの台帳では、採否がかなり固まったO2主力枝を **暁一一型** と記してよい。
研究枝・比較枝は史実系列名＋「暁搭載試験機」「O2搭載比較機」等で記す。

主人公や会社が使う社内呼称と、陸海軍の公文書名が違うことを正常な状態として扱う。
