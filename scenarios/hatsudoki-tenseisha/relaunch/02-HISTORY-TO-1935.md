# リランチ史 —— 甲から乙初期、1935年まで

> **Status:** 事業史・開発順序は CLOSED 寄り。年ごとの細部、軍契約数、機体採否は PROVISIONAL。
> 本稿は旧135×152一本化史を継承しない。

## 1. 甲の真意

甲は「弱い練習用」ではない。

軍から見れば、
**性能・価格・整備性だけなら普通に欲しい発動機。ただし新鋭メーカーが大量生産・補修・継続供給まで本当に頼れるかは未確認**
という位置を狙う。

主人公から見れば、
**乙と共通の気筒・燃焼・弁・リング・油・冷却・加工工程を、軍用商品として量産しながら熟成する前駆機**
である。

軍の認識は概ね次の順で進む。

- 1929: 妙に出来のよい新参試作。
- 1930–31: 普通に使える航空発動機メーカー。
- 1931–32: 次期計画の候補から外せない。
- 1932–33: 供給能力さえ確認できれば主力用も任せたい新興有力メーカー。

軍の投資理由と主人公の意図が一致する。

> 軍: 甲をもっと作らせるため設備・工作機械・試験機会を与える。
> 主人公: その設備で乙を作る。

## 2. 乙の真意

乙は1935年の九六・九七式世代を狙う。

一次目的は、

- 寿・光を選ぶ理由を減らす。
- 既存燃料・既存運用でも不利益を出さない。
- 小径・軽量戦闘機第一の要求へ合わせる。
- 量産全数で保証できる。
- その後4〜5年程度で栄級要求と正面から戦える。

乙に1944年の誉・ハ43級までの成長責任は負わせない。

## 3. 燃料思想

乙は「92octを要求する発動機」ではない。

- **87oct:** 正規保証線。通常運用・寿命・巡航で犠牲を出さない。
- **92oct:** 実験・特認高出力線。内部部品を変えず、主としてboost / ignition / mixture scheduleで追加性能を回収する。

設計圧縮比を92専用に上げ切らない。

営業上は、
**「現行ガソリンで普通に使える。実験的に92oct運転にも対応したところ、追加性能が出た」**
程度から始める。

供給網が育てば、92を後に標準化してよい。

## 4. 乙は軍に突然出現しない

乙の存在は早期から軍へ知られる。
驚きは「存在」ではなく、予想以上の性能と完成度。

| 時期 | 社内状態 | 軍・機体屋から見えるもの |
|---|---|---|
| 1929–30 | 甲試作 | 甲そのもの |
| 1930–31 | 甲少量量産・耐久 | 甲の供給能力を確認 |
| 1931–32 | 甲安定。乙機械系設計 | 「次は複列14をやっている」と逆提案 |
| 1932前半 | 乙0初回転 | 原則社内 |
| 1932後半 | 乙0 600–700hp級 | 軍技術者へ限定見学 |
| 1933前半 | 700–760hp、耐久開始 | 「800hp級以上を狙う」と正式説明 |
| 1933後半 | 750–800hp級 | 官側へ地上評価用個体を供給 |
| 1934前半 | 800–830hp級、飛行可能 | 機体メーカーへ飛行試験用個体、interface図面 |
| 1934後半 | 850–880hp級 | 次期機の比較試験 |

主人公は800hp級という堅い腹案を先に示し、内部では900hp超を狙う。
虚偽ではなく、保証可能な範囲を先に口にする。

## 5. 乙0の役割

商品甲へ複列14固有の複雑さを無理に背負わせない。

甲で育てるもの:

- シリンダ / ヘッド
- 燃焼室 / 双点火
- ピストン / pin / ring
- valve / seat / guide
- cooling fin
- bore / honing
- lubrication
- heat treatment
- production tooling / gauges

乙0で育てるもの:

- 7気筒master rod系
- 複列crankcase
- crankshaft
- 二列吸排気・後列冷却
- torsional vibration
- reduction gear
- supercharger installation

これにより甲は安く・軽く・単純に保つ。

## 6. 排気利用

排気利用は乙の軸出力へ足さない。

乙会社は自社飛行試験で、

- individual rearward exhaust
- nozzle area
- back pressure
- CHT
- cowl / cooling outlet interference

をA/B試験し、機体メーカーへ「推奨搭載パッケージ」として渡す。

1935世代では排気推力そのものは劇的でない。
**初期候補として15–25 kgf級**を独立変数として持ち、実機速度が上がるほど価値が増す。
ejector cooling shroudは研究対象だが初期乙戦闘機の標準装備にはしない。

## 7. 海軍九五・九六式世代への割り込み

海軍には概念上、次の選択肢が並ぶ。

1. **九五式艦戦系:** 完成済み・低リスクの滑り止め。
2. **九試・寿系:** 軽量・固定脚・単葉の野心的だが現実的な本命。
3. **九試・乙版:** 九試の長所を維持しつつ、乙の大出力に合わせ翼・前胴・propeller・coolingを再設計。
4. **乙先進:** 引込脚・閉鎖風防・高速構造・統合排気など、九試のさらに次世代を試す別機種級研究枝。

加えて **九五乙** を少数試験・qualification用として検討可能。

九五乙は主力競争用ではなく、

- 小型空母での発着艦
- 塩害
- 甲板始動
- 低速高出力冷却
- 復行
- 艦上整備
- CAP / 局地防空

を先払いする変則的testbed / 保険機として価値がある。

## 8. 事変前の生産効果

追加の発動機会社が存在しても、平時の第一線機数が発動機数に比例して増えるわけではない。
年度予算、部隊編制、機体工場、治具、熟練工が先に制約となりうる。

1932–35年の追加能力はまず、

- test enginesを惜しまず壊せる
- competing prototypesを並行できる
- spare engines
- reserve aircraft
- training aircraft
- conversion stock
- field qualification

へ回る。

既存メーカーを動員基盤として残す必要から、新参乙の採用が既存寿・光発注を完全置換せず、
**平時総在庫を modest に純増させる可能性**を残す。

現時点の仮置きでは、事変前航空総在庫への純増は **+5〜15%級を監査候補**とし、自動確定しない。
1936年以後の航空拡張局面では、既に温まった乙工場が増加需要の受け皿となり、初めて第一線機数の純増へ大きく転換しうる。
