## リランチの中心変更

旧体系は、1944年の18気筒大出力要求から逆算して1932年に135×152mm気筒を切り、
乙14気筒→丙18気筒を一気筒で覆う構造だった。

リランチ後はこの逆算を正準から外す。

- 主人公の未来視は無限としない。
- 甲では乙までを強く見通す。
- 乙は1935年の九六・九七式世代で寿・光と競争し、その後数年で栄級要求と戦えることまでを主な成長責任とする。
- 誉・ハ43級や1944年要求は、1935年以後に育った組織能力と軍要求から再設計する。
- 技術利得はピーク馬力へ丸めず、定格時間・燃料耐性・寿命・重量・冷却抗力・量産保証などへ配分する。
- 生産技術・試験能力・品質管理を設計性能と同格の能力軸として扱う。

## 現在の暫定製品座標

### 甲

- 130×150mm共通気筒の単列9気筒、約17.92L。
- 450hp級の普通に欲しい商品。
- 軍への信用形成と同時に、乙用気筒・燃焼・弁・リング・油・冷却・加工工程を量産で熟成する。
- 甲そのものを過度に高出力化せず、乙へ開発資源を移す。

### 乙

- 同130×150mm、複列14気筒、約27.87Lを第一候補。
- 87octで離昇900–920hp級、30分850–880hp級、常用最大780–810hp級を暫定座標とする。
- 92octは通常87運用を犠牲にしない特認・実験高出力線として980–1000hp級を候補。
- 定格は最悪条件最低保証ではなく、指定条件で受領・耐久試験を通した使用上限として扱う。
- 520–535kg、径1.14–1.15m級を監査中。
- 個別排気の推力はshaft hpへ足さず、独立した搭載利得として扱う。

これらの数値は `PROVISIONAL`。機体・熱・過給・重量監査で更新する。
