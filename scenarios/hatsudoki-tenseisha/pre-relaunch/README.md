## 何を残してよいか

旧資料から再利用してよいのは、**個別検討の材料・比較アンカー・失敗経緯**。

たとえば、

- 保証 / 通常 / demo / conditional ratingを分ける規律
- 冷却余裕を出力以外へ配分する考え
- 致死故障と検出可能摩耗を分ける故障工学
- exhaust thrustとshaft hpを分離する考え
- SPC / DFM / test infrastructure / NDTの重要性
- 旧数値が過大・過小だった理由

などは、リランチ正本で明示的に再採用すれば継承できる。
