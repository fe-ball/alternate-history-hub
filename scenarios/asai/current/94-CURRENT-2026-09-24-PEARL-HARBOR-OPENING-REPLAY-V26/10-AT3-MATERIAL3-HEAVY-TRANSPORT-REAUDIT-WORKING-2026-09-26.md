# AT-3 / MATERIAL NO.3 HEAVY-TRANSPORT RE-AUDIT — 2026-09-26

**Status:** POST-V26 WORKING TECHNICAL RE-AUDIT — DOES NOT CREATE 1941 OOB  
**Parents:** V8 Material No.3 origin / technical envelope; V10 E7 TP outlook; V11 industrial capacity; V15 visual geometry.  
**Combat-clock effect:** NONE.

## 1. Central verdict

The inherited AT-3 concept remains physically coherent. No clean-sheet redesign is required.

Retain:
- high wing;
- four turboprops;
- tricycle / multi-wheel low-pressure landing gear;
- non-pressurized large cargo box;
- rear lower ramp + upper/door structure;
- 48 m span / ~240 m2 wing / 35.5 m length / ~4.1 m outside fuselage width;
- metal primary load paths with bonded/sandwich/composite secondary structure;
- E6-M-T for first prototype / early aircraft;
- E7-M-T as preferred production-growth powerplant if its reducer/prop/TBO gates close.

The main re-audit corrections are semantic and operational:

1. separate **13 t standard-range cargo** from **15 t heavy / shorter-range cargo**;
2. split economical cruise, normal cruise and fast cruise;
3. treat 1,000–1,200 m as a favorable / lighter operational capability target, not the universal 55 t base-planning requirement;
4. heavy vehicles are **airland cargo to a secured major field**, not paradrop cargo;
5. the old 300 t/night short-shuttle figure is a theoretical surge arithmetic, not sustained planning throughput.

## 2. Geometry and weight

V15 visual geometry is retained:

- length: **35.5 m**;
- span: **48.0 m**;
- wing area: **~240 m2**;
- aspect ratio: ~9.6;
- external cargo-fuselage width: **~4.10 m**;
- internal cargo box target: **~13.2 x 3.25 x 3.0 m**;
- high wing;
- fuselage-side multi-wheel main gear;
- rear loading architecture.

Re-audited weight center:

| item | working center / band |
|---|---:|
| prototype X1 flight mass | 48–50 t |
| normal operational MTOW | **~54–55 t** |
| structural proof / short overload | ~58–60 t test envelope; not routine first-block service |
| operating empty target | **~29–30 t**, center ~29.5 |
| standard cargo | **~13 t** |
| normal heavy cargo | **~15 t short/medium range** |
| exceptional indivisible cargo | ~16–17 t class after local floor/CG/runway approval |
| fuel, standard 13 t cargo at 55 t | ~12.5 t available mass budget before reserves / installation details |

The 28–30 t old empty target is not dependent on an all-composite miracle. The first aircraft remains metal in the major primary load paths.

## 3. Structure / material policy

First-generation primary structure:
- metal center-wing carry-through;
- metal main spars / principal bending members;
- metal engine mounts / hot zones;
- metal landing-gear and ramp hinge hard points;
- metal heavy-cargo longitudinal tracks.

Use already-qualified process gains in:
- bonded aluminum skins / stiffeners where practical;
- metal-face / paper-honeycomb doors and secondary floor panels;
- plant-FRP / GFRP fairings, covers and wet secondary parts;
- local composite stiffeners only where current allowables support them.

Do not make CFRP primary structure a first-flight dependency.

The original 5–8% whole-aircraft empty/equipped relief target versus an otherwise comparable all-riveted heavy structure remains a **program objective**, not an achieved number before X1/X2 weight measurement.

## 4. E6 propulsion — first-flight baseline

First prototype / early aircraft remain on four E6-M-T.

Per engine:
- normal / high-power service coordinate: ~2,050–2,100 shp;
- long-duration transport coordinate: ~1,850–1,870 shp.

Aggregate:
- takeoff / short high-power: ~8,200–8,400 shp;
- long-duration: ~7,400–7,480 shp.

Propeller:
- **~3.8 m four-blade** remains a sensible E6 prototype center;
- constant-speed + full feathering mandatory;
- reverse pitch is not required for X1 service claims.

At ~2,100 shp and 3.8 m diameter, disk power loading remains comparable to the already-audited high-power propeller school; the major local gates are reducer torsion, governor behavior, blade/root fatigue and engine-out feather reliability rather than raw disk area.

## 5. Performance re-audit

### 5.1 Speed semantics

Do not call 330–360 km/h all "economic cruise."

Working split:

- best-range / economical cruise: **~290–310 km/h class**;
- normal operational cruise: **~315–335 km/h**;
- fast cruise: **~340–355 km/h**, fuel-costly;
- maximum, E6 first generation: **~395–415 km/h class** depending weight / altitude / drag / power retention.

This retains the older 390–415 km/h maximum-speed neighborhood while making the cruise claim more explicit.

### 5.2 Payload-range split

Use a first-order planning model centered on:
- 55 t initial mass;
- ~29.5 t operating empty;
- realistic propulsive efficiency / transport L/D;
- E6-M-T part-load fuel economy rather than the old gross-cycle shortcut;
- ~1.5 t protected fuel / diversion reserve class in the mission accounting.

Working planning bands:

| payload | practical planning range |
|---|---:|
| **15 t** | **~1,600–2,000 km**, center ~1,800–1,900 |
| **13 t** | **~2,000–2,400 km**, center ~2,200–2,300 |
| **10 t** with auxiliary-fuel provision | **~2,600–3,200 km**, center ~2,900–3,100 |
| ferry / very light payload | installation-dependent; do not publish a single value until tank volume is frozen |

Therefore the prior "13–15 t at 2,000–2,300 km" envelope is retained for the lower end of that cargo band but is **too generous if read as a guaranteed 15 t standard mission**.

Fuel-volume state must be tracked separately from weight margin. Removing cargo does not automatically create wing-tank capacity.

## 6. Low-speed / runway state

At 55 t / 240 m2:
- wing loading ~229 kg/m2;
- CLmax ~2.2–2.5 gives a design stall neighborhood roughly high-130s to high-140s km/h;
- approach planning roughly ~175–190 km/h depending configuration / weight.

Working runway semantics:

**Aircraft capability target**
- favorable prepared-field takeoff / landing performance can approach **~1,000–1,200 m class** with high lift and four-prop slipstream.

**Operational base-planning requirement at ~54–55 t**
- use **~1,200–1,500 m prepared / well-compacted usable runway class** until measured X1/X2 data close obstacle clearance, brake energy, tire heating and wet-field margins.

At 48–50 t prototype / lighter tactical state, the 1,000–1,200 m class is much more comfortable.

AT-3 is therefore not a first-wave rough-strip transport even with low-pressure multiwheel gear.

## 7. Cargo handling and heavy-vehicle use

Cargo box remains approximately:
- 13.2 m long;
- 3.25 m wide;
- 3.0 m high.

Rear clear opening should target roughly **2.8–3.0 m usable width**.

Floor:
- four strong longitudinal load tracks;
- distributed tie-downs;
- removable roller / skid system;
- heavy load-spreading beams / frames;
- ramp loads reacted to ground supports rather than unsupported cantilever.

### Vehicle use

The mission is **airland**, not heavy-equipment paradrop.

Physical / weight interpretation:
- two Type 95 Ha-Go class light tanks are within the ~15 t combined-mass neighborhood and fit longitudinally;
- one standard / new-turret Chi-Ha class vehicle fits the cargo box geometrically, but its ~15–16 t worldline mass belongs to the **short-range heavy-cargo state**, not the 13 t standard mission;
- artillery tractors, recovery vehicles, workshop modules and engineer machinery are often more valuable routine cargo than tanks.

Vehicle carriage always requires:
- floor-track proof;
- ramp proof;
- CG position;
- tire / gear loading;
- destination unloading surface.

Do not infer that every 15 t vehicle can be driven in merely because total payload mass is sufficient.

## 8. Personnel / medical use

Heavy-cargo mission remains primary.

Working configurations:
- normal troop transport: ~70–80 personnel class depending seats / baggage / fuel;
- paratroop: **~50–60** remains a deliberate conservative drop configuration because exit flow / CG / equipment, not payload mass, becomes the gate;
- medical: ~40–50 litter patients + attendants remains a reasonable first-generation fit.

Conventional transports should carry ordinary personnel whenever they can; AT-3 should not waste heavy-airlift capacity simply because seats fit.

- 1942Q2: X1 final assembly / systems integration / four-engine ground runs;

These are WORKING development targets, not pre-recorded future events.

## 11. E7 growth path

Do not wait for E7 to fly X1 if doing so delays the airframe.

Preferred architecture:

### X1 / early aircraft
4 x E6-M-T:
- mature enough to de-risk airframe / landing gear / cargo systems;
- ~2,100 shp high-power class.

### E7 production-growth comparison
4 x E7-M central TP:
- ~2,250–2,450 shp normal planning class if reducer / prop / TBO gates close;
- aggregate ~9,000–9,800 shp.

Primary use of E7 margin:
1. hot/high / tropical takeoff and one-engine climb;
2. retain 55 t performance with more real reserve;
3. permit ~58 t growth or ~15 t standard cargo without sacrificing runway target;
4. only then spend residual margin on headline speed.

Do not redesign the aircraft around two E7-L engines. Engine-out asymmetry, propeller diameter, reducer and ground-clearance costs make that a poor first growth step.

E7 growth likely needs a larger / higher-activity ~4.0–4.2 m class propeller and may justify five blades; this remains a local 1942–43 qualification gate.

## 12. Industrial / production constraint

Raw E6 cores are not the dominant prototype constraint by 1941–42.

Bottlenecks are more likely:
- very large wing / center-section jigs;
- gear / brakes / tires;
- large reducers and propellers;
- heavy floor / ramp fittings;
- skilled large-airframe assembly / QA;
- hangar / assembly-bay capacity.

Working production semantics:
- prototype / pre-series can be supported inside the existing large-aircraft program;
- ~1 aircraft/month is a reasonable initial low-rate mature target;
- sustained 3–4/month requires dedicated additional facilities / major opportunity cost.

No free mass-production gain is created from T-5 core capacity alone.

## 13. Operational doctrine if service is reached

Priority cargo hierarchy:

1. complete aircraft engines / turbine modules and failed-unit return;
2. workshop / generator / pump / radio / radar / optical packages;
3. engineer equipment and recovery vehicles;
4. artillery / tractors / ammunition bundles where indivisibility matters;
5. light / medium armored vehicles to **secured major forward airfields**;
6. medical evacuation / high-value return freight.

Do not use AT-3 for routine rice / ordinary ammunition if ships / rail can deliver on time.

### Short shuttle throughput guard

The old example "10 aircraft x two 15 t sorties = 300 t/night" is **theoretical arithmetic only**.

For planning:
- unit 12–13 aircraft / ~10 ready is already a strong readiness state;
- sustained heavy-cargo planning should normally begin around **one effective heavy sortie per ready aircraft per day** on short secure routes;
- 10 ready aircraft therefore produce roughly 100–150 t/day gross delivered-leg cargo depending load / turnaround / weather;
- two sorties/day is a surge case requiring very short legs, prepared handling and maintenance debt.

Do not treat short-shuttle surge arithmetic as theater-wide sustained throughput.
