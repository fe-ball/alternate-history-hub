## 1. What the GT aircraft actually changed

The early GT aircraft provide a strong empirical control experiment:

- GT aircraft have no continuous repetitive spark ignition after start;
- piston aircraft create repeated high-voltage ignition impulses;
- identical/similar radio installations are observably quieter on the GT aircraft.

This does NOT mean Asai discovers RF interference.

It accelerates Japanese standardization of:
- magneto / HT lead / plug shielding;
- bonding straps;
- generator suppression;
- condensers / chokes / filtering;
- power filtering;
- waterproof / vibration-resistant connectors;
- aircraft-side radio-noise acceptance tests.

Timeline authority:
- 1932Q4 observation;
- 1933H1 comparison;
- 1933H2 acceptance-test proposal;
- 1934 Army/Navy trials;
- 1935 important-aircraft acceptance requirements begin;
- 1936-37 spread especially to recon/bomber/long-range/naval aircraft.

## 2. What this buys on a piston fighter

For an A6M fitted with a functioning radio, the worldline gain can be:

- lower ignition-noise floor;
- better weak-signal intelligibility;
- fewer intermittent noise-related unreadable calls;
- more repeatable installation/grounding quality;
- better connector/weather/vibration reliability;
- more useful formation / air-ground communication than an otherwise identical poorly suppressed installation.

This is a **communications availability / intelligibility gain**.

It is NOT automatically:
- longer transmitter range by a fixed percentage;
- higher transmitter power;
- frequency agility;
- secure radio;
- IFF;
- data link;
- continuous controller tracking.

## 3. Fighter formation doctrine is NOT automatically changed

The V7 authority explicitly states:

**radio alone does not fix doctrine.**

No current source closes a general IJN fighter-doctrine reform that changes:
- section/shotai geometry;
- leader-wingman relationship;
- mutual-support doctrine;
- attack order;
- coordinated multi-section firing;
- standardized radio brevity;
- disengagement doctrine;
- combat spread;
- squadron-level free-fighter control.

Therefore:
**retain the historical-type IJN fighter tactical/doctrinal baseline unless a separate doctrinal event is found or created.**

The improved radio makes existing calls more likely to get through.
It does not invent new calls, new formations or a new command philosophy.

## 4. "Formation handling" correction

Prior V26 discussion sometimes used language such as:
- improved radio reliability / formation handling;
- improved section integrity.

These phrases must be read narrowly.

Allowed interpretation:
- fewer formation breaks caused specifically by unreadable radio calls;
- easier regroup / simple vector / leader instruction when the radio is working;
- less installation/QC variance between aircraft.

Not allowed without further evidence:
- intrinsically tighter combat formation;
- modern two-ship mutual-support tactics;
- coordinated firing attacks;
- higher kill efficiency simply because the radio is clearer;
- automatic tactical reorganization after first contact.

Thus the earlier broad "formation handling" combat bonus is **downgraded**.

## 5. Gunnery / firing doctrine is a separate path

V8 FCS1-type gains provide:
- better boresight;
- better mount/alignment/QC;
- better ammunition-lot consistency;
- better re-zero repeatability;
- smaller systematic sighting error when firing geometry is already favorable.

They do NOT provide:
- gyro lead;
- new fighter firing doctrine;
- coordinated formation fire;
- guaranteed higher hit rate;
- doctrinally improved deflection shooting.

For A6M combat:
gunnery-quality improvement is technical / repeatability based, not a new formation-shooting system.

## 6. Airspace command / fighter direction — what DID change

There is a real but limited organizational change in warning/control.

By 1940-41 the worldline improves:
- observer posts;
- direct telephone/radio reporting;
- plotting rooms;
- standardized report format;
- readiness states;
- better local Army-internal and Navy-internal handoff.

This is a **warning/readiness/plotting system gain**.

V26:23 explicitly keeps:
- ground/shore plotting as the main fighter-control node;
- no nationwide RAF-style precision GCI;
- no seamless Army-Navy common air picture.

Thus airspace command improves mainly in:
**detect -> report -> plot -> alert -> launch -> coarse vector**.

It does NOT close:
**continuous track -> exact altitude -> individual fighter control -> dynamic battle management**.

## 7. Carrier-fleet air control is even more limited

By spring 1942 selected carriers may have Type21-line air-warning radar.

Its allowed effects:
- coarse early warning;
- threat-bearing cue;
- plotting-room support;
- coarse CAP vectoring.

Not allowed:
- reliable precision altitude;
- continuous fighter tracking;
- mature CIC;
- mature GCI;
- shared multi-carrier digital/voice picture;
- radar gun-laying.

Therefore an Apr29 or MI carrier CAP can receive:
- earlier launch/alert;
- broad bearing instructions;
- approximate threat timing.

After fighters engage:
the controller picture degrades rapidly.

V26:67 TRUE_STATE vs CONTROLLER_ESTIMATE remains mandatory.

## 8. A6M radio benefit at Apr29 — revised interpretation

For current Apr29 CarDiv5 modeling:

- improved EMI suppression / installation reliability;
- improved probability that simple tactical radio messages are intelligible;

Do NOT grant:
- doctrinally improved fighter formations;
- improved multi-section attack choreography;
- automatic mutual support;
- precision ship-to-fighter control;
- a generic "section integrity" combat multiplier.

V26:73-76 remain useful, but one component is narrowed.

A6M-only CAP gains from:
- common performance envelope;
- common fuel/spares;
- common deck handling;
- common pilot qualification;

The C2 benefit is:
- simpler planning and fewer type-specific estimation errors.

It is NOT:

The controller still has only a coarse picture.
