## 1. Do not use one generic "air command"

Separate four functions.

### A. Operational mission command
Held below:
- fleet / carrier-division commander and air staff.

Controls:
- mission objective;
- target class / priority;
- launch timing window;
- strike mass;
- reserve policy;
- broad route / rendezvous;
- CAP allocation;
- abort / retask rules;
- second-strike preparation.

### B. Ship / base air-operations control
Held below locally:
- carrier captain / air officer / flight-deck and air-group staff;
- equivalent base air-operations function ashore.

Controls:
- actual launch/recovery sequence;
- deck readiness;
- fuel / armament state;
- which ready fighter element can be launched;
- recovery conflicts;
- damaged-aircraft handling;
- local CAP relief.

### C. Airborne tactical command
Held in the air:
- overall strike leader when a multi-type strike is formed;
- fighter / dive-bomber / attack-aircraft mission leaders;
- chutai / two-shotai package leaders;
- shotai leaders.

Controls after launch:
- route corrections within mission intent;
- altitude / spacing;
- formation split/reform;
- visual target confirmation;
- attack sequence;
- local target allocation;
- attack-axis changes;
- abort or disengage when prebriefed thresholds are crossed;
- return / divert / rejoin.

### D. Fighter-direction / defensive control
Shared:
- ship/base plot and controller below;
- CAP leader in the air.

Below controls:
- sector;
- broad bearing vector;
- reinforcement / reserve launch;
- relief;
- priority of high/low threat.

Airborne CAP leader controls:
- exact intercept geometry;
- which shotai/package actually engages;
- cover versus attack;
- reform;
- disengagement once visual combat develops.

## 2. The key doctrinal effect of better communication

The most important result is NOT "the ground controls aircraft more closely."

It is:
**the boundary between below-side command and airborne command becomes more explicit.**

Better radio lets the organization:
- pass intent before contact;
- update threat information;
- receive status;
- issue a limited retask;
while still recognizing that the airborne leader has the better local tactical picture after visual contact.

This produces a form of delegated mission command without requiring foreign doctrine import.

## 3. Why over-centralization is self-correcting

Once radio becomes usable, commanders will initially be tempted to give more detailed orders.

China combat quickly reveals the limits:
- reports are delayed;
- positions are approximate;
- enemy geometry changes faster than headquarters can follow;
- radio traffic can congest;
- transmission can be missed;
- the airborne leader sees what the controller does not.

Therefore procedure should evolve toward:

below:
- objective;
- priority;
- boundary conditions;
- reserve;
- broad vector.

airborne:
- execution geometry;
- exact attack sequence;
- immediate target choice.

This is a mature response to imperfect communications.

## 4. 1935-1936 — command procedure begins

Radio becomes reliable enough for:
- check-in;
- acknowledgement;
- route / rendezvous;
- simple status;
- recall.

Command remains strongly prebriefed.

Below-side authority:
- high.

Airborne authority:
- mainly execution of a fixed plan.

## 5. 1937-1938 China combat — local discretion expands

Repeated combat produces situations where:
- the target moves;
- weather changes;
- escort becomes separated;
- reconnaissance updates arrive late;
- the planned route is no longer ideal.

Working adaptation:
- mission leaders receive explicit discretion to change local route/altitude;
- reconnaissance/strike leaders can confirm/deny target state;
- airborne leaders can abort uneconomic attacks within defined limits;
- group leaders report results / BDA / fuel and request re-task or return.

The E5 command-recon/BDA system reinforces this culture:
recon -> strike -> BDA -> retask becomes a recurring command loop.

## 6. 1939 — command roles become more specialized

As information throughput grows, the organization differentiates roles.

Below-side staff increasingly owns:
- mission allocation;
- intelligence synthesis;
- readiness;
- route/deconfliction planning;
- reserve management.

Airborne leaders increasingly own:
- local geometry;
- target confirmation;
- formation integrity;
- engagement sequence.

This is also when "more information" begins to require staff filtering:
not every report goes directly to every pilot.

## 7. 1940 A6M / long-range operations — airborne command becomes more important

Long range and higher speed increase:
- positional uncertainty;
- separation between subelements;
- consequences of fuel mismanagement;
- need for rejoin / divert authority.

Therefore A6M-era fighter/strike leaders need more delegated authority, not less.

Working change:
- strike leader has authority to alter local approach and attack timing;
- type leaders can reassign their own subelements;
- fighter-cover leader can detach / retain cover elements;
- shotai/two-shotai package leaders can act independently inside the commander's intent.

Radio makes this delegation reversible:
the lower commander can still send a broad retask or recall.

## 8. Late 1940-1941 carrier concentration — multi-layer command becomes explicit

Concentrated carrier operations create a command-span problem.

No single airborne leader can directly maneuver every aircraft.

Use layered command:

### Carrier-force / CarDiv below-side
- target priority;
- launch window;
- reserve;
- broad mission architecture.

### Overall airborne strike leader
- route;
- main timing;
- final attack coordination;
- major local retask.

### Type / mission leaders
- fighter cover;
- D3A group;
- B5N/FT-Type91 group.

### Tactical package leaders
- six-aircraft/two-shotai fighter packages;
- bomber/attack subgroups.

### Shotai leaders
- immediate maneuver / firing / reform.

The radio improvement makes the hierarchy functional without making it centralized to the individual-aircraft level.

## 9. Strike-command doctrine by spring 1942

For a multi-type carrier strike:

### Before launch
Below side defines:
- target;
- priority;
- weapon role;
- planned sequence;
- rally point;
- return/divert criteria;
- radio signals / code words;
- lost-comms fallback.

### En route
Overall strike leader can:
- adjust course/altitude;
- delay or compress formation;
- order fighter cover reposition;
- split a reconnaissance / late element;
- respond to new contact information if credible.

Below side may transmit:
- target-location update;
- target-priority change;
- abort/recall;
- emergency divert.

It should NOT normally:
- micromanage exact attack bearing once the strike has visual contact.

### On target
Overall leader:
- confirms target identity/class;
- chooses whether the prebriefed multi-axis plan is still valid.

Type leaders:
- execute D3A / Type91 / FT timing;
- adapt to CAP/AA/maneuver.

Package/shotai leaders:
- control individual approach groups.

After final attack commitment:
below-side tactical control is minimal.

## 10. CAP-command doctrine by spring 1942

CAP differs because it remains physically near the defended force.

Below-side control therefore persists longer.

Ship/base controller can:
- update bearing;
- launch reserve;
- hold a high element;
- order broad sector change;
- order relief/return.

Airborne CAP leader can:
- choose intercept line;
- assign two-shotai package versus single shotai;
- preserve cover;
- disengage from a decoy/low-value target;
- request reinforcement.

After merge:
authority shifts downward in the air:
- package leader;
- shotai leader;
- individual pilot if control fragments.

## 11. "Downside" / below-side command is not one person

For carriers, separate:

### Force commander / air staff
Owns operational purpose.

### Carrier captain
Owns ship safety / maneuver / flight operations interface.

### Air-group command / air staff
Owns aircraft readiness / mission package / crew state.

### Flight-deck / hangar organization
Owns physical generation of sorties.

### Fighter-control / plotting function
Owns current defensive air picture and CAP cueing.

These functions may overlap in personnel in 1942.
Do not invent a later-war CIC bureaucracy where none exists.

## 12. Information ownership

By spring 1942, each layer has different information.

Force / air staff:
- best strategic/operational picture;
- poor immediate air geometry.

Ship plot/controller:
- best local warning picture;
- approximate CAP status.

Airborne strike/CAP leader:
- best local visual/tactical picture;
- limited wider operational picture.

Shotai/package leader:
- best immediate maneuver picture;
- narrowest horizon.

The command system works when decisions are made at the layer with the relevant information.

## 13. Command latency

Track explicitly.

### Strategic/operational
Minutes to hours:
- staff estimate;
- new strike order;
- reserve policy.

### Ship-to-air broad retask
Tens of seconds to several minutes:
- detect;
- interpret;
- transmit;
- acknowledge.

### Airborne package command
Seconds to tens of seconds:
- visual assessment;
- leader call;
- maneuver.

Therefore:
a ship order may be valid for sector/task changes,
but can be stale for exact attack geometry.

## 14. Command-quality states

Use two separate state families.

### B-CMD — below-side command state

B0:
- no coherent current picture.

B1:
- broad mission / readiness only.

B2:
- useful group-level plot / readiness / task picture.

B3:
- locally strong current picture with recent radar/visual/leader reports.

Spring-1942 first-line carrier force:
- B2 normal before contact;
- B3 possible temporarily with coherent Type21/visual/report input.

No B4 continuous precision battle-management state.

### A-CMD — airborne command state

A0:
- fragmented individual action.

A1:
- shotai leader control.

A2:
- two-shotai / chutai package control.

A3:
- overall strike/CAP leader successfully coordinating multiple packages.

Spring-1942:
- A2 normal in prepared first-line units;
- A3 possible before and during early coordinated attack;
- dense combat can degrade A3 -> A2 -> A1 -> A0.

## 15. Handoff state is the critical variable

Model command by handoffs:

H1:
below mission order -> airborne leader.

H2:
sensor/plot update -> CAP/strike leader.

H3:
overall airborne leader -> type/package leader.

H4:
package leader -> shotai.

H5:
airborne status/BDA -> below side.

Most command failures are not "bad leadership."
They are:
- late handoff;
- ambiguous handoff;
- unacknowledged handoff;
- stale information;
- leader casualty;
- channel congestion.

## 16. Friendly-fire / airspace coordination

Better command should also affect the fighter-AA boundary.

Prebriefed:
- CAP altitude/sector;
- approach/recovery lane;
- emergency clear-sector call;
- broad AA engagement condition.

But no automatic deconfliction exists.

If CAP follows a low attacker into the close AA envelope:
- ships may still fire;
- controller may order break-off;
- compliance may be late.

Thus communication reduces, but does not eliminate, fighter/AA interference.

## 17. Implication for FT / multi-stage attack command

Japanese strike command can prebrief:
- FT suppression candidate role;
- Type91 axis;
- D3A timing;
- exploitation signal.

But because local geometry changes:
- airborne strike/type leaders decide whether a suppression-capable FT actually attacks a screen node or the carrier;
- below side does not choose "attack cruiser X" in real time unless the situation is exceptionally clear.

This directly supports the V26:63 multi-stage model.

## 19. MI implication later

After Apr29 re-audit, MI should NOT use:
- one omniscient Nagumo-side controller;
- fully independent uncoordinated shotai.

Instead use:
- operational mission command below;
- group-level CAP control near the force;
- delegated airborne strike command at range;
- layered type/package/shotai authority;
- explicit handoff latency and failure.
