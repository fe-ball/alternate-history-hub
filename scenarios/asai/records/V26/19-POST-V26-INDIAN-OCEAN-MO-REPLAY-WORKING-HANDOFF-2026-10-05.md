## 10. FT performance issue discovered during replay

This replay used FT evasion mostly through:
- mother-aircraft approach / attack setup cues,
- Allied prior intelligence,
- mixed-weapon geometry,
- not a fully closed seconds-level FT time-of-flight model.

Important unresolved issue:
- standard FT final cruise / terminal speed is not yet numerically closed,
- practical combat release range is not yet numerically closed,
- therefore exact defender reaction time is not yet closed.

This creates a replay-audit risk:
- some earlier defensive turns, especially Crace-type no-CAP cases, may have implicitly allowed too much post-release reaction time.
- Yorktown / Saratoga cases are less exposed because they had radar warning, fighter interception, B5N approach cues, and prior FT intelligence.

## 11. Mother-aircraft differentiation

B5N + FT:
- requires a clearer shallow-dive / acceleration setup,
- release around the existing working 350-380 km/h class envelope,
- provides more visible pre-release cue.

Higher-speed FT mother:
- can enter release condition with less acceleration setup,
- reduces pre-release warning,
- shortens the transition to useful ramjet flight,
- may become a “short-warning snap-release” weapon rather than merely a longer-standoff weapon.

Do **not** assume arbitrary high-speed release until store-separation / adapter / q qualification is closed.

H6K / H8K:
- H6K + Type91 is historically plausible / combat-proven as a concept.
- H6K + standard FT is not combat-present.
- H8K FT interface remains PROPOSED.
- rocket-assisted ramjet FT + dedicated drop/ejector arm is a development proposal, not yet combat-present.
- do not turn scarce H8K into a mass FT attack platform before production / serviceability justifies it.
