## 4. Interface / carriage closure — WORKING

Because FT is Asai-origin and separation is a first-order design problem, Asai is deeply involved in the store interface.

Architecture:
`mother-aircraft primary structure -> aircraft-specific adapter beam -> common two-point ejector cradle -> common FT suspension interface`.

Representative ejector:
- synchronized two-point positive separation;
- stroke ~0.10–0.15 m;
- average downward force ~5–10 kN;
- peak ~10–20 kN;
- stored energy ~0.5–1.5 kJ;
- complete cradle/ejector ~20–40 kg.

Design philosophy:
- datums / shear keys / locating bushes establish position;
- bolts/hooks carry load rather than being used for improvised alignment;
- keyed multi-contact electrical connector;
- positive safe/arm/separation interlocks;
- ramjet/rocket full thrust impossible while attached;
- standardized continuity / gyro / ejector / control-neutral checks;
- serial-life cards for reusable racks/ejectors.

1941 mature configuration:
- wings are **flight-fixed but removable for stowage**, not folding/deploying in flight;
- concentrated-load structure remains metal;
- FRP/epoxy may be used for fairings/covers, not the primary rack load path;
- production alignment target roughly ±0.1–0.2° class for mature jigs/gauges.

Aircraft-specific carriage trim:
- B5N may accept incidental FT self-lift during takeoff;
- G4As high-speed carriage biases weapon incidence toward near-zero lift, then post-release gyro/tail commands the useful weapon angle of attack.

This is a 1941 implementation of a much later **interface-control / configuration-management / modular-maintenance philosophy**, not future electronics.
