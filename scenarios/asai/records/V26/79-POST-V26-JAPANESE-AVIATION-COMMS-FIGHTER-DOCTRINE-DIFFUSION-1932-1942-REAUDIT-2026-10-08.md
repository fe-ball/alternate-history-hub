# POST-V26 Japanese aviation communications -> fighter doctrine diffusion re-audit, 1932-1942 — 2026-10-08

Status: WORKING-CLOSE / DOCTRINE-TIMELINE RECONSTRUCTION / NO COMBAT OUTCOME PROMOTION

## Authority guard

V26 canon remains 1941-12-07T14:30:00-10:30 HST.

This file supersedes the overly static reading in V26:77-78 that "radio improves but fighter doctrine remains essentially unchanged."

Correction:
- radio alone does not magically create doctrine;
- BUT a decade of improving radio usability plus continuous combat from 1937 onward must generate procedural and tactical adaptation;
- absence of an earlier dedicated doctrine file is not evidence that field practice remained frozen.

Do not invent a Western-style doctrinal revolution.
Do reconstruct the changes that repeated combat and usable communications would naturally select.

## 1. Four separate diffusion layers

Treat communication-driven change as four clocks.

### L1 — hardware usability
- ignition-noise suppression;
- bonding / filtering / connectors;
- installation QC;
- radio serviceability / intelligibility.

### L2 — procedures
- callsigns;
- check-in / acknowledgement;
- mission frequencies;
- rendezvous / rejoin points;
- abort / recall;
- lost-comms fallback;
- bearing / altitude / contact report format.

### L3 — tactical employment
- formation spacing;
- task split between shotai/chutai;
- attack / cover / reserve roles;
- staggered passes;
- disengage / regroup / re-attack;
- escort handoff.

### L4 — command architecture
- observer / ship / airfield report;
- plot;
- readiness;
- launch;
- coarse vector;
- CAP leader / mission leader allocation;
- relief / reserve cycling.

L1 enables L2.
Repeated combat turns L2 into L3.
Staff/training institutionalization turns L3 into L4.

No layer appears instantly.

## 2. 1932Q4-1934 — technical discovery / acceptance phase

Already closed in V7:
- E4 GT aircraft reveal dramatically cleaner radio conditions;
- same radio/antenna comparisons isolate piston ignition/generator noise;
- aircraft-side radio-noise acceptance testing follows;
- Army/Navy trials shielding, bonding, generator suppression and filtering.

Operational effect:
- almost entirely L1.

Do NOT backdate:
- new fighter formation doctrine;
- fighter direction;
- standardized combat voice procedure.

This period changes the engineering problem from:
"airborne radio is inherently unreliable"
toward:
"installation noise is measurable and fixable."

## 3. 1935-1936 — reliable-radio procedure begins to matter

V7 already closes:
- acceptance requirements spreading to important aircraft;
- especially reconnaissance, bomber, long-range and naval aircraft;
- early air-ground institutionalization.

Natural aviation consequence:
- radio checks become a real dispatch item rather than ceremonial equipment;
- units begin writing usable call / acknowledge / lost-comms procedures;
- route changes and simple mission reports can be trusted more often;
- flight leaders learn that separated elements can sometimes be recovered by voice rather than only visual search.

Fighter impact:
- still uneven;
- no radical combat-formation reform yet;
- visual formation remains primary.

State:
- L1 mostly established on priority aircraft;
- L2 emerging.

## 4. 1937 — China war turns reliability into operational feedback

Continuous combat matters.

Once naval/Army aviation flies repeated combat sorties:
- radio failures become logged operational defects;
- successful calls create direct evidence of value;
- mission leaders learn which messages are worth transmitting under workload.

By late 1937, plausible/required procedural adaptations are:

### before contact
- common mission check-in;
- route/rendezvous confirmation;
- bomber/escort join-up;
- weather / diversion / field-status updates;
- mission-leader recall.

### during contact
- simple enemy-sighting call;
- direction / altitude-band call;
- "engage / hold / rejoin / return" class command;
- warning that an element is separated or fuel-limited.

### after contact
- rejoin point;
- missing-aircraft accounting;
- diversion / recovery coordination.

This is NOT modern fighter direction.
It is the first combat-driven L2 normalization.

## 5. 1938 — long-duration war creates tactical adaptation

By 1938 the change can no longer remain "radio works more often."

Repeated escort / sweep / reconnaissance-support operations naturally select practices that exploit it.

Basic IJN fighter organization remains historically recognizable:
- three-plane shotai;
- nine-plane chutai.

But the formation need not remain visually rigid throughout the mission.

Working 1938 adaptation:
- wider/looser pre-contact spacing where visual contact remains safe;
- altitude separation between elements;
- mission leader can detach a shotai for visual check/intercept and recall it;
- shotai can rejoin by agreed point/bearing rather than staying physically glued to the formation;
- escort elements can be reassigned between bomber groups by voice;
- fuel/engine trouble can be reported without the entire group automatically following home.

Combat behavior after merge remains pilot-centric and aggressive.
Dogfight cohesion still degrades quickly.

State:
- L2 established in experienced units;
- L3 begins locally.

## 6. "Formation firing" — what actually changes

Do NOT invent synchronized volleys.

The realistic change is **attack sequencing and role assignment**.

With usable voice:
- leader can nominate which shotai attacks first;
- another shotai can remain high / cover / reserve;
- an attack element can call break / rejoin;
- duplicate pursuit of the same target can be reduced;
- follow-on attack can be delayed until the first element clears;
- escort can be told to remain with bombers instead of every pilot joining the dogfight.

Individual pilots still aim/fires individually.

FCS1 / boresight/QC improvement remains a separate technical gain.

Thus:
radio changes **who attacks when and who does not**, more than it changes the ballistic act of shooting.

## 7. 1939 — China + Nomonhan drive warning / reserve / control procedures

V9 actor lessons already preserve:
- improved Japanese reconnaissance / operational warning;
- rising demand for radio;
- command/control lessons.

Natural 1939 aviation adaptation:
- formalized alert categories begin to matter;
- airfield fighter units practice launch against reported bearing/approach;
- patrol areas / altitude bands become more explicit;
- not every fighter must chase the first contact;
- retaining a local reserve becomes a repeatable procedure;
- after-action reports can correlate warning time, launch time, contact time and missed intercept.

Army and Navy do not become one air-control organization.
Each service learns internally.

State:
- L3 spreads;
- L4 begins at major bases / major operational headquarters.

## 8. 1940 — A6M China combat + massed naval aviation

V24 closes:
- A6M already conducts China combat/escort;
- better radio improves persistence on supported axes;
- Chinese fighters increasingly avoid unfavorable mass combat.

Historical sanity anchor:
China-war experience itself led the IJN toward carrier concentration and the end-1940 "box" carrier concept; doctrine was historically dynamic, not frozen.

Worldline consequence with better radio usability:
- long-range A6M escort is easier to assemble/rejoin;
- bomber escort can be divided by altitude/task;
- mission leader can preserve a cover element rather than relying only on visual discipline;
- multi-chutai sweeps can separate and rejoin with less risk;
- standardized contact/bearing/altitude/fuel-state phrases become increasingly valuable;
- route/fuel discipline improves because stragglers can report rather than forcing visual shepherding.

Do NOT create finger-four / Western pair tactics by decree.

The three-plane shotai remains the basic combat element.

## 9. Late 1940-1941 — procedure becomes training syllabus

By this point:
- the technology has been in military use for years;
- China combat has generated hundreds/thousands of mission repetitions;
- A6M long-range work creates strong incentives for reliable radio procedure.

Therefore first-line Navy fighter training plausibly standardizes:

### mission assembly
- common frequency;
- check-in;
- leader identification;
- rendezvous/rejoin point;
- fuel / abort conventions.

### combat control
- contact bearing;
- rough altitude band;
- target class;
- engage / hold / cover / rejoin / return;
- leader-to-shotai task assignment.

### escort
- escort commander / bomber leader coordination;
- handoff rules;
- "do not chase" / rejoin calls;
- damaged bomber / straggler protection decisions.

### CAP
- patrol sector / altitude intent;
- relief timing;
- reserve / ready aircraft;
- contact report to/from ship/field.

This is a **procedural doctrine evolution**.

It does not require ideological "mission command" reform.

## 10. Strategic radio silence remains

Better tactical radio does not abolish Japanese concern about emissions.

Separate:
- pre-operation / fleet-level radio silence;
- tactical airborne voice after launch/contact.

A strike may minimize transmissions before surprise is spent.

Once tactical contact begins:
- first-line units use voice because combat value is now well established.

Therefore Pearl-era "pre-X-hour transmissions minimized" remains compatible with a materially more radio-dependent tactical air doctrine.

## 11. 1941 carrier-air command state

Before shipborne radar becomes useful, carrier fighter direction can still improve through:

visual/picket/aircraft report
-> carrier air/plot watch
-> CAP leader
-> shotai leaders.

Functions possible:
- launch warning;
- broad bearing;
- estimated range/time;
- sector allocation;
- relief / reserve launch;
- recall / rejoin.

Functions still weak:
- exact altitude;
- continuous enemy track;
- continuous own-fighter track;
- individual-fighter vectoring;
- multi-carrier common tactical picture.

This is already more than "visual signals only" if tactical radio is reliable.

## 12. Dec1941-Apr1942 combat feedback

Pacific combat now adds a new feedback loop:
- Pearl mass-strike assembly/deconfliction;
- Enterprise counter-carrier contact;
- Wake / Coral Sea carrier-threat experience;
- radar introduction;
- repeated CAP / strike-recovery conflicts.

The likely immediate procedural responses are:
- clearer CAP leader designation;
- standardized raid bearing / altitude-band calls;
- explicit ready/relief fighter accounting;
- clearer "engage / remain high / cover low / return" task calls;
- tighter ship-to-air reporting discipline;
- better logging of last-known CAP sector/fuel state.

Type21-line radar in 1942 plugs into this existing organization.

Radar does NOT invent fighter direction from zero.

## 13. Spring 1942 carrier fighter-control architecture

Use a three-level chain.

### Level A — ship / carrier-cell plot
Inputs:
- Type21 where fitted;
- visual reports;
- screen reports;
- returning aircraft reports.

Output:
- raid bearing;
- rough range/time;
- rough altitude class if available;
- priority sector;
- launch/relief order.

### Level B — CAP leader / senior buntaicho
Receives the coarse picture.

Decides:
- which shotai intercepts;
- which remains high;
- which covers low;
- when to rejoin / disengage.

### Level C — shotai leader
Controls immediate combat element.

Once visual combat begins:
- local judgment dominates;
- ship control becomes intermittent.

This is not US 1942 radar fighter direction.
It is a radio-enabled Japanese command chain with coarse sensor input.

## 14. Actor-knowledge consequence

V26:67 remains mandatory.

The controller may know:
- "A6M section A is northeast/high";
- last report time;
- estimated fuel.

He does NOT know continuously:
- exact position;
- exact energy;
- exact fuel;
- exact enemy relation.

The difference from the prior model is:
**stale information can still be acted upon through a real procedural command chain.**

## 15. Carrier-to-carrier coordination

Do NOT grant a perfect fleet-wide CAP pool.

By spring 1942:
- common procedures/frequencies can permit local cross-carrier coordination;
- carrier divisions / tactical cells can pass raid information and request support;
- airborne leaders can redirect a nearby shotai if contact/radio conditions permit.

But:
- multi-carrier track fusion is incomplete;
- frequency congestion / radio silence / ship separation matter;
- fighter ownership and recovery deck remain practical constraints.

Use:
- local/cell-level coordination,
not:
- one omniscient Kido Butai fighter director.

## 16. Revised interpretation of worldline A6M communication gain

A6M improvement is now four-part:

1. **hardware reliability**
   - lower EMI / better installation.

2. **procedural reliability**
   - standardized calls / rejoin / abort / contact reporting.

3. **formation employment**
   - easier task split, cover, reserve, rejoin and staggered attack.

4. **coarse command integration**
   - plot/ship/field can pass a usable vector to CAP leader.

Do NOT turn this into a generic kill multiplier.

It changes:
- contact probability;
- number of fighters arriving with useful altitude;
- reserve preservation;
- duplicate pursuit;
- re-engagement;
- return/recovery losses;
- attacker cohesion.

## 17. What remains historically recognizable

No "thought reform."

Retain:
- aggressive offensive fighter culture;
- elite-pilot emphasis;
- three-plane shotai;
- strong pilot autonomy once engaged;
- tendency for combat to fragment;
- weak cross-service integration;
- imperfect radio discipline;
- strategic radio-silence concerns;
- limited carrier sensor picture.

The divergence is:
**the same culture learns to exploit a radio that actually works often enough to be worth building procedures around.**
