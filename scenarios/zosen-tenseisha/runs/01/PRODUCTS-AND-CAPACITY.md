# 第一走 — 商品船型と生産性の数値台帳

> **ALL DESIGN AND CAPACITY FIGURES BELOW ARE WORKING TARGETS, NOT VERIFIED HISTORICAL RESULTS.** 比較のため工程境界・年次・想定を固定する。史実は必要に応じ research/HISTORICAL-ANCHORS.md を参照。

## 1916年の加工・溶接鉄工所

職工30人、年間250日×10h、時間有効率70% = **52,500人時/年**。1916年型の「切断・穿孔・曲げ・小組立を終えた良品鋼材」工数60人時/鋼材t、改善型45人時/t。これは船台での大組立・接合や艤装を含む船殻120人時/tという別の仮定とは混ぜない。

1916年に割り振った仕事の仮例：

| 分野 | 工数配分 | 年間数量の仮定 | 注記 |
|---|---:|---:|---|
| 船殻用加工部材 | 42% | 368t | 22,050人時/60人時/t |
| 鋳鋼・鋳鉄部品の機械加工 | 25% | 105件 | 一件当たり125人時モデル |
| ウインチ・船具 | 15% | 21組 | 375人時モデル |
| 型板・治具・検査具 | 10% | 25組 | 210人時モデル |
| 修繕・現場作業 | 8% | 28件 | 150人時モデル |

上記は全職工30人の年間能力を一度だけ割り当てたモデル。会話に別途登場した溶接班6人・年間10,500人時、うち受注8,225人時という例は**この30人の内数**であり、表に単純加算してはいけない。受注別の旋盤・剪断・揚重機負荷はこの表には含まれていない。

1918年に職工60人を目指す仮定では全105,000有効人時/年。加工済み鋼材約980tは、工数45人時/t・配分42%を置いた場合の数値。旋盤2→4台、船殻切断・穿孔系統1→2系統などの増設・段取り改善がなければ実際の生産上限に届かない。

### 製造工数の進歩（別工程の試算）

船殻加工・船台組立・接合・検査等をまとめた仮モデル120人時/t（1915年型）→92（1918年目標）→74（1923年）→60（1928年）。これは史実の日本造船所平均値ではない。*上の加工専業60→45人時/tとは対象工程が違う*。

## 1924年 第一商品（仮称 400GT沿岸機械雑貨船）

| 仕様 | 初期設計目標 |
|---|---|
| GT | 約400（容積指標） |
| 垂線間長×幅×満載喫水 | 45.5m×8.1m×2.65m |
| 方形係数／海水密度 | Cb=0.68／1.025t/m³ |
| 満載排水量一次計算 | 約681t |
| 仮軽荷重量 | 241t |
| DWT | 約440t |
| 燃料・清水等50tを除いた貨物 | 約390t |
| 主機・速力目標 | 購入350～450PS級、8.5kn |
| 荷役 | 自荷役2～3tデリック×2、ウインチ |
| 造船所側総建造工数 | 初号船42,000人時程度の仮置き |
| 船殻鋼材と船殻工数 | 仮に160～180t×100人時/t=16,000～18,000人時（総工数の内数） |

注意：排水量一次計算だけではGTや貨物容積、復原性、所要主機出力は保証されない。Fullagar等の実船は技術水準の比較であり、主人公の船と同じ寸法・生産費とは限らない。

同型の船殻工程100→85→75人時/tは三隻を通じた研究目標。完成船総建造費の同率減少ではない。40,000人時台の完成船工数も同時代史料で検証すべき値。

## 1925～28年の二商品系列

- 甲型：約400GTの普通の標準貨物船。規格化、反復発注、加工・艤装工数低減が競争力。
- 乙型：約400～450GT、DWT410～430t、通常の貨物倉とデリックを保持し、船尾後部甲板に5～8t完成機械／運搬台込み10t級を入れる12m×2.5m程度のクォーターランプ。船体後部と支点、格納・係留・固縛は専用設計。天候・満載喫水・潮位・岸壁強度で使えない岸壁もある。貨物甲板の低い場所から機械室・主倉への自由通行は保証しない。
- 乙型の船価+5～10%という値は価格感度の仮説であり売買記録ではない。積載量減や港で回避できる重量物クレーン費用を比較して初めて商売上の優位を評価できる。

1927年頃の単船建造工数の仮比較：成熟甲型34,000人時、乙型初号船43,000人時。職工100人×年間1,400有効人時×新造船へ60%=84,000人時なら、甲乙各一隻の合計77,000人時は**労働時間の総量として**成立する。船台・艤装岸壁・揚重機・受注・主機納期の証明にはならない。

## 1933～35年 香焼A26型（2,600GT級）

| 項目 | WORKING目標 |
|---|---|
| 総トン数 | 約2,600GT |
| 載貨重量 | 約3,000DWT |
| Lpp×B×喫水、Cb | 90m×13.4m×5.5m、0.70 |
| 満載排水量の一次計算 | 約4,760t |
| 軽荷重量仮定 | 約1,760t |
| 実貨物目標 | 約2,700～2,800t（DWTから燃料・水等を控除） |
| 主機 | 購入した約1,200～1,500PS級直結ディーゼル（仮） |
| 速力 | 11～12kn（抵抗・機関出力計算未実施） |
| 貨物設備 | 5t級の船載デリック群／自社製ウインチ |
| 構造 | 鋲接・溶接併用、工場小組立・先行艤装を優先 |

**監査上の大問題:** 90m級・排水約4,760t・11～12knに対して1,200～1,500PSが足りるかは未検証。単純な寸法整合だけで主機出力を確定しない。第一走ではあくまで商品企画目標。

1935年のA26一隻230,000人時、1937年185,000人時は生産工数の研究目標で、対象は自社・協力工場側の工程（購入主機の製造工数は除外）。会社人数がそのまま新造船工員とは限らない。

### 1935～37年の能力感度モデル

| | 1935模型 | 1937計画模型 |
|---|---:|---:|
| 全製造職工 | 450 | 700 |
| 有効時間/人/年 | 1,400 | 1,400 |
| 新造船配分率 | 55% | 60% |
| 新造船に使える年間人時 | 346,500 | 588,000 |
| A26換算1隻当たり人時 | 230,000 | 185,000 |
| 人時上限による隻数 | 1.51 | 3.18 |

あくまで仮想工数と配分が生む算術上の上限。年間の実際の進水・引渡し数量、全社人数、社外工の人員・費用などは別途設定する。1937年の3.18隻は実績ではない。

## 優位性の測り方

船台占有日数、完成船一隻当たりの総工数、外注工数、鋼材歩留まり、検査不合格、変形・手直し、設計変更、海上試運転の出来、船価、保証修理、船主側の実輸送能力を**同時に記録**。初号船の特殊投入を隠さず、二号・三号船で再現できたときに初めて「造船所の地力」と呼ぶ。
