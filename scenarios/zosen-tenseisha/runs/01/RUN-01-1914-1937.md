# 第一走 Run 01 — 溶接鉄工所から香焼島の標準船建造へ

**STATUS: USER-ACCEPTED WORKING SCENARIO, 2026-10-15.** これは「今回の第一走」であって、全走共通の歴史でも、1937年以降の戦況を確定した記録でもない。採用された方向性と助手の詳細仮案は区別する。

## 物語の中心

1890年生まれの未来知識を持つ日本人技術経営者。1910年代の第一次大戦景気から、財閥子会社ではない独立の溶接・鉄工技術会社を育てる。未来の鋼や巨大工場をいきなり持たず、**当時の購入鋼材・溶接機・被覆棒・工作機械でも、品質と工数で勝てる**市場を選ぶ。事業で蓄積した資本・職人・試験実績を使って小型商船へ進み、1927年と1930～31年の恐慌を活用して長崎香焼島の旧松尾造船所系施設を再建、1930年代半ばに2,600GT級商船の反復建造を実現する。

ユーザーが積極的に採用した核心：初期施工・生産性が強み、材料と船そのものの独自設計は後から進む。新造・修繕・機械製作の多角化は、不況対策であると同時に未来の重工業能力を育てる。

## 第一期：1911～1918年、好況下での技術事業化

- **1911～13（PROPOSED）:** 工業学校等で機械・造船を学び、既存の鉄工所・機械／鋳造工場へ入る。大阪圏の既存設備を使い、加工と修理の現場を理解する。就学先・職歴は未確定。
- **1914～15（WORKING）:** 既存工場の一角で治具、図面、検査、材料仕分け、補修の標準化に取り組む。アーク溶接・ガス切断の研究。購入した既存被覆棒／輸入溶接機等を選択する。1914年に被覆棒を独自に発明したわけではない。
- **1916（WORKING）:** 約30人の加工・製作部門を運営。鋳鋼の巣埋め・機械部品補修、架台・ブラケット・タンク・船具、加工済み船殻部材、治具・工具を受注。高品質の施工、下処理、検査、工場内の労働分担を商品化。「潮溜まりの覇者」で十分。
- **1917～18（WORKING）:** 約60人級へ成長。高精度な鋼板・形鋼の加工、前組立、溶接製作、船舶機械・ウインチ・修繕を反復受注。購入芯線を用いた自社被覆剤の研究とロット管理は研究品／限定販売の可能性。どの特許・権利のもとで売るかはOPEN。
- **1917～19（WORKING）:** 自社管理の技術部門から独立会社へ発展。最初から大規模な高炉や船台を保有したわけではない。親工場と継続的な請負関係を残し、実質的な経営自主性、知的財産、技術者の採用権を確保する。

商売の勝ち筋は「溶接棒が未来的」よりも、切断・開先・予熱・施工・機械加工・水密／寸法試験をまとめて納め、再鋳造や現場合わせを減らすこと。造船所の鋼材支給を受けた加工賃契約は、1916～18年の鋼材逼迫への対処に適する。

## 第二期：1919～1924年、試作から初めての商船へ

- **1919～21（WORKING）:** 大戦後の造船不況を見て、大阪湾の休止工場・小型船台を買収・賃借。浪華造船所のような史実の休止例を候補に置くが、特定資産の権利移転は未確定。修繕、船具・機械、一般産業の鉄構物で事業を維持。
- **1920～23（WORKING）:** 鋼製艀・小型作業船を建造して、溶接部材だけでなく船台での組立、水密、船体変形、進水、軸系・配管・艤装を検証。鋼線／被覆と材料試験を段階改良。小型電炉または提携製鋼所で材料研究を開始。
- **1923～24（WORKING）:** 初めての反復販売商品として400GT級の沿岸機械雑貨船。自荷役用デリック・ウインチは備えるが、本格20tランプは標準装備しない。普通に運航でき、低工数で造り、修理可能な鋼製商船を目指す。外部主機メーカーから完成機を購入。
- **1924～26（WORKING）:** 同型二・三番船で製造改善を検証。真の地力は初号船の誇張された進水速度ではなく、全工数と手直しの削減、担当班変更時の再現性、完成船の信頼性に求める。

## 第三期：1925～1931年、二系列と恐慌の戦略

- **1925～28（WORKING）:** 標準400GT級貨物船「甲型」で反復建造・原価低減。機械輸送兼用船「乙型」は同じ基礎船型を使うが後部甲板を専用補強し、通常岸壁用の斜めランプを研究。最初は5～8t程度の機械に限定。機械輸送用の特殊船は一般貨物船の販売を妨げない独立派生商品。
- **1926～27（WORKING）:** 昭和金融恐慌の前に支払資金と複数決済銀行、材料・主機の前払い管理を整備。1927年の信用収縮を生き残って、機械・工場・造船人材を取得する機会を得る。
- **1927（PROPOSED acquisition adopted as scenario direction）:** 長崎の旧松尾造船所・香焼島の史実上の再建構想へ参加する分岐。全面的な負債救済合併ではなく、資産の権利整理・取得予約／長期賃借・段階的な工場資産取得を模索。史実の再建が失敗したことと、第一走で交渉を成功させることは異なる。
- **1927～29（PROPOSED）:** 鳥羽の造船・起重機部門整理から人材と機械を得る交渉、電機部門との提携。大造船所播磨そのものの買収は対象外。大阪・瀬戸内圏の修繕拠点や旧浪華施設も個別候補。
- **1930～31（WORKING）:** 世界恐慌と金解禁後の日本の昭和恐慌。新造船需要だけに依存せず、船舶修繕、舶用機械の再生、工場設備改造、荷役機械の製作、製缶・鉄構へ生産配分。1931年12月以降の円安を意識し、輸入精密工作機械を早めに確保する選択肢を持つ。

## 第四期：1932～1935年、香焼島のA26反復建造

- **1928～32（WORKING）:** 香焼島では修繕船渠／機械工場を優先再開。古い建物・船台をそのまま復活させず、材料受入→切断→曲げ→小組立→先行艤装→船台→岸壁試験の流れに再配置する。大阪は特殊機械・被覆棒・試験・ウインチ、長崎は大型船殻・完成船が主。
- **1932～33（PROPOSED）:** 800～1,500GT級による大型化工程の検証、他造船所向け大型部材の供給。1932年の船舶改善助成制度は4,000GT級以上の特定新船を対象とするため、この会社が2,600GT型で直接助成金を受ける前提にはしない。
- **1933～35（WORKING）:** 「香焼標準貨物船A26型」約2,600GT・DWT約3,000t・11～12kt目標を反復建造。主機は購入した1,200～1,500PS程度の低速直結ディーゼルを本命とし、船内の配管、タンク、機械台、荷役機械と工場の小組立を統合。主要縦通継手には必要に応じ鋲接を残し、全溶接船の記録競争は狙わない。
- **1935（暫定到達点）:** 大阪に材料・機械・溶接の開発と製造、長崎に数千GT級の商船建造能力を持つ独立重工業会社。A26の実際の建造隻数・利益・溶接率はOPEN。自動溶接の特定長継手での工業化はまだ研究／部分実用化目標。

## 次回への1936～37年構想（未実行）

1936年に部材番号・配管・治具・検査・工場内組立・職人教育と鋼材・主機・電機の複数調達を磨く。1937年7月の支那事変に伴う船腹需要変化は史実として見通すが、この世界線での採用、徴傭、建造契約、輸送成果や戦争の進行はまだ決めていない。

見込み事業は (a) 標準商船の短期建造、(b) 既存船の修繕・改造、(c) ウインチ・機械・特殊荷役装置。1937年に向けたスパートは、1935年までの技術群が相互に増幅する企業内能力を意味する。
