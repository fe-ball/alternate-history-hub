## 主題

1890年生まれの未来知識を持つ技術経営者が、1910年代の日本で**独立資本の小規模鉄工・溶接製作**から事業を始め、修繕・機械加工・材料試験・反復造船を通じて、1930年代には商船を効率よく建造する中堅重工業会社へ育つ仮想歴史。船の性能向上と製造生産性は別々に検証する。単一のチート装置でなく、既存工業技術の合理的な結合、累積した実地試験、人材と調達網の強化を重視。
