# 豊国IFの固有ルール

権威順は v3 → v3と矛盾しない執筆規律 → 明示的採用の記録 → 派生叙述・検討資料。
ファイル名の最大番号、更新日時、書かれた年代の遅さだけで正典を変更しない。

- 能動的な分岐は豊臣秀吉の寿命が史実より5年長いこと。老年期の健康の差として前から効き、1598年に突然5年追加されるという意味ではない。1603年の死を基本線とする。
- 登場人物に未来知識・史実比較の知識はない。史観の宣言と実証済みの史実を分ける。
- 講和は割譲なしの庚子約条。倭城・付帯地・警固権の解釈による実効支配と、領土割譲は同義ではない。
- 旧雑考・各国表の採否は参考提言集の項目別状態を確認する。旧稿の南部諸道領有・割譲を復活させない。
- 検討メモの幅付き推計、艦船の技術修正、未採用案は提案のまま保持する。
- 編年・解説に架空の史料引用や決め台詞を足さない。説明用の便宜語を作中の固有用語にしない。
- 敗北、赤字、反乱、機会費用、資源・船員・木材の限界を消さない。

この文書は回収資料の読み方を整理したもので、新しい物語上の採用決定ではない。
