# 豊国IF検討メモ――戦後貿易・利権構造の経済規模試算(慶長六〜八年/一六〇一〜〇三頃)

本メモは庚子約条(1600)成立後、通商と利権の構造が確定して流れ始めた数年後――秀吉存命の最終期――における利益量の試算である。数字はすべて幅で示す。実在の史料・研究に基づく数値(アンカー)と、この世界線のための仮定を区別して記す。ハンドオフ第6項に従い、断定的に見える箇所も最蓋然性の提示にすぎない。

## 一、表の貿易――寧波勘合の規模

**制度の仮定。** 明側の統制上、直航は港(寧波)・時期・隻数を限定した形になる。ここでは日本発の勘合船年8〜12隻に、明側商人の対日渡航若干を加えた双方向年10〜20隻規模を仮定する。歴史上の室町勘合(十年三隻)では政治的に意味をなさないため、実態としては月港(漳州)の引き数制度に近い「隻数管理された民間交易」へ滑っていくと考えるのが自然である。1567年の月港開港が対日直航だけは禁じ続けたことを踏まえれば、この条約は「東アジア貿易最後の禁制品=日本航路」の解禁であり、既存の全流通構造に対する再配分効果が極めて大きい。

**輸入(日本側買付)。** 主力は白糸。戦後の景気と朝鮮在番・普請需要を上乗せし、開始2〜3年で年2,000〜3,000担(買付18〜27万両)。これに絹織物・薬種・砂糖・書籍・雑貨で同額弱を加え、買付総額は年40〜70万両。

**日本国内での売上と粗利。** 売上65〜110万両、日本側商人・元締めの粗利は25〜45万両(銀2,500〜4,500貫)。ポルトガル船が独占していた50〜100%の中継マージンの大半が、この枠組みの内側へ移転した勘定である。

**輸出と決済。** 銅・硫黄・刀剣・漆器・扇などの商品輸出は5〜10万両にとどまり、差額は銀で決済される。合法経路の銀流出は年25〜40トン。国産銀の産出増(佐渡は1601年に本格化)がこれを支える。

## 二、傘の下――統制下違法貿易の機構と規模

許可貿易の最大の副産物は、違法貿易のリスク構造の激変である。機構を分けて示す。

1. **積荷の過少申告・附搭。** 勘合船の公式積荷の外側に載る私荷。貢舶制度の伝統的な運用そのものであり、明側の現地官憲も慣例的な手数料(陋規)で組み込まれる。
2. **沖合・外港での瀬取り。** 舟山群島周辺での洋上取引。かつての双嶼のような非公認集散地が、今度は「勘合船の風待ち・修理」という口実の傘の下で再生する。
3. **倭城・対馬・五島への「漂着」交易。** 福建・浙江の商船が修理や避難を名目に日本側拠点へ入る形。倭城網が合法的に存在すること自体が、受け入れ側の港湾を摘発不能にする。
4. **保険料率の低下による量の拡大。** 日本船の海上での存在が条約で正当化されたため、拿捕リスクが崩落し、抛銀利率は一航海35〜60%から20〜35%へ低下しうる。リスクプレミアムの低下は、それ自体が取引量を膨らませる。
5. **金銀比価の裁定。** 金銀比価は中国でおよそ1:7〜8、日本で1:11〜12。銀を持ち込み金を持ち出す往復で、経費差引前40〜60%の裁定余地がある。金の入手量に制約されるため量は限られるが、利幅が厚いため必ず発生する。

**規模の見立て。** 類似制度(マニラの登録外銀、月港の引き数又貸し)では、非公式フローが公式の0.5〜3倍に達するのが通例である。開始数年のここでは、公式寧波貿易の0.5〜1.0倍、すなわちフロー20〜40万両・銀流出換算10〜25トンを見込む。日本側政権の対応は摘発ではなく、湊役・見逃し料の形での非公式課税による包摂(元倭寇系の海商網を引数の受け皿にする、v3のいう元締め化)であり、そこからの中枢の取り分は年1〜3万両程度と小さいが、統制の対価として機能する。

## 三、南方・琉球・南蛮船の再配分

**朱印船。** 条約と同時期の再開により、1603年時点で年8〜12隻。銀持出し8〜15トン、粗利回り一航海40〜70%で、粗利総額10〜20万両。朱印料と船株運上として中枢に1〜2万両。

**琉球口。** 兵を入れない資本浸透の初期であり、フローは年1〜3万両にとどまる。

**ポルトガル船。** 寧波開港はマカオ中継の存在理由を直撃する。定航船の積荷は生糸主体から欧州・インド産品と砂糖へ縮み、売上は従来の50〜100万両から20〜30万両級へ、銀持ち帰りは10トン未満へ落ちる。v3が述べる「南蛮中継利権の減殺」の数量的な姿はこれである。

## 四、朝鮮方面利権の初期実態――「利権」の中身の解剖

朝鮮方面は、利権と一括される割に、この時点では現金を生まない。構成要素ごとに見る。

**付帯地の収取。** 十八城の付帯地の名目的な収穫potentialを合計しても数万石規模であり、耕地崩落(結数で戦前の三分の一以下)と労働力流出のため実収はその2〜5割、年1〜3万石程度。しかもほぼ全量が在番の兵糧として現地消費され、域外に出る余剰はない。初期数年は本土からの補給が逆に必要である。

**在番と城郭維持の費用。** 平時在番を1.5万人規模とすると、兵糧・扶持・修繕で年10万石相当以上の負担となる。銀換算でおよそ3,000〜6,000貫。大半は在番大名の軍役として分散負担され、中枢の現金持ち出しは年1,000〜2,000貫に圧縮されるが、地域収支としては明確な赤字である。これは初期植民拠点の通例であり、鉱山を持たない交易拠点型の海外領は本国送金か貿易レントで赤字を埋めるのが同時代の標準形である(フィリピンのスィトゥアードが典型)。この世界の倭城網にとってのスィトゥアードが、寧波貿易の利である。

**釜山開市。** 朝鮮は銀をほとんど持たず、木綿布を通貨代わりとする低貨幣化経済である。取引は人参・木綿・皮革・雑穀の対価に日本側の銭・鉄器・塩・南方物産を渡す物々交換に近い形で始まり、フロー総額は年5〜15万両程度。うち人参は量こそ小さいが利幅が厚く、後年の主力候補である。

**最初に現金化する利権は調達である。** 在番1.5万人への補給は年10万石規模の購買フローであり、その買付差配・回漕・払方を握る在番大名と御用商人の物流マージンこそ、朝鮮利権で最初にまとまった現金を生む部分になる。開市の場銭・津料、付帯地代官の手数料がこれに続く。

**信用浸透は所得でなく資産形成。** 復興資金の貸付(月利3〜5%)と質流れの集積は、年々の現金収益としては小さい。回収されるのは銭でなく田畠の担保権であり、利益は将来の付帯地拡大として簿外に積み上がる。裁許一件ごとの管轄の固定化も同様に、収益でなく資本の蓄積である。

**銭の浸透。** 慶長通宝の半島流通は鋳造益(額面と地金・工賃の差)を生むが、通貨をほとんど受け付けてこなかった経済への浸透は開市圏と付帯地周辺から徐々にしか進まず、この時点の鋳造益は無視しうる規模である。意味は収益でなく、決済単位を握ることにある。

**小括。** 慶長六〜八年の朝鮮方面は、年数千貫の持ち出しを続ける費用センターであり、同時に、調達マージン・担保権・裁判管轄・決済単位という四種の資本が積み上がる投資局面である。「利権知行」の初期の実質は、現在収益の分配というより、これら将来収益に対する持ち分の割当に近い。堺・長崎で船株や在番役得の相場が立つのは、市場がこの将来性を資本化しているためで、同年に生まれるVOC株の値付けと同型の現象である。

**当時基準での読み方。** 銀8,500貫の粗利は米15万石強の購買力に相当し、可処分ベースで見れば20〜40万石級大名の実収入に匹敵する経済圏が、戦後2〜3年で貿易部門として立ち上がった勘定になる。中枢の実質取り分800〜2,000貫は米1.5〜3.6万石相当で、200万石超の蔵入地収入に対する上乗せは数%にとどまる。恩賞需要(七年の役の動員十数万)に対してこの原資は明白に薄く、慶長六年の襲撃未遂と利権知行制度化の急がれ方は、この薄さの帰結として整合する。

**現代的指標での読み方。** 銀流出45〜80トン/年は当時の世界銀産出の1〜2割弱、マニラガレオンの登録銀(約200万ペソ=50トン)と同水準である。中枢取り分8〜20万両は30〜75万ペソ、すなわちスィトゥアード1〜3年分に相当し、明の太倉歳入(400万両)の2〜5%、明が朝鮮の役に投じた戦費(700〜1,000万両)の百分の一強にすぎない。明にとって、年百万両単位の駐留費を捨てて日本にこの程度のレントを許す講和が財政的に合理であったことも、この比率から読める。

**総流出量が史実と大差ない点について。** 合計の銀流出45〜80トンは史実の同時期(50〜80トン)とほぼ重なる。これは意図的な見立てである。銀の総フローは中国側の吸収力と日本の鉱山産出に律速されるため、条約が短期で変えるのは総量ではなく経路と利ざやの帰属である。マージンがポルトガル船と非統制の密貿易から、日本の統制下の複合体へ移転する。総量が動くのは佐渡・石見の増産が効いてくる1610年前後からで、そこからは年100〜150トン水準への拡大が見込める。

## 六、補論――商人型家臣団と船手大名を織り込んだ修正

第五節までの試算は政権を単体の徴税者として扱っており、「銀流出総量は史実と大差ない」という結論は、(一)産出銀の輸出比率が一定、(二)産出曲線が史実通り、(三)稼ぎを銀の純流出で測る、という三つの暗黙の仮定に依存していた。豊臣家臣団の商業的性格と船手大名(旧海賊衆)を織り込むと、三仮定はいずれも崩れる。

**退蔵から輸出への振替。** 国内の銀には退蔵・装飾・大判・国内流通という競合用途があり、産出の相当部分は史実では国内に留まった。拿捕リスク低下で一航海20〜35%まで下がった投資利回りに、奉行衆と堺・博多の商人網(島井・神屋・角倉ら。この世界では堺薬種商出身の小西行長も健在で在朝の要職にある)が抛銀と船株を通じて小口資本を束ねて流し込むと、退蔵の機会費用が上がり、同じ産出量でも輸出に回る比率が一〜二割上振れる。年10〜25トンの上乗せに相当する。

**産出曲線の前倒し。** 貿易利益の鉱山再投資である。銀の対中国購買力プレミアムが恒常化すれば、山師融資・探鉱・排水普請・精錬(南蛮絞りは1591年に確立済み)への資本流入が史実より早く厚くなる。佐渡(1601)・院内級の開発が資本制約なしに進むなら、史実で1620〜30年代に来る産出ピークは10年程度前倒しされうる。1610年頃の産出は史実比プラス三〜五割の幅を見込む。

**船手大名の警固レント。** 1588年の海賊停止令は海賊衆の廃絶ではなく海上暴力の政権独占化であり、朝鮮の役はこの集団を俸給付きの職業海軍に鍛えた。史実の平和はこれを座礁させた(来島氏の内陸転封が象徴)が、この世界では庚子約条の倭寇対策名分が、対価を取れる正規業務を生む。船団護衛料、倭城・対馬・五島の津料、瀬戸内の過所船旗の先例を東シナ海へ拡大した唐船向け通行手形の発行である。年百帆規模のジャンク交通に対し年2〜6万両程度と、銀量としては小さいが、非加盟の密貿易を傘の中へ誘導する執行機構として働き、第二節で0.5〜1.0倍と置いた傘下非公式フローを1.0〜1.5倍かつ半ば財政化された形へ押し上げる。停止令との整合は、私的海賊の復活ではなく免許代理人化、すなわち同じ独占の外洋への投射として取れる。

**純流出という物差しの限界。** 商人国家の稼ぎは往復の両方に乗る。日本船による中国〜南方間の運送賃、中継マージン、警固料は銀流出に現れない経常収入であり、マニラ向け航路は史実でも日本側が糧食・鉄などを売って銀を受け取る流入側の航路であった。船手・商人網の拡大はこのサービス収支を十年で年5〜15万両規模まで育てうる。

**抑えとして働くもの。** 生糸の短期供給弾力性(買付急増は産地価格を押し上げ利ざやを圧縮する)、明側の警戒による公式枠の政治的上限、大型船体・船員・水先人の育成に要する年数、そして政権自身の貴金属流出への警戒である。流出の加速は中国沿岸の銀安と価格攪乱を史実より早く呼び込む点で、後年の問題の前倒しでもある。

**修正後の見立て。** 1603年時点の総流出は55〜95トン(第五節の幅から上限が伸びる)、効果が本格化する1608〜10年頃には90〜140トンに加えてサービス収支が乗る。短期の水準爆発ではなく、成長曲線の前倒しと、銀流出に映らない収入層の追加として現れる。政治経済的な帰結として、九鬼・藤堂・脇坂・加藤嘉明・松浦・五島・宗・島津に堺・博多資本を加えた、海のレントに収入を依存する利益集団が1600年代を通じて形成され、1609年の呂宋仕置は、能力と動機を備えたこの集団の事業として説明可能になる。

## 七、留保

隻数管理の形態、寧波での買付価格、非公式フローの倍率、在番規模は本メモの仮定であり、幅の上下いずれの経路もありうる。補論の輸出比率上振れ・産出前倒し・通行手形収入も同様に仮定であり、とりわけ産出前倒しの幅は探鉱の当たり外れという偶然に大きく依存する。生糸価格・銀輸出総量・明財政・結数崩落・抛銀利率・スィトゥアードは実史アンカーである。朝鮮側収支は最も不確実で、復興速度と付帯地の運用方針(直営か請負か)次第で赤字幅は倍半分動く。また本メモは秀吉存命期を中心に据えており、マニラ役以後(1610〜)の構造変化は含まない。
