# 豊国IF検討メモ――系譜三代の行動圏と交戦の見通し

「この船はどこまで行けるのか」を、水と兵糧、船型、季節の三つから詰める。超型については腐食を考慮せず、設計時と試験航海後の目算として扱う。

---

## 一、航続を決めるのは水である

**消費。** 一人一日の飲料水は温帯の平時でおよそ三リットル、夏場や漕走の続く日には五リットルに達する。一代目の総員三百五十人なら日に一.〇〜一.八トン、超型の五百人なら一.五〜二.五トンになる。

**兵糧は問題にならない。** 一人一日五合として、三百五十人三十日で五十二石、重量にして約八トン。水の三分の一以下であり、しかも腐らない。

**積める水の量。** 排水量の五〜八%を水に割くのが現実的な上限で、四百トン級なら二十〜三十トン、七百トン級なら三十五〜五十トン。これだけ見れば二十日から二十五日分になる。

**ただし樽の水は保たない。** 木樽の水は二〜三週間で濁り、それ以上は飲めるが飲みたくないものになる。したがって**実効の無補給行動は二十日前後が天井**であり、積載量ではなく水質が縛る。実務上は十日から二週間ごとに水を補給する運用になる。

**この一点が、この艦種の性格をほぼ決めている。** 巡航しない、出撃する、という前メモの結論は、ここから機械的に導かれる。

## 二、距離の換算

帆走での日進は、開けた海で六十〜九十海里、瀬戸内のように潮待ちと夜泊が入る水域で二十〜四十海里。参考として主な区間の概算距離を挙げる。

| 区間 | 概算距離 | 帆走所要 |
|---|---|---|
| 大坂→下関(瀬戸内航程) | 約300海里 | 10〜15日 |
| 下関→対馬 | 約90海里 | 2〜3日 |
| 対馬→釜山 | 約30海里 | 1日 |
| 博多→釜山 | 約110海里 | 2〜3日 |
| 下関→朝鮮南岸(順天方面) | 約220海里 | 4〜6日 |
| 長崎→済州 | 約120海里 | 2〜3日 |
| 長崎→那覇 | 約450海里 | 7〜10日 |
| 長崎→寧波 | 約450海里 | 7〜10日 |
| 那覇→台湾北端 | 約350海里 | 6〜8日 |
| 長崎→マニラ | 約1,500海里 | 25〜35日 |
| 大坂→松前(日本海回り) | 約700海里 | 15〜20日 |

**注意すべきは瀬戸内の遅さである。** 大坂から下関までに十日から十五日、すなわち水の在庫の半分以上を国内で使ってしまう。**大坂の一番艦は、水を継がずに朝鮮へ届く船ではない。**下関・博多・対馬で継いで初めて戦場に立てる。前メモで基地を西へ置くべきとした理由が、ここで数字になる。

## 三、世代別の行動圏

### 一代目(安宅丸級。排水量350〜500トン、総員300〜380)

**無補給の出撃半径は三百〜四百五十海里。**往路六日、現地五日、復路六日に予備を見る勘定である。

- **下関・博多を拠点とすれば。** 朝鮮南岸の全域、対馬、壱岐、五島、済州。倭城網のどこへでも出て戻れる。庚子約条体制の守備範囲とほぼ一致する。
- **大坂を拠点とすれば。** 瀬戸内全域、紀伊水道、豊後水道まで。九州西岸へ出るには途中で水を継ぐ必要がある。
- **外洋は想定外。** 玄界灘と対馬海峡が実用上の外縁になる。低い乾舷と高い総矢倉という組み合わせは外洋の大うねりに向かず、設計時にもそこは求められていない。

**要するに、海峡の船である。**

### 二代目(超型。排水量600〜800トン、総員450〜550、砲20〜28門)

腐食を措いて見れば、この船の性能向上は明白である。ただし**航続はほとんど伸びない。**船が大きくなった分だけ人も増えるため、水の日消費が比例して増え、無補給行動は二十日前後のまま動かない。

**伸びるのは凌波性と航洋性である。**船体が深く、乾舷が上がり、隔壁で締まっている。冬の玄界灘に出られる日が増え、済州以南の外洋航行が現実の選択肢になる。設計者の目算としては、次のあたりまでを射程に置くことになるだろう。

- **南。** 那覇まで七〜十日。琉球は補給地として使えるため、そこから先の台湾北端も届く。
- **西。** 寧波まで七〜十日。勘合船の護衛、あるいは示威としての入港。
- **北。** 日本海回りで松前まで。蝦夷への関心が高まる時期と重なる。

**つまり超型の行動圏は、東シナ海をほぼ覆う。**釜山、済州、那覇、寧波、長崎――これは庚子約条体制の政治地図そのものであり、船の届く範囲と条約の及ぶ範囲が一致する。設計の狙いがそこにあったと読むこともできるし、結果としてそうなったと読むこともできる。

**呂宋まで届くか。** 計算だけならば届く。漕ぎ手を陸に置いて総員を百五十人程度に落とせば、水の日消費は〇.五トンを切り、四十トンの水で八十日分になる。だが、これは艪走軍船を帆走商船として使うということであり、船型は台風期の南シナ海に向かない。**紙の上では届くが、進んでやりたがる者はいない**という位置づけが正確だろう。試験航海の後に「南へも行けます」と報告書に書かれ、誰も実行しない、という形が自然である。

### 三代目(改級。排水量450〜600トン、総員400〜480)

船体は縮むが、**行動圏はむしろ広がる。**理由は水である。

前メモで挙げた銅の水槽をこの世代に載せるなら、樽の水が二〜三週間で濁るという制約が外れる。同じ積載量で**四十日から六十日**の無補給行動が可能になり、二十日の天井を超える。船が小さくなったのに遠くへ行けるという逆転が起きる。

- 東シナ海の全域を、途中で水を継がずに往復できる。
- 呂宋までの片道が、無理のない計算に収まる。船型の制約は残るため実施は季節を選ぶが、超型のときのような「紙の上だけ」ではなくなる。
- 漕ぎ手比が改善しているため、現場での動きは三代のうち最も良い。

**この世代で初めて、艦種としての完成を見る。**もっとも、当事者にとっては「腐らない釘に変えたついでに水槽を銅で作ってみたら、思いのほか水が保った」という程度の発見であり、行動圏が広がったことに気づくのはしばらく後になる。

## 四、季節――年の半分は動けない

行動圏は季節で大きく削られる。

- **十一月から三月。**北西の季節風が強い。低乾舷で総矢倉を高く構えた船にとって、冬の玄界灘と日本海は危険である。この期間は事実上、瀬戸内と内海に閉じ込められる。
- **七月から十月。**台風期。外洋はもとより、九州西岸・朝鮮南岸でも安全でない日が増える。
- **実用の季節は三月から六月と、九月から十月。**年のおよそ半分である。

これは七年の役の作戦期がおおむねこの窓に収まっていたことと一致する。そして水主を季節ごとに雇うという運用(補論二)は、この季節性と正確に噛み合う。**動けない季節に漕ぎ手を養う理由がない。**費用の話と季節の話が、ここで一本になる。

## 五、何と戦えるか

行動圏と並んで、相手別の見通しを整理しておく。

| 相手 | 見通し |
|---|---|
| 板屋船・唐船・ジャンク | 圧倒する。砲力、船体、接舷戦のいずれでも上回る |
| 小型帆船・私掠船 | 捕捉できれば勝つ。ただし追跡はできず、逃げられる |
| 中型ガレオン(500トン級、20〜30門) | 条件次第。風のある外洋では機動と砲力で劣り、不利。凪と沿岸と接舷戦の間合いでは有利 |
| 大型ガレオン、後年の戦列艦 | 勝てない。砲力と船体の頑丈さで及ばない |
| 艦隊戦 | 単独では成立しない。味方の帆走艦と組み、艪走の利く場面を作られて初めて働く |

**総じて、「風のない内海では勝ち、風のある外洋では負ける」船である。**これは欠陥ではなく設計の帰結で、その内海こそが日本の守るべき海だという前提が成り立つ限り、選択は正しい。前提が崩れるのは、戦場が外洋に移ったときである。

## 六、この数字が制度に返ってくるところ

- **倭城の兵糧定数。**無補給二十日という制約は、来援艦隊が現地で水を継げることを前提にしている。すなわち倭城は籠城のためだけでなく、**来援を迎えたときに水と兵糧を出せる湊**でなければならない。定数の設計に、籠城分に加えて来援分の上乗せが要る。
- **拠点の配置。**下関・博多・対馬に水と食糧の置き場を持つことが、艦の性能を伸ばすのと同じ効果を持つ。船を大きくするより安い。
- **季節の運用。**動員、船揃え、修理はいずれも冬に寄せられる。年間の行政の周期がここから決まる。
- **呂宋との断絶。**この艦種は南方には行かない。呂宋方面の海軍は別に要る。艦隊が二つに割れるという前メモの指摘が、航続の数字からも裏づけられる。

## 七、留保

一人一日三〜五リットル、樽の水が二〜三週間という数字は同時代の航海一般からの推定であり、日本の軍船の実務についての直接の典拠を持たない。排水量の五〜八%を水に充てるという配分も仮定である。日進距離は帆装の詳細に依存し、混成帆装の性能は本メモの推定の域を出ない。

区間距離は概算であり、実航程は水路と潮による。瀬戸内の十〜十五日は潮待ちと夜泊を織り込んだ保守的な見積りで、条件が良ければ短縮する。

三代目に銅の水槽を載せるという想定は前メモの提案の延長であり、これを採らなければ三代目の行動圏は二代目と大差ないものになる。採否は主作成者の判断による。

交戦の見通しは、砲数と船体の比較からの定性的な推論であり、実際には砲の口径、砲手の練度、海況、指揮の巧拙が結果を左右する。とりわけ中型ガレオンとの優劣は条件に依存する幅が大きく、表の記述以上に不確定であると考えるべきである。
