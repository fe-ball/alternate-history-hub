# 豊国IF検討メモ――サイズ感の比較と、見え方

系譜三代を同時代の諸船と並べ、寸法の実感を整理する。あわせて、指摘のあった明清交代期の沿岸島嶼戦への出動可能性を短く検討する。

寸法は間(六尺=約一.八二メートル)を併記する。当事者の語彙で言えば長さは間で数えられる。

## 二、読み取れること

**(一)長さでは驚かれない。幅で勝つ。**一代目は全長四十〜四十八メートル、大安宅船の大きいものと同程度である。ところが幅は十〜十二メートルあり、長さと幅の比は四対一前後になる。地中海のガレーが八対一、ガレアスでも五対一強であることを思えば、**日本の軍船は短くて太い**。平底和船の伝統と、接舷戦のために甲板面積すなわち兵員数が要るという要求の両方から来る形である。

**(二)見た目より重い。**幅が広く、外板が厚く、総矢倉が載り、船底に銅が回る。だから同じ全長の大安宅船に対して排水量は一.五倍から二倍になる。**外から見た印象はさほど変わらないのに、中身は倍近く重い。**

**(三)違いは全部、水面下にある。**平底の和船と板屋船は喫水一〜一.五メートル。キールを入れた一代目は二.五〜三.五メートルで、倍以上深い。この一点から、浜に上げられない(ゆえに銅を張る)、入れる湊が減る、波に強くなる、という帰結がすべて出る。そして喫水は岸から見えない。

在来の水軍が安宅丸級を「豪華軍船の系譜の最新作」としか見ない(補論二)理由も、ここで説明がつく。**上構えは安宅船のままで、変わったのは水面下だから**である。乗って初めて違いが分かる船を、乗らない者は評価しない。

**(四)千石船との対比が最も雄弁である。**弁才船の千石積は排水量二百五十〜三百トンを十五〜十八人で運ぶ。一代目は三百五十〜五百トンを三百〜三百八十人で動かす。**ほぼ同じ大きさの船を、二十倍の人間で動かしている。**費用対効果の議論(補論二)の物理的な正体はこれであり、同時に、軍船とはそういうものだという説明でもある。

**(五)海の向こうの収斂形に並ぶのは二代目である。**六百〜八百トンという二代目の規模は、ヴェネツィアのガレアス(六百〜七百五十トン)とほぼ同格になる。艪走と帆走を併せ持つ重武装艦という同じ問題への回答が、交流のないまま同じ寸法帯に落ち着く。ただし比率は違ったままで、あちらは細長く、こちらは太い。この差は接舷戦を捨てたか残したかの差でもある。

**(六)三代目は縮んで、ガレアスとガレオンの中間に落ち着く。**四百五十〜六百トンは中型ガレオンと重なる帯であり、幅の広さの分だけ甲板は広い。

## 三、見え方

- **岸から見れば。**大安宅船と区別がつかない。総矢倉の箱と一枚帆、そして舷から突き出た艪。近づいて初めて、水線がやけに沈んでいることと、その下が赤茶色に光っていることに気づく。
- **関船の甲板から見上げれば。**舷の高さは関船の倍以上。乗り移るには梯子か鉤縄が要る。
- **千石船と並べば。**長さは一.五倍だが、人の数は二十倍で、甲板は人で埋まっている。
- **ガレオンと並べば。**長さは同程度か短い。幅は広い。マストは低く、帆は少ない。舷から艪が出ているのが、あちらから見た最大の違いになる。
- **湊での扱い。**関船や小早が入れる浅い入江に入れない。沖に錨を打ち、艀で人と荷を運ぶ。この不便が日常的な不満の種になる。

## 四、喫水がもたらす制約

三メートルを超える喫水は、この船の行動を実際に縛る。

- 朝鮮南岸の入り組んだ入江のうち、深い泊地を持つものしか使えない。倭城の湊がすべて使えるとは限らず、どの城が大船を受けられるかが軍事的に重要な区別になる。
- 瀬戸内の狭い瀬戸では、潮待ちに加えて水深の制約が加わる。
- 河口・干潟は原則として不可。とりわけ朝鮮西海岸は干満の差が大きく、大船が入るのは危険である。

**この最後の点は、指摘のあった江華島型の戦闘に直接効く。**漢江河口一帯は浅く、干満差が大きい。喫水三メートルの艪走艦がそこへ入るのは座州の危険が高く、実際には沖に控えて砲を貸し、島や河口の中へは関船・小早を入れるという分業になる。**大船は行くが、戦場の芯には入れない。**

## 五、明清交代期の運用について

指摘の通り、この艦種が最も働けるのは、開けた外洋でも本格的な艦隊決戦でもなく、**沿岸と島嶼の、風の当てにならない海**である。金門・厦門・舟山、あるいは朝鮮西海岸の島。在来の関船・小早の群れに不足しているのは砲力であり、それを風の有無に関わらず持ち込めるという一点で、この船は十分に強い。えっちらおっちら回航してきて、島の裏に据わり、撃つ。任務の像としてはこれが正確だろう。

**ただし季節が問題になる。**行動可能な季節は春と秋(前メモ第四節)であり、大陸の危機は季節を選ばない。実際、朝鮮に対する北からの侵攻が真冬に来た場合、**この船が最も必要とされる時期は、この船が最も動けない時期と重なる。**間に合わなかった、あるいは間に合わせるために無理をして損害を出した、という展開は、備えの限界を示す材料として使える。「来援を確実にする船」という建造の名目が、季節という一点で裏切られる形になる。

回航そのものも軽くない。下関から寧波方面まで七〜十日、水は二十日で尽きる。途中の補給地を先に押さえておかなければ、行っても戦えない。**この艦種の遠征は、船の話である前に補給地の話になる。**

## 六、留保

寸法はいずれも幅と論争を含む。大安宅船・安宅丸の数値は伝承であり、九鬼の鉄張り大船の「十二三間・七間」は多聞院日記の記述だが比率が異常で解釈に議論がある。弁才船の十五〜十八人という乗員は、船型が完成した十七世紀後半以降のもので、一六〇〇年前後の廻船はこれより人を要した可能性が高い。板屋船・ガレアス・ガレオンの数値は型式と時期で振れる。

系譜三代の寸法と喫水はすべて仮定である。とりわけ喫水二.五〜三.五メートルは排水量と船型からの逆算であり、実際には設計者が浅い喫水を優先して船体を平たく寄せる選択もありうる。その場合、凌波性は下がるが湊の自由度は上がり、性格の異なる船になる。

季節と危機の時期が食い違うという第五節の指摘は、叙述上の起伏として提案するものであり、実際には冬でも瀬戸内伝いに西へ寄せておく、あるいは前年秋から前進配備しておくという運用で緩和されうる。緩和策を用意するかどうかも主作成者の判断に委ねる。
