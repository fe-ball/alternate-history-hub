# 豊国IF検討メモ――諸元比較と系譜の年表(安宅船・板屋船・ガレアス・洋船)

安宅丸級を「和製ガレアス」と位置づけるにあたり、比較対象の実史諸元を並べ、そこから系譜三代の数字を導く。あわせて年表を整理する。本メモは参照用であり、伝承値と推定値の区別を各所に明記する。

---

## 一、比較のための実史諸元

日本側の数値は積石(積載容量)で語られるため、排水量とは別物である。おおむね千石積が積載約百五十トン、排水量にして二百五十〜三百トン級と見て換算する。この換算自体が粗いことを断っておく。

## 二、漕ぎ手比――比較の物差し

諸元を横断して比べるには、排水量あたりの漕ぎ手数を見るのがよい。

| 船種 | 排水量(推定) | 漕ぎ手 | 漕ぎ手/トン |
|---|---|---|---|
| 関船 | 50〜80t | 40〜60 | 0.8〜1.0 |
| 大安宅船 | 150〜300t | 100〜180 | 0.6〜1.0 |
| 板屋船 | 120〜180t | 100前後 | 0.6〜0.8 |
| 地中海ガレー | 150〜200t | 150〜250 | 1.0〜1.5 |
| ヴェネツィア・ガレアス | 600〜750t | 300〜500 | 0.5〜0.7 |

**重い艪走軍船は、洋の東西を問わず0.5〜1.0のあたりに収まる。**ガレーが1.0を超えるのは速度を買っているからで、重武装の船はそこまで漕ぎ手を積めない。

ここに安宅丸の伝承値を当てる。漕ぎ手二百人であれば、成立する排水量は**二百〜四百トン**。補論一で在来の艪の比率から出した数字と一致する。逆に、全長六十メートル級という大きいほうの伝承を採れば排水量は七百〜千トンとなり、漕ぎ手比は0.2〜0.3、すなわち**どの艪走軍船の伝統から見ても半分から三分の一しかない**。史実の安宅丸が重すぎて漕げなかったと伝わる理由は、この一点で説明がつく。ガレアスの船体にガレー未満の艪を付けた船だったことになる。

**この世界の配備艦は、この失敗を繰り返さない。** 選択肢は補論一の通り二つで、船体を漕ぎ手に合わせて縮めるか、漕ぎ手を船体に合わせて増やすかである。そして後者への道が、思いがけない方向から開く。

## 三、板屋船から取れるもの

朝鮮の船については、鹵獲した実物、釜山の普請場へ流れた朝鮮の船大工(資料集の既定)、倭城付帯地での日常的な接触という三重の経路がある。取れるものは四つある。

**(一)一挺を多人数で扱う櫓。** これが最大の収穫である。日本の艪は一人ないし二人で扱うが、板屋船の櫓は四〜五人で押す。**舷側に漕ぎ口を開けずに漕ぎ手を増やせる**という、補論一で立てた難問への回答が、地中海ではなく隣国にある。櫂を採れば砲門と漕ぎ口が板列を奪い合うが、櫓の多人数化なら船体に穴を開けない。艪を数十挺に減らして一挺あたりの人数を増やせば、百挺二百人と同じ人数で、より大きな力を出せる。

**(二)二層配置。** 下層に漕ぎ手、上層に戦闘員という板屋船の構成は、そのままガレアスの配置でもある。漕ぎ手を下に押し込めば、上層の舷側を砲に明け渡せる。艪と砲の場所争いは、平面ではなく上下で解くのが正解であり、その実例が二つの伝統から同時に示される。

**(三)厚板。** 装甲としての船体外板。唐船・板屋船の砲に耐えるという要求に対しては、キールによる縦強度よりこちらが直接効く。

**(四)木釘と込み栓。** 鉄をほとんど使わない工法。この時点では単に在来的な選択にすぎないが、後年の腐食の一件で決定的な意味を持つことになる。

**総合すると、安宅丸級の設計は三系統の合成になる。** 安宅船から総矢倉と接舷戦の力、板屋船から二層配置と多人数櫓と厚板、洋船からキールと肋骨と舷側砲。そしてキールを入れたことの代償として銅を張る。和洋折衷という言い方では足りず、和・朝・洋の三項である。

## 四、系譜三代の諸元案

以上を踏まえた提案値。すべて世界線の仮定であり、幅を持つ。

| 項目 | 安宅丸級(一代) | 超安宅丸級(二代) | 改級(三代) |
|---|---|---|---|
| 排水量 | 350〜500t | 600〜800t | 450〜600t |
| 全長 | 40〜48m | 50〜58m | 45〜52m |
| 幅 | 10〜12m | 12〜14m | 11〜13m |
| 櫓 | 100挺・二人(水主200)、後に一部を多人数櫓へ改める | 40〜50挺・五〜六人(水主250〜300) | 40〜50挺・五〜六人(水主250〜300) |
| 漕ぎ手/トン | 0.4〜0.6(不足気味) | 0.4〜0.5(なお不足) | 0.5〜0.65 |
| 砲 | 石火矢・大筒10〜16門 | 20〜28門 | 18〜24門 |
| 総員 | 300〜380 | 450〜550 | 400〜480 |
| 船底の銅 | 1.5〜3t | 3〜5t | 2.5〜4t |
| 締結 | 木釘・込み栓主体 | 鉄釘(唐人技師の工法) | 青銅・真鍮、木釘併用 |
| 舵 | 和式の掛け舵 | 洋式の吊り金具 | 中国式の懸吊舵 |
| 構造 | 厚い航に縦通材、部分的な隔壁 | 水密隔壁+縦通材、大型化 | 隔壁を増やし、継手で持たせる |

**一代目が漕ぎ手比で不足しているのは意図的である。**在来の百挺二人立てをそのまま踏襲したため、キールと銅と砲で増えた重量に対して艪が足りない。就役後に「思ったより漕げない」という評価が出て、途中から一部の艪を多人数扱いに改める、あるいは配備艦で上屋を削るという是正が入る。この不出来が、二代目で漕ぎ方を朝鮮式へ寄せる動機になる。

**二代目は大きくなったぶん、なお漕ぎ手比が改善しない。**堅牢化を追った結果として大型化が付いてきた、という順序(隔壁と鉄釘という手段が大きさを許してしまう)であり、漕走性能は据え置きか微増にとどまる。砲力は明確に上がる。

**三代目は締結材の天井により一回り縮む。**そのぶん漕ぎ手比は改善し、実は最も動く船になる。砲は二代目より減るが、二代目が持て余していた大きさを捨てた結果であり、実用上の後退とは限らない。

**時期の妥当性。** 一番艦の就役(1617〜22)から腐食の発覚(1640年代)まで二十数年あり、この間、一番艦は無事に浮かんでいる。史実の安宅丸が四十七年もったことを踏まえれば無理はない。既存艦が健在なまま新型が失敗するという構図が、断罪でなく困惑として処理される理由でもある。

**唐人技師の招聘時期。** 寧波勘合により1600年代から招聘自体は可能だが、まとまった技術者の流入は明の混乱と重なる1630年代以降と見るのが自然で、v3既定の「明末清初の技術者流入」に乗る。

## 六、留保

実史側の諸元はいずれも幅と論争を含む。とりわけ安宅丸の全長・積石は史料により大きく食い違い、本メモは漕ぎ手比の整合を根拠に小さいほうを採ったが、これは推論による選択であって史料的裁定ではない。九鬼の鉄張り大船の寸法は多聞院日記の記述だが、幅と長さの比が異常であり、解釈に議論がある。板屋船の寸法・格軍数は型式と時期により相当に振れる。ガレアスの諸元はレパント期のヴェネツィア型に依り、他国・他時期の同種艦とは異なる。

漕ぎ手比という物差しそのものが本メモの道具であり、実際の推進力は艪の長さ・水線形状・喫水・海況に大きく依存するため、比だけで性能を論じられるものではない。

系譜三代の諸元案は全面的に仮定である。とりわけ二代目で漕ぎ方を朝鮮式の多人数櫓へ寄せるという想定、および一代目が漕ぎ手比で不足するという設定は、叙述上の起伏を作るための選択であり、最初から適正な艪数で設計される経路も同程度にありうる。年表の各年次も同様に幅を持ち、腐食の発覚を1640年代に置いたのは唐人技師の流入時期からの逆算にすぎない。
