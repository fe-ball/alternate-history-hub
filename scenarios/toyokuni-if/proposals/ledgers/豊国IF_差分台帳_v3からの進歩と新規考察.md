# 豊国IF差分台帳――v3からの進歩点と、矛盾しない新規考察の集約(引き継ぎ用)

## 本文書の性格

本文書は、正典『豊国に5年の天よりの命をv3』に対して、2026年7月の検討作業(資料集v2の改稿および検討メモ四本の作成)で積み上がった増分を、第三者が引き継げる形で仕分けた台帳である。読者として、本プロジェクトを引き継ぐ人間およびAIを想定する。

仕分けは三区分による。(一)v3の記述を深化・具体化したもの(矛盾なし)。(二)v3に記載がなく、矛盾もしない新規考察。(三)採否が主作成者の判断待ちのもの。ハンドオフ文書第0項の正典構造に従い、本台帳の全項目は採用されるまで提言プールに属する。また、各検討メモの分析中で用いられる要約的な言い回し(歳入構造の対比、船員数の実数比較など)は分析上の便宜であって、作中用語・固有概念ではない(ハンドオフ第1項)。

## 一、v3の記述を深化・具体化したもの

**1. 戦況記述の増補(明の作戦学習と撤退過程)。** v3の「防戦と遠征の繰り返しで明のプレゼンスを削る」という骨子を、資料集v2で次のように具体化した。明は三路分散(1598)の敗因から学んで水陸の全力を順天一点に注ぐ総攻囲(1599)へ移行し、その最善手が露梁での封鎖艦隊撃滅によって覆される。以後、日本側の補給線攻撃、播州の乱との資源競合、期限付き増派を可決していた北京廷議の限界が重なって撤兵に至る。朝鮮単独攻勢(1600)には「単独で大敗すれば明も再介入を避けられない」という賭けの論理を与えた。日本側を無敵に描かないため、順天は落城寸前まで追い込まれる。蔚山籠城(1598)の教訓が水・兵糧の定数化として制度に残る記述も追加した。

**2. 南蛮中継利権の減殺の数量化。** v3の定性的主張を、ポルトガル定航船の売上が年50〜100万両級から20〜30万両級へ縮小し、その中継マージンが日本側の統制下複合体へ移転する、という数値の形にした(利権試算メモ)。

**3. 利権知行の原資が初期には薄いことの特定。** 豊臣中枢の実質取り分は、朝鮮方面の持ち出しを差し引くと年800〜2,000貫(米1.5〜3.6万石相当)にとどまり、蔵入地収入への上乗せは数%である。七年の役の動員規模に対する恩賞原資の明白な不足が、慶長六年の太閤襲撃未遂と、利権知行制度化が急がれたことを経済面から裏書きする(同メモ)。

**4. 朝鮮方面利権の初期実態の解剖。** 初期の朝鮮方面は費用センターであり(在番負担で年数千貫の持ち出し)、最初に現金化するのは在番約一.五万人への物資調達の差配である。貸付・質流れ・裁許の前例・銭の浸透は、年々の所得ではなく将来収益(付帯地・管轄・決済単位)の資産としての蓄積にあたる。鉱山を持たない海外拠点が本国補助か貿易収益で赤字を埋めるのは同時代の通例であり(フィリピンを維持したメキシコからの補助金が典型)、この世界の倭城網の補助金源は寧波貿易の利である(同メモ)。

**5. 「徳川への遠慮と依存は消えない」の経済的基礎付け。** 史実の豊臣の歳入は、経済要地に散在する蔵入地、鉱山運上、都市の金融・調達機能の徴発、貿易独占の萌芽、貴金属ストックから成り、領域を面で課税する構造ではない。徳川の関東一円支配との対比で言えば、豊臣は結節点を押さえて流通に課金する型の政権であり、海上権力の利得はその本業の延長にあたる。この型は徳川には模倣しにくく対抗上の成長軸となる一方、徴収の対大名依存と直属軍事力の希薄という弱点は、海上でも船手大名への依存として保存される。v3の釘はこの構造の帰結として維持される(経済構造メモ)。

**6. 蝦夷地・海軍軍需品への駆動力の追加。** v3付記の「毛皮商人が蝦夷の木々を見出す」経路に、国内木材需給の逼迫が史実より早まる(下記二-8)という需要側の駆動力が加わった。

## 二、新規考察(v3未記載・矛盾なし)

**1. 銀流出量の見方。** 政権を単体の徴税者として見る限り、講和後の銀流出総量は史実同時期と大差なく(年45〜80トン)、条約が短期に変えるのは総量ではなく経路とマージンの帰属である。ただし商人型家臣団と船手大名を織り込むと、(a)退蔵から輸出への振替(+10〜25トン)、(b)貿易利益の鉱山再投資による産出増の約十年前倒し、(c)唐船向け通行手形・護衛という収入(海賊停止令の趣旨=海上暴力の政権独占を外洋へ延長したもの)、(d)銀流出に現れない運賃・護衛料などの経常収入、が上乗せされる。総括すれば、水準の急拡大ではなく成長の前倒しである(利権試算メモ補論)。

**2. 戦時海事基盤の平時転用という見方。** 唐入りが実際に建設した基盤(輸送船腹二千艘級・水夫数万・船手衆約九千)は、史実では1598年以降に解体された。この改変の経済的本質は新規建設ではなく、史実で廃棄されるはずだった既存資本の維持・転用であり、初期投資は史実においても既に支払われている。推計値が「前倒し」型になる根拠である(経済構造メモ)。

**3. 常備海軍の規模と負担構造。** 平時常備七千〜一万二千人(文禄期船手衆の六〜十割の水準維持)、維持費は年銀2,000〜4,000貫。護衛料等による直接の自己資金化は一〜二割にとどまり、この海軍は収益事業ではなく、貿易利権を見返りとする軍役として維持される。負担は担い手諸家の可処分収入の数%で通常の軍役水準に収まる。艦隊総費用が明のかつての朝鮮駐留費の数十分の一である非対称が、講和体制の持続性を金額面から支える(海賊海運規模メモ)。

**4. 呂宋遠征(1609)の実行可能性検算。** 現有の人員・船腹で可能。律速は船腹でも兵力でもなく、航海士層の薄さ・疫病・季節風による日程の一発性の三点である。1601〜08年の八年間の平時外洋通商が航海士層を育てたという因果により、資料集の1609年開始という設定は内的に整合する。隠れた費用として、外航熟練層の25〜40%を一季徴用するため当年の商業航海が部分停止する(粗利10〜20万両級の逸失)。作戦類型の実在証明として鄭成功のゼーランディア攻略(1661)を参照できる(同メモ補論)。

**5. 船員数の実数比較。** 人口比では農業国ゆえに低くとも、外洋可能な船員の実数二〜三万人は同時期の英仏と同格で、世界でも上位数か国の水準にある。しかも欧州諸国の船員は主力が欧州水域に張り付くのに対し、日本の全量は単一戦域に集中しており、東アジアでの局地優位は総数比を上回る。国家に組織され武装可能な船員供給としては域内で唯一である(福建の海洋世界は同規模だが政治的に分散)。人口基盤が大きいため、人口比一%弱のままでも世紀半ばには蘭の史実ピークの実数を上回りうる。最深部の制約は水夫でなく航海士・指揮官層である(同メモ補論)。

**6. 呂宋航路の構造。** 季節風により一隻年一往復に律速されるため、輸送量の拡大は隻数の増加としてしか実現できず、航路が船腹と人員の供給層を太らせる。中部ルソンの米作により植民地が食料自給できるため、朝鮮方面と異なり、この航路は補給路ではなく最初から商業航路として立ち上がる。駐留海軍と軍事輸送が固定需要の床を張り、その上に商業需要が乗る(呂宋航路メモ)。

**7. 船員供給の非日本人化。** 史実のガレオン乗組の多数派が比島人水夫であった通り、呂宋領有は比島人・華人の船員・船匠の吸収を可能にする。海事人員の拡大が日本の人口構造(農業国ゆえの比率の低さ)から切り離される。植民地保有が海事面で持つ最大の意味である(同メモ)。

**8. 木材問題の定式化。** 問いは「足りるか」ではなく「どこで切り、どこで組むか」である。総量は足りる(呂宋の造船適堅木のストックは需要より桁二つ大きい)。海上輸送はこの時代に確立済みだが(バルト材木貿易、紀州・土佐の廻材、シャム材のジャンク輸送)、採算はバラスト・帰り荷(既定の呂宋炭)と高価値部材(竜骨・曲がり材・檣)に限られる。したがって主解は造船の現地化(カビテ)であり、これはスペインが取ったのと同じ配置である。加えて、熱帯堅木は檣に不向きで日本は針葉樹に富むため、檣・帆桁を南下便で、竜骨・曲がり材を北上便で運ぶ双方向の部材貿易が季節風の往復に整合する。日本国内では、史実で十七世紀半ばに顕在化した木材逼迫が、海軍需要の分だけ十〜二十年早まると見るべきである(同メモ)。

**9. 伐採・造船労働の統治問題。** スペリオル期のガレオン建造は伐採・造船の賦役で成り立ち、その負担は逃散と反乱を繰り返し招いた(1649年のスマロイの乱が代表)。木材の量ではなく、木を切り船を組む労働の確保こそが統治上の難所であり、呂宋統治設計の主要論点として登録する(同メモ)。

## 三、新規に開いた検討領域(素描)

**1. 蝦夷地開拓の先駆けとしての海軍需要。** v3既定の毛皮商人の北上に木材逼迫の前倒しが重なると、蝦夷材(エゾマツ・トドマツの軽軟材は檣・板向き、ヒバは耐朽の船材)の試伐が1610〜20年代に始まる経路が開ける。雑考4の「公認植民会社による蝦夷植民」構想の最初の実体は、農業入植ではなく杣・炭焼・湊の三点になると考えられる。松前口の性格が交易口から資源口へ半歩ずれ、北方への関心が南方の帝国の後方需要から生まれる、という因果になる。

**2. 軍船備林という行政ジャンル。** 史実の日本林政(御留山・御林、木曽のヒノキ統制、海岸の防砂松原造成)を土台に、軍船用材の備林(仮称・御船木山)という史実にない行政分野が接木される。同時代の実在例は多く、ヴェネツィアの造船用樫林の国家管理、後年のコルベールの海軍林政(1669年森林大令)、イングランドの檣木徴発印など、海軍を持つ国家は例外なく森林行政を発達させた。日本版の構成要素として、檣木指定と巨木台帳、伐り旬と葉枯らし乾燥の規式、曲がり材(膝材)の育林、防砂・松脂採取(海軍軍需品のピッチ・テレピン原料)と結合した松林管理、船大工による山の検分役、などが導ける。軍需・防災・年貢外収入が一本の松林で交差するため大名の受容性は高い一方、留山の強化は入会地の圧迫として百姓との紛争源になる。

**3. 産業・環境の小話素材。** 物語に落とす際の材料として以下を控える。呂宋の堅木モラベに鉋の刃を欠く日本の船大工と、檜の素直さに驚く比島・華人の船匠。北上便の呂宋炭が釜山の温突に焚かれ、南下便の杉檣がカビテに立つという、季節風の一往復による気候帯間の交換。鉄穴流しの拡大(v3既定)による土砂流出が川湊の埋没として廻船側と衝突し、治水普請が早まる摩擦。蝦夷の杣が冬山で倒したエゾマツの初荷に堺の目利きが値を付ける場面。御船木山の台帳に載った巨木一本をめぐる村・代官・船手奉行の裁許一件。

**4. その他の登録のみの論点。** 航海士養成(按針・雇いスペイン人水先・唐人火長の混成から堺・長崎での教習へ。雑考4の科学アカデミー構想の最初の実体候補)。比島人・華人船員の身分・処遇の設計。呂宋統治設計の全体(賦役か賃雇いか、パリアンの自治、教会財産の処理)。いずれも未検討の空白として明示的に残す。

## 四、採否待ちリスト(主作成者判断)

1. ガレオン東航便の日本寄港(伊東・浦賀等)。マニラ発アカプルコ行きの帰航路は北緯三十七〜四十度まで上がり日本沖を通る。史実でも1609年にマニラ発ガレオンが上総に漂着し寄港交渉が持ち上がった(ドン・ロドリゴの一件)。採用すれば東日本の港=徳川圏が体制の受益者となる政治効果を持つ。編年1612〜13年項への追記候補。
2. 唐船向け通行手形・護衛の制度化。編年の慶長九〜十年項への追記候補。
3. 軍船備林(仮称・御船木山)。編年では秀吉死後〜1610年代。
4. 蝦夷試伐の開始年代(1610年代か20年代か)。
5. 呂宋遠征の機会費用(当年商業航海の部分停止)を編年・戦記に影として書くか。

## 五、整合チェック(v3の釘との突合)

徳川依存の保存は経済構造メモが釘を強化する方向で整合。朝鮮水軍の扱い(神格化も過小評価もしない)は資料集v2の李舜臣・見乃梁の記述の範囲内。琉球非侵攻は全メモで維持(資本浸透のみ)。貴金属流出への警戒と管理貿易オプションは補論の抑制要因に明記済み。良い出来事への偏りの禁止に対しては、順天の落城寸前、艦隊の赤字構造、賦役反乱リスク、入会紛争、遠征の機会費用と、負の要素を各所に配置済み。用語規律については、全メモで説明用の即席語を作中用語化せず、現象の記述で通している。
