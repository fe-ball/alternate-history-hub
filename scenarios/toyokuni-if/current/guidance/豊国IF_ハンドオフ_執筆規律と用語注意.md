# 豊国IF ハンドオフ文書 ――執筆・検討にあたっての規律と釘刺し

本文書は『豊国に5年の天よりの命を』(v3)系列の検討・執筆を引き継ぐ者(人間・AIを問わず)向けの注意事項集である。設定そのものの要約ではなく、**「どう書いてはいけないか/どう考えてはいけないか」**の規律をまとめる。

## 0. 正典構造(どのファイルを信じるか)

- **v3(『豊国に5年の天よりの命をv3』)が正典。** 史観宣言・因果の論証を含む設計文書であり、他文書と矛盾する場合はv3を優先する。
- **雑考1〜5は提言プール。** 受け入れ済みのものと未検討のものが混在する(『構造』ファイル参照)。雑考の記述を既定事実として扱わないこと。
- **各国表(1610年時点html)はスナップショットであり、既知の不整合を含む。** 特に「慶尚道・全羅道を割譲」はv3・資料集の「割譲なし。倭城とその付帯地・警固権の拡大解釈による実効支配」と矛盾する。**後者が正**。朝鮮の版図は書類上一寸も動いていないことがこの講和の核心である。
- **資料集(md)はAI生成の派生物。** 正典を時系列に展開したものにすぎず、これ自体を根拠として設定を固定しない。
- **検討メモ群(利権試算・経済構造・海賊海運規模・呂宋航路)と差分台帳は提言プールに属する。** 雑考と同格であり、主作成者が採用するまで既定事実として扱わない。採否待ち項目は差分台帳第四節に集約されている。
- **雑考一〜五および各国表の項目別の生死は、『参考提言集(雑考・各国表 統合整理版)』の状態表示を正とする。** 原文書が手元にない環境では、参考提言集をもって両者の代替としてよい。

## 1. 用語の扱い ――説明用の即席語を作中用語にしない

**最重要。** 作者が史観を説明する際に使った以下のような言葉は、**説明のための雑な即席語であり、特異的な用語・作中概念・学術用語ではない。**

- 「圏的支配」「面的支配」「圏」
- 「レイド」(海上機動による襲撃・焚き働きの類を指して使われた)
- その他、作者の説明文中に現れる同種のラベル
- 検討の対話やメモの中で便宜的に生じた言い回しも同様である(例:「絶対」を冠した比較語、「点と流れの国家」などの要約語)。分析文書の地の文で一度使うことは差し支えないが、術語として定義・反復・見出し化しない。

これらを固有名詞・キーワードとして正典化し、鉤括弧付きで連呼したり、「◯◯とはこの戦役を象徴する概念で――」式に作中世界へ持ち込んだりしてはならない。v3自身が「圏的支配はキーワードのようになるが、強調しすぎない」と釘を刺している通りである。

**代わりに現象を記述する。** 例:
- 「圏的支配」→ 城付きの付帯地と、城主が当然に振るう周辺警固の拡大解釈。裁許の前例、資本流入、質流れの集積による、登記上の領土を動かさない実効支配の深化。
- 「レイド」→ 船手による沿岸への焼き討ち・糧站破壊・神出鬼没の襲撃。

同時代人が使うはずのない語彙(近代軍事用語・社会科学用語)を作中史料の引用や人物の台詞に混ぜないこと。地の文での分析的使用は可だが、ラベルの反復より現象の記述を優先する。

## 2. 史観の位置づけ ――宣言であって証明ではない

v3冒頭の史観群(秀吉は耄碌していない、慶長の役は限定戦争、等)は「反証の存在を認識しつつ、それでもこの立場を取る」という**宣言**である。

- 根拠は史観の補強であり証明ではない。執筆時に「証明された事実」のように強弁しない。
- 逆に、史観を勝手に緩めて通説(耄碌説・癇癪説など)に引き戻すことも禁止。

## 3. 視点規律 ――登場人物は史実を知らない

- 「史実より◯◯である」は誰の知るところでもない。**史実比較はそれ自体では歴史を変化させる理由にならない。** 変化は常に、現地の人間がそれを可能にし、失敗し、成否を判断することを通じて起きる。
- 秀吉は史実より健康でも、老いれば純粋に「自分は老いた」と感じる。周囲も同様。
- 二次的変化についても同じ。「史実ではこの人物は死んでいたが」式の視点を作中人物に漏らさない。

## 4. イベント記述のバイアス ――良イベント偏重の断り

- v3の記述がグッドイベント中心なのは、**悪い出来事や小粒の不況は「普通に進行する歴史の中に当然たくさんある」前提を採っている**ためであり、悪いことが起きない世界という意味ではない。
- 通史・戦記に展開する際は、敗北・際どさ・失敗体験・不況を能動的に織り込むこと。**日本無敵化の禁止。** 勝利は構造の勝利として描き、無敵の勝利として描かない(例: 順天が本当に落ちかける、後詰が三日遅ければ、等)。
- 全体の流れが書かれている場合も、あくまで試案である。

## 5. 個別の釘(人物・勢力評価)

- **秀吉**: 頭脳的劣化はない。ただし精神的ストレス・肉体的衰弱には年々悩まされる。督戦は理性的で、死守命令の乱発はしない。中華的外交(華夷秩序の強固さ)への理解不足はあった。
- **家康**: 野心は無制限ではない。主家の真剣な継承危機がなければ簒奪的アクションに出ない。名分なき反乱を取らない保守性を信頼する史観。
- **朝鮮水軍**: 神格化しない。ただし過小評価もしない――v3の一部の強い表現は**LLM等を説得するためのものであり、朝鮮水軍の戦闘力アベレージが低かったとは考えていない**。補給への脅威・渡海阻止の価値は認める。
- **義兵**: 一律の自発的民衆ゲリラとみなさない。主力は両班・郷村有力者が組織した半正規軍的なもの。
- **徳川の抑え**: 秀吉はそこまで行わない。軍役負担・普請でのバランス取り程度。
- **明**: 朝鮮方面のレッドラインは平壌。朝鮮全体の緩衝地帯価値を怪しむ意見も国内に大きい。撤兵は財政・西南の乱・北辺(ヌルハチ)の複合による合理的判断として描く。

## 6. 断定表現の扱い

- 付記類(産業・技術・通商・対外影響)は考証的検討であり、複数経路の議論として読む。**断定的な記述は「可能性の中で最も蓋然性が高いと考えるもの」の提示にすぎない。**
- 派生文書を書く際も、単一経路への固定(例: 製鉄大型化の経路)を避け、幅を保持する。

## 7. 文体規律 ――架空史料・セリフ・評価文

編年・概要など記録調の文で顕著になりやすいAI的な癖を禁じる。

- **架空史料の引用・決め台詞を乱発しない。** 引用がなくても成立する記述を基本とする。人物の発言は間接話法(「〜と伝わる」「〜を訴えた」)で処理する。直接話法と創作台詞は戦記など明示的な物語文の中に限る。
- **出来事の意味づけを警句で締めない。** 「――」による断言、「〜のである」調、対句・逆説・体言止めのオチ(例:「銭が主権より先に国境を越えている」「名分という器は中身を入れ替えられるために存在する」)を評価文に使わない。評価は現象と帰結の記述そのもので示す。
- **同時代人が言いそうにない台詞を作らない。** 近代的な相対化・メタ認識・気の利きすぎた自己言及を人物に語らせない。
- 物語文(戦記)でも、地の文の格言化(「学ばぬのは滅ぶ側だけである」の類)は抑制する。

## 8. 改変の波及原則

- 明示的な改変トリガーは**秀吉の寿命+5年のみ**。それ以外はすべて、厳密なシミュレーションか宣言済み史観からの帰結として導く。
- 寿命延長は1598年に突然足されるのではなく、老年期の衰弱の回避としてずっと前から少しずつ効く(判物の筆勢、壮健さ、空手形への警戒の薄れ、等)。
- **寿命を安易に括らない。** 「寿命とは統帥の信用である」のような言語化は一面の効果の要約にすぎず、これ自体を主題・キーワードとしてラベル化しない(第1項の規律は作者自身の説明語にも自作の要約語にも等しく適用される)。寿命はまず単なる寿命そのものであり、体が動く・病まない・死なないという物理的事実として、信用以外の無数の経路(督戦、視察、造営、外交や裁許の継続性)でも効く。
