# 豊国IF 引き継ぎ要領(README)

本パッケージは仮想歴史プロジェクト『豊国に五年の天よりの命を』(分岐点:豊臣秀吉の寿命が史実より五年長い)の作業一式である。新しい検討・執筆セッションは、本要領の読み順に従えば前提を再構築できる。

## ファイル構成と読み順

1. **豊国に5年の天よりの命をv3.txt** ――正典。分岐トリガー、依拠する史観の宣言、想定歴史変動、産業・通商・対外の付記。すべての矛盾はv3を優先して裁定する。
2. **豊国IF_ハンドオフ_執筆規律と用語注意.md** ――規律(準正典)。正典構造、用語規律(説明用の即席語を作中用語化しない)、視点規律(登場人物は史実を知らない)、文体規律(架空引用・警句の禁止)、寿命の扱い、人物評価の釘。**作業前に必読。**
3. **豊国IF_資料集_講和からルソンまで_v2.md** ――叙述(採用済み扱い)。唐入り開幕から呂宋領有後(1613)までの編年・戦記四篇・物産図録。文体規律適用済み。
4. **豊国IF_差分台帳_v3からの進歩と新規考察.md** ――台帳。v3からの深化点と新規考察の仕分け、**採否待ちリスト(第四節)**、v3の釘との整合チェック、全ファイル索引。
5. **豊国IF_参考提言集_雑考・各国表統合整理版.md** ――台帳。旧提言文書(雑考一〜五、知人提供の各国情勢表)の全項目を状態付き(採用済み/展開済み/保持/閉鎖など)で統合。原文書の代替として機能する。**特に、各国表にあった「慶尚道・全羅道割譲」は錯誤として閉鎖済みであり、正典の講和は割譲なしの庚子約条である。**
6. **検討メモ四本**(提言。読む順は任意、相互参照あり)
   - 豊国IF_検討_戦後利権の経済規模試算_1601-03.md ――講和後数年の貿易・利権の数量試算。補論に商人型家臣団・船手大名を織り込んだ修正。
   - 豊国IF_検討_豊臣政権の経済構造と海上権力の利得.md ――史実の豊臣の歳入構造の整理と、海上権力の利得がこの政権の本業の延長である理由。
   - 豊国IF_検討_海賊と海運の規模維持量推計.md ――外航・武装海事部門の常備量と維持費、呂宋遠征の実行可能性検算、船員数の実数比較。
   - 豊国IF_検討_呂宋航路のプールと木材問題.md ――呂宋航路の構造、船員供給の非日本人化、木材の「どこで切りどこで組むか」への定式化。

## 現在地(2026年7月時点の作業状態)

- 正典期間の叙述は1613年(呂宋領有とアカプルコ交易の再開)まで整備済み。
- 経済・海事の基礎数量は検討メモで一通り置かれた(すべて幅付きの推計。実史アンカーと世界線仮定の区別は各メモの留保節を参照)。
- 主作成者の採否待ち項目は差分台帳第四節に五件:ガレオン東航便の日本寄港、唐船向け通行手形・護衛の制度化、軍船備林(仮称・御船木山)、蝦夷試伐の開始年代、呂宋遠征の機会費用の叙述化。

## 未検討の主要領域(次の議論の候補)

- 呂宋統治設計(賦役か賃雇いか、パリアン自治、教会財産、比島人・華人船員の身分)。
- 後金・清問題(サルフの戦いへの関与の有無と規模。参考提言集18)。正典の「結びに代えて」が示す次の火種であり、倭城の名分再解釈と直結する最大の分岐点。
- 秀吉死後の国内政治の細部(輔弼体制の運営、秀次の役割、利権知行の配分政治)。
- 欧州側の本格検討(三十年戦争の変容。参考提言集17)。
- 十七世紀中盤以降:産業調整(参考提言集12)、木材・海軍軍需品制約の顕在化、蝦夷開発、航海士養成と学術。

## 作業上の注意(要点のみ。詳細はハンドオフ)

- 改変トリガーは秀吉の寿命+5年のみ。ほかは史観と因果からの帰結として導く。
- 数値は幅で示し、実史アンカーと仮定を区別する。断定は最蓋然性の提示にすぎない。
- 日本を無敵に描かない。負の要素(赤字構造・反乱リスク・機会費用・際どい勝利)を能動的に配置する。
- 記録調の文に架空引用・決め台詞・警句のオチを入れない。
- 数値範囲の表記は「〜」を用いる(ASCIIチルダ「~」はMarkdownで打ち消し線として誤描画されるため使用しない)。
