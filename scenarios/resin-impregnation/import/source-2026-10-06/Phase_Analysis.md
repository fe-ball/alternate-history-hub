# 各時期（フェーズ）における多角化・収益性・商業戦略分析

本ドキュメントでは、主人公の企業が第1期から第6期にかけてどのように事業を拡大し、そのR&D費用・商業活動・金融運営をどのように管理してきたかを一貫して記述する。商業・金融・宣伝戦略の詳細はCommercial_And_Financial_Strategy.md参照。各時期の売上概算はRevenue_Model.mdを参照。

---

## 【§0】期区分の正典定義（CANONICAL）

**本節は資料群全体における期区分の正典（canonical reference）である。** 他のすべての文書（Master_Parameters・Detailed_Growth_Simulation・01_タイムライン・Compreg_Markets_And_Lifecycle・Revenue_Model 等）は、本節の定義に従う。

### 期区分の基本構造

本資料群の「期（フェーズ）」は、**技術・事業の発展段階を示す概念区分**であり、必ずしも排他的な時間範囲を持たない。研究フェーズの並行進行と次世代素材の重複開発を反映し、一部の期は時間範囲が**並列または末尾でオーバーラップ**する。

| 期 | 時間範囲 | 主題 | 並列・重複 |
|:---:|:---:|:---|:---|
| 第1期 | 1910〜1917年 | キルンドライ・耐水合板・廃材乾留 | 単独 |
| 第2期 | 1917〜1926年 | フェノール積層材・絶縁板・初期傾斜密度 | 単独 |
| **第3期** | **1926〜1934年** | コンプレグ・樹脂自社合成・耐蝕ライニング | **第4期と並列** |
| **第4期** | **1926〜1934年** | ガラス繊維への着目・次素材探索 | **第3期と並列** |
| **第5期** | **1934〜1940年頃** | エポキシ〜GFRP・航空部門本格化 | **第6期前半とオーバーラップ（1936〜1940）** |
| **第6期** | **1936〜1942年頃** | CFRP完成・三層炭素素材体制 | **第5期後半とオーバーラップ（1936〜1940）** |

### 並列・オーバーラップの読み方

- **第3期と第4期は同一時間範囲（1926〜1934年）の並列カテゴリである**。第3期は「主業務として収益化されている事業」を、第4期は「次世代素材の探索・水面下研究」を、それぞれ別の側面から記述する。同年代の同一企業の活動を二つの焦点で切り分けたものである。
- **第5期と第6期は1936〜1940年でオーバーラップする**。第5期はエポキシ〜GFRP事業の本格化（1934年起点）、第6期はCFRP研究の起点（1936年）から実戦配備（1942年）までを扱う。1936〜1940年の期間は両方の文脈に属する。

### 財務文書における期区分の取り扱い

財務集計（Master_Parameters・Detailed_Growth_Simulation・Revenue_Model）は、年度ベースで売上を集計する都合上、本節の概念区分そのままを反映できない。以下のマッピング規約を適用する。

| 財務期 | カバー範囲 | 本節（概念区分）との対応 |
|:---:|:---|:---|
| 第1期 (1910-17) | F1全域 | 1:1対応 |
| 第2期 (1917-26) | F2全域 | 1:1対応 |
| **第3期 (1926-34)** | **F3+F4の財務出力合算** | F3とF4は並列のため、財務上は合算した1,200万円として計上する |
| **第4〜5期前半 (1934-37)** | **F5前半** | エポキシ・GFRP事業の立ち上げ期。日華事変（1937）末で年率3,500万円 |
| **第5期後半〜第6期前半 (1937-41)** | **F5後半 + F6中盤** | 軍需全開期。1941年末で年率8,500万円。1938年は両期の連続線上で内挿 |
| 第6期 (1942-) | F6後期 | CFRP実戦配備期。年率12,500万円 |

財務文書では、ECNタグ `REV_P3`〜`REV_P6` の数字とラベルを以下のように扱う。

- `REV_P3` = 第3期 (1926-34)：F3+F4の合算
- `REV_P4` = 第4〜5期前半 (1934-37)：F5前半に対応する財務ブロック
- `REV_P5` = 第5期後半〜第6期前半 (1937-41)：F5後半とF6前半をまたぐ財務ブロック
- `REV_P6` = 第6期 (1942-)：F6後期

### 各文書冒頭での参照ルール

期区分を参照する全文書は、冒頭に以下の一文を含める：

> 本資料の期区分は `Phase_Analysis.md §0`（期区分の正典定義）に従う。

財務集計を行う文書（Master_Parameters・Detailed_Growth_Simulation・Revenue_Model）は加えて以下を含める：

> 財務期のラベル（第3期・第4〜5期前半・第5期後半〜第6期前半・第6期）は §0 の財務マッピング規約に従う。

### 設計意図

第3期・第4期の並列構造は、主人公企業が「主業務で収益を上げながら同時並行で次世代素材を水面下で研究する」という二面性を表現する装置である。同様に第5期・第6期のオーバーラップは、エポキシ・GFRP事業を量産化しながらCFRPの研究を並走させる構造を反映する。これらの並列・重複は資料群の本質的な設計であり、整合化のために潰してはならない。

## 日本経済の大きな波（前提）

| 時期 | 経済状況 | 主人公への影響 |
|:---:|:---|:---|
| 1910〜14年 | 明治末〜大正初期。安定成長 | 木材業は堅調 |
| 1914〜18年 | **第一次大戦ブーム**。輸出急増、軍需景気 | **追い風**。合板・軍需材の需要爆発 |
| 1920〜22年 | **戦後恐慌**。物価暴落、企業倒産多数 | **逆風**。ただし必需品（織機部品）は底堅い |
| 1923年 | **関東大震災**。東京・横浜壊滅 | **復興需要**＝建築材・合板の特需 |
| 1927年 | 昭和金融恐慌 | 中程度の逆風 |
| 1929〜31年 | **世界恐慌**。日本は特に農村が疲弊 | 逆風。ただし軍需は拡大基調 |
| 1931年〜 | 満州事変→軍需拡大。高橋財政によるリフレ | **強い追い風**。軍需＋インフラ拡大 |
| 1937年〜 | 日中戦争→本格的な戦時経済 | **軍需全開**。民需は統制下に |

## 【第1期】木材乾燥・耐水合板（1910〜1917年）

| 分野 | 具体的な研究・製品 | 後の戦略技術への繋がり |
|:---|:---|:---|
| **木材防腐・防虫** | クレオソート処理、防腐剤の加圧注入 | 真空加圧含浸チャンバーの原型 |
| **天然塗料・ワニス** | 漆、柿渋、亜麻仁油ワニス | 「木材に液体を塗って硬化」の概念確立 |
| **接着剤全般** | 膠、カゼインなどの比較試験 | 接着剤の体系的な評価能力 |
| **木材加工機械** | ロータリーレース、プレス機の導入 | 「積層・プレス」システムの確立 |

### 収益性とR&D負担：◎ 自己資本で対応可能
- **収益**：キルンドライ高級材の利益率が高く、WWIブームが追い風となる。年商 [80万円]{{ECN:REV_P1}} 規模へ。
- **負担**：化学者の雇用はまだ不要。ボイラーやプレス機の設備投資も乾燥材の利益で十分回収可能。

### 商業・金融方針（第1期）
- **金融**：完全無借入・自己資本のみ。
- **宣伝**：直接B2B訪問のみ。木材商としての既存ネットワーク活用。
- **価格**：「狂わない高品質材」というプレミアムを材木商の業界相場から20〜30%上乗せで維持。

## 【第2期】フェノール積層材（1917〜1926年）

| 分野 | 具体的な研究・製品 | 利益率・市場 | 後の戦略への繋がり |
|:---|:---|:---|:---|
| **織機用シャトル** | ベークライト製シャトル | **極めて高い**。紡績工場独占 | 絶対的な安定収益源 |
| **フェノールワニス** | 液状品を塗料として販売 | 中。防錆・耐水用 | 塗料事業の起点 |
| **電気絶縁材** | フェノール紙積層板 | 中〜高。重電・通信向け | インフラ大市場の開拓 |
| **サイレントギア** | 布入りフェノール歯車 | 高い。金属歯車の代替 | 複合材の経験 |
| **傾斜密度の初期実装** | 含水率プロファイル操作によるプロペラブランクの粗い傾斜実現 | 高い。航空工廠向け | 真のコンプレグへの概念的基盤 |
| **フルフラル基礎** | 籾殻からの抽出実験（1920年代前半〜） | （純研究） | 戦時自給ルートの開拓・合成ゴム原料探索の起点 |

### 収益性とR&D負担：◎ 安定収益期
- **収益**：織機用シャトルが極めて高い利益を生み出す。年商 [400万円]{{ECN:REV_P2}} 規模に達し、現代価値で数十億円規模の安定基盤となる。
- **負担**：樹脂は三共から購入し、研究費は試作や小規模実験に留まるため、利益の数%程度で十分賄える。

### 商業・金融方針（第2期）
- **金融**：大正14〜昭和元年（株式会社化時）に地方銀行との取引を確立。
- **宣伝**：シャトル・積層絶縁板は「売れるから宣伝しなくてよい」状態。
- **価格**：シャトルは競合品比20〜30%高でも買われる。根拠は「交換頻度が半分以下」という実績。

| **合成ゴム原料研究** | フルフラル→ブタジエン経路（水面下） | （純研究。1931年以降本格化） | 天然ゴム代替の戦略的布石 |

### 耐蝕ライニング事業
- **開始時期**：1930〜1931年頃。世界恐慌期の収益下支えとして機能。
- **継続契約モデル**：昭和5〜6年の初期施工から「5年定期点検契約＋再施工優先権」のセット提案を標準化。「単発の施工販売」から「定期点検を伴う中長期の継続契約」へとビジネスモデルを転換。

### 1931年：合成ゴム事業ライン本格化
- **トリガー**：ソ連SKB工業生産発表 × 満州事変（ともに1931年）。
- **経営判断**：量産ゴム製品は「理研系スピンオフ企業等への資本参加・合弁化」によって展開し、自社の強みが生きる「特殊防振マウント・耐油ホース等」のみを自社工場で直接内製化する二段構え。
- **ABE→燃料国産化の打診**：ABE発酵由来ブタノールから100オクタン航空燃料原料が得られる可能性を、陸軍燃料部門・逓信省に「こういう可能性があります、一緒に検討しませんか」という形で情報提供開始。主人公のキャラクター（国内生産に貢献できるなら貢献する）と整合する。

### 収益性とR&D負担：○ 乗り越え可能
- **負担**：樹脂合成プラント建設 [80万円]{{ECN:CAPEX_RESIN_PLANT}} と化学者の増員。
- **収益**：世界恐慌でも消耗品需要で下支え。1932年以降は軍需拡大で年商 [1,200万円]{{ECN:REV_P3}} 規模へ急回復。

### 商業・金融方針（第3期）
- **金融**：DR-980購入 [120万円]{{ECN:CAPEX_DR980}} などの大型投資を銀行融資と自己資金で調達。
- **宣伝の基本方針**：コンプレグは公開、エポキシは秘匿。
  - 名古屋開府博覧会（昭和5年）：実績アピール
  - 昭和7〜8年：陸空技研への「サプライヤー」として出入り開始
- **代理商活用**：絶縁板などの量産品は商社経由。プロペラ等は直販。
- **工場見学制度**：三菱・石川島との信頼構築。

## 【第4期】ガラス繊維への着目（1926〜1934年・第3期と並列）

**※本期は §0 の正典定義に基づき、第3期（1926〜1934年）と同一時間範囲で並列に進行する次世代素材探索フェーズである。** 第3期が「主業務として収益化されている事業」を扱うのに対し、本期は「水面下で進行する次素材研究」を扱う。両者の財務出力は合算され `REV_P3` (1,200万円) として計上される。

- **研究内容**：各種天然繊維の積層試験、ドイツ産ガラスウールの評価、米国ガラス短繊維の実験、日東紡績への接触と資金援助。
- **収益性とR&D負担**：◎ 第3期の利益で容易に吸収。サンプルの取り寄せや日東紡への部分支援は、コンプレグやシャトルの利益で十分賄える少額投資。本期は独立した売上を持たず、研究投資のみが計上される。

### 商業・金融方針（第4期）
- **特許収益化**：昭和9〜10年頃からライセンス交渉準備。
- **日東紡合弁**：白金るつぼ等の大型投資 [2,500万円]{{ECN:CAPEX_PLATINUM}} を軍予算・銀行融資・日東紡等と分担。自社負担 [800万円]{{ECN:CAPEX_PLAT_SELF}} を利益で吸収。

| **萱場との可変ピッチプロペラ協業** | 油圧ハブ＋複合材ブレード | 高。プロペラ事業の高付加価値化 | 住友ハミルトン系への対抗 |

### 収益性とR&D負担：◎ 軍需拡大で利益は十分
- **収益**：日中戦争以降の本格的な戦時経済下で軍需が全開。
- **負担**：エポキシスケールアップやカップリング剤合成の設備投資が必要だが、軍需拡大に伴う利益がそれを吸収する。

### 商業・金融方針（第5期）
- **金融**：昭和12年以降の「軍需産業への優遇融資」環境を活用。設備増設・日東紡合弁追加投資を融資でまかなう部分を増やす。
- **国家総動員法対応（昭和13年〜）**：価格統制の対象になる前に主要顧客との長期供給契約を締結しておく。特に炭素電極・活性炭は軍の優先配分品目として管理される。
- **GFRPの公開範囲設計**：フェノール-ガラス積層板（公開版）は業界誌・展示会で積極的に紹介。エポキシGFRP（本番版）の化学的正体は軍との共同研究として秘匿を維持。

## 【第6期】CFRP完成（1936〜1942年頃・第5期後半とオーバーラップ）

**※本期は §0 の正典定義に基づき、第5期後半（1936〜1940年）とオーバーラップする。** 1936年からCFRP研究が水面下で進行し、1942年に実戦配備に至る発展段階を扱う。1936〜1940年の研究投資は第5期の事業利益で吸収され、財務上は `REV_P5` (第5期後半〜第6期前半 1937-41) に内包される。1942年以降の本格量産期は `REV_P6` (12,500万円) として独立計上される。

|:---|:---|:---|:---|

| **竹チョップドCF** | コンパウンド成形品・電極 | **中。** | 設備稼働平準化 |
| **炭素電極（拡大）** | 戦時アルミ製造急拡大対応 | **高。戦略物資** | 航空機製造との直接連動 |
| **GFRP継続** | 汎用軍需向け | **高** | 量産機への広範な供給 |

### 収益性とR&D負担：◎ 強固な収益基盤の確立
- **収益**：三層炭素素材体制の完成により安定した高収益。炭素電極・合成ゴム事業が戦略物資として急上昇。
- **負担**：CFRPの軍事機密化により特別会計からの調達価格が確保される。

### 商業・金融方針（第6期）
- **CFRPの特別会計扱い**：レーヨン系CFRPは軍事機密として秘密特許出願後、特別会計（軍の研究予算）から調達される。価格交渉は一般市場とは切り離した形で行われる。
- **炭素電極の戦略物資化**：「アルミニウム製造に必要な炭素電極」として国家指定戦略物資に準じた扱いを受ける。
