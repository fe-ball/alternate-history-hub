# 水上機・飛行艇向け事業戦略

本資料は、水上機・飛行艇というカテゴリに対する部材供給・完成機販売・海軍との関係構築を包括的に記述する。

---

## 1. なぜ水上機が「高い利得」なのか

### 海軍の水上機依存度

史実の日本海軍は開戦時に1,000機以上の水上機を運用しており、空母搭載機より数が多い。偵察・哨戒・対潜・救難・局地防空・水上基地からの攻撃と、用途が広大である。太平洋戦争の作戦環境は島嶼が点在する広大な海域であり、滑走路のない環境から運用できる水上機の戦略価値は陸上機以上に高い局面が多い。

### 複合材料と水上機の相性

水上機の最大の弱点は「重い」ことである。フロートや艇体の重量が空力性能を蝕む。複合材料による軽量化の恩恵は、陸上機以上に水上機で大きい。

加えて、フロート・艇体底面の耐海水性はコンプレグやGFRPの「水を吸わない」特性と直結する。木製フロートは海水を吸って日ごとに重くなり性能が劣化する。金属製フロートは海水腐食で寿命が短い。コンプレグ・GFRPフロートは両方の問題を構造材レベルで解決する。

### GFRP艇体の構造的革新

全金属製の飛行艇艇体をGFRPに置き換えると、重量削減だけでなく「艇体全体がレドームになる」（電波透過性）。これは対潜哨戒や水上索敵のレーダー搭載に直結する。

## 2. 販売可能な商材

### 2.1 コンプレグフロート（1933年〜）

水上機のフロート（浮舟）は、複合材料の恩恵が最も大きい航空部品の一つ。

**性能上の優位**：コンプレグフロートは吸水率1〜3%であり、木製フロートの30%超と比べて運用中の重量増加がほぼ発生しない。「海水に浸かっても重量が変わらない」という特性は水上機運用者にとって衝撃的。

**訴求点**：「整備頻度の低下」「稼働率の向上」「離水性能の安定」。

| 項目 | 値 |
|:---|:---|
| 単価 | [2,500円]{{ECN:PRICE_FLOAT_C}} (対) |
| 年間潜在需要 | 新規機体100〜200機分（200〜400本）＋交換用 |
| 年間実績供給 | 50〜100本（1933〜37年、海軍制式採用前の試験装着段階） |
| 年間売上 | [20万円]{{ECN:REV_P3_AVIA_FLOAT}} |
| 投入開始 | 1933年（実証開始） |

### 2.2 GFRPフロート（1938年〜）

シランカップリング完成後のエポキシ系GFRPフロート。コンプレグフロートのさらなる軽量化版。

**追加の優位**：GFRP中空構造によりコンプレグより30〜40%軽量。「電波を通す」特性により、フロート内にアンテナやセンサーを内蔵する将来発展性がある。

| 項目 | 値 |
|:---|:---|
| 単価 | [12,000円]{{ECN:PRICE_FLOAT_G}} (対) |
| 年間需要 | 高性能水偵・哨戒機向け |
| 年間売上 | [250万円]{{ECN:REV_P5_AVIA_FLOAT}} |
| 投入開始 | 1938〜39年 |

### 2.3 飛行艇向けGFRP艇体部材（1939年〜）

川西航空機（九七式大艇・二式大艇の製造元）への艇体部材供給。全艇体のGFRP化は量産性の制約があるが、艇体底面パネル（被波部）のGFRP化は実用的。

**訴求点**：被波による腐食問題の根本解決、底面パネルの軽量化（航続距離延長に直結）、電波透過性（対潜レーダーの艇体下面設置が可能に）。

| 項目 | 値 |
|:---|:---|
| 単価 | [5万円]{{ECN:PRICE_BOAT_PANEL}} (中型機分) |
| 年間需要 | 大型飛行艇の年間生産数に連動 |
| 年間売上 | [150万円]{{ECN:REV_P5_BOAT_PANEL}} |
| 投入開始 | 1939〜40年 |

### 2.4 完成水上機（フロート装着型）

自社航空部門でDR記録またはDR連絡ベースのフロート装着型を製造する。ディーゼル＋コンプレグフロートの組み合わせは、長距離哨戒用途への直接的な提案根拠になる。

機密度「低」の公開仕様機として、海軍航空関係者への実証飛行に使う。

| 機体 | 初飛行推定 | 構造 | 主目的 |
|:---|:---:|:---|:---|
| DR記録フロート装着版 | 1933〜34年 | コンプレグ主構造＋コンプレグフロート＋DR-980 | 「燃費1/12」を水上機で再現 |
| DR連絡・水 | 1935〜36年 | 麻FRP胴体＋コンプレグフロート＋DR-980 | 長距離水上哨戒への提案 |
| 四号・飛艇 | 1940〜41年 | GFRP艇体＋ディーゼル | 対潜哨戒・超長距離索敵 |

## 3. 海軍との関係構築

### 現行資料の弱点

現行の資料群は陸軍航空工廠との関係が中心であり、海軍との接点が薄い。水上機部材の売り込みは海軍航空本部・横須賀航空隊・追浜飛行場との関係構築を意味する。

### 接触の時系列

| 時期 | 動線 |
|:---|:---|
| 1931〜32年 | 陸軍航空工廠向けのプロペラ・パテ供給と並行して、海軍航空本部にもプロペラブランクと昭四号パテのサンプルを提出。「海軍機のプロペラにも同じ品質のものを」という直接的な提案 |
| 1933年 | DR記録の記録飛行データ（燃費1/12）を海軍航空本部にも共有。「水上哨戒にディーゼルは最適ではないか」という提案 |
| 1933〜34年 | DR記録フロート装着版の製作。海軍関係者を招いた水上離着水の実演。「海水に浸かっても重くならないフロート」は水上機部隊にとって革命的であり、強い関心が示されるのが自然 |
| 1934〜35年 | 海軍の既存水偵（九四式水偵等）へのコンプレグフロート試験装着の提案。機体は海軍が持っているもの、フロートだけ主人公企業が提供する形態 |
| 1935〜37年 | DR連絡・水による長距離水上飛行の実証。海軍の長距離哨戒任務への適性を実データで示す |
| 1937年〜 | 日華事変で海軍水上機の稼働率向上が急務に。コンプレグフロートの海軍制式採用を目指す。水上機1,000機超を運用する海軍にとって、フロートの吸水問題は慢性的な悩みであり、解決策が提示されれば採用圧力は強い |
| 1938〜39年 | GFRPフロートの試験供給開始。川西航空機との艇体部材供給交渉 |

### 海軍特有の訴求点

陸軍との交渉（「アルミ節約」「整備頻度低下」）に加え、海軍向けには以下が効く。

- **塩害耐性**：金属フロートの海水腐食は海軍の慢性問題。「腐食しないフロート」は維持費を劇的に下げる。
- **機雷・浮遊物への耐衝撃性**：コンプレグは金属より衝撃吸収性が高く、水面の浮遊物との衝突で凹みにくい。
- **電波透過性**（GFRP段階以降）：レーダーの搭載位置の自由度が増す。艇体そのものがレドームになるという概念は、海軍の電探開発部門にとって魅力的。

## 4. 川西航空機との関係

川西航空機は日本の飛行艇製造の唯一のメーカーであり、九七式大艇・二式大艇の設計・製造を担当している。

主人公企業が川西に対して提案できるのは艇体部材の供給と、GFRP構造設計の協業の両方である。川西には飛行艇の設計・製造ノウハウがあり、主人公にはGFRP構造の設計・製造能力がある。大型飛行艇については川西の設計主導＋主人公の部材供給が合理的だが、中型以下のGFRP飛行艇については主人公の自社設計もありうる（Aviation_Fleet_List.md参照）。

具体的には、底面パネル（プリカット済みGFRPシート）、フロートのコンプレグブランク、エポキシ接着剤キット（二液缶）、燃料タンクシーラントを「水上機向け素材パッケージ」として一括提案する。

## 5. 事業としての位置づけ

水上機関連事業は、コンポーネント販売の最も有望な拡大先の一つである。

- **フロートは消耗品に近い**（海水による劣化で定期交換が必要）→ 継続的な受注
- **海軍の水上機調達数は年間100〜200機**→ フロート需要だけで年間200〜400本
- **飛行艇は高単価**→ 艇体部材1機分で数千〜1万円の売上

航空部門全体の中での水上機関連の位置づけは、前回の議論で合意した「コンポーネント売上が最大の柱になる」構造の一翼を担う。

| 評価項目 | 評価 | 理由 |
|:---|:---|:---:|
| R&D必要性 | ○中程度 | フロートの水上離着水耐性試験は必要だが、素材技術自体は既存 |
| 起動コスト | ○中程度 | フロート装着型の試作＋水上離着水試験 |
| 収益性 | ◎高い | フロートは消耗品的に継続受注。飛行艇部材は高単価 |
| 戦略的価値 | ★★★高い | 海軍との関係構築。太平洋戦線に直接効く |
| 開始タイミング | 1933年（フロート試作） | DR記録の実績を土台にする |
