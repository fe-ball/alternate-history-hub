# 炭素素材の三層体制

> 原設定監査 source-audit-2：繊維E/密度と複合材の物性を区別。GFRPの比弾性率だけで構造用途を一律排除せず、同じ形状・荷重・環境で比較する。ピッチ系はE=150GPaの場合75〜79GPa・cc/gであり150ではない。高弾性グレードの研究は維持するが、3.8円/kgは限定費目の小計で認定長繊維の全原価ではない。25円/kgも歩留りに依存する。電極・活性炭・絶縁用途は別品質で、炭素化炉の共用時間・洗浄・歩留り・加工を二重に使わない。 根拠・留保は [原設定監査](../audit/SOURCE-AUDIT.md)（TECH-04、TECH-06）。

本ドキュメントでは、主人公企業が保有する炭素素材ラインナップを体系化し、各層の技術・経済・事業特性を詳述する。

---

## 1. 三層体制の概要

### なぜ「三層」か

炭素素材は一種類で全用途を賄えない。引張強度を最大化すると製造コストが高く量産できない。量産性を優先すると剛性か強度かのどちらかが犠牲になる。この矛盾を解決するのが用途別の役割分担である。

```
【第一層：強度層】レーヨン系CFRP（長繊維）
  → 最高の引張強度。少量・高価。特務機最重要部位。

【第二層：剛性層】メソフェーズピッチ系CF
  → 最高の弾性率（剛性）。量産可能・安価。翼スパー・量産機。

【第三層：量産補完層】竹チョップドCF
  → 廉価・大量。コンパウンド・炭素電極・設備稼働調整弁。
```

## 2. 第一層：レーヨン系CFRP（長繊維）

### 2.1 技術的特性

| 項目 | 値 |
|:---|:---|
| 前駆体 | レーヨン（再生セルロース）帝人・東洋レーヨン国産品 |
| 炭素化収率 | 約20%（5kgのレーヨン→1kgのCF） |
| 引張強度 | 700〜1000MPa |
| ヤング率 | 40〜60GPa |
| 比重 | 1.6〜1.7 |
| 比強度（強度/比重） | 超々ジュラルミン（400MPa/2.8）を大幅に超える |
| 製造原価 | 約25円/kg（昭和15年水準） |
| 量産性 | 限定的（張力下炭素化の精密制御が必要） |

### 2.2 製造プロセスの特殊性

```
張力下炭素化の精密制御：
  レーヨン糸を管状炉に通しながら
  ①温度プロファイルの厳密管理（昇温速度・保持温度）
  ②張力の精密制御（多すぎると糸切れ・少なすぎると強度低下）
  ③雰囲気ガス（窒素）の純度管理
  ④タール排出管理（保全コストの主因）

職人的技能：
  糸切れを防ぎながら適切な張力を維持するのは
  熟練した工員の技術が必要
  → 「職人なしの工業はない」の典型例
  → 習熟曲線により歩留まりが改善：初期60%→熟練後80%
```

### 2.3 用途の集中

希少性から「本当に必要な部位への集中投入」が戦略的に合理的：

| 部位 | 理由 |
|:---|:---|
| プロペラブレード | 高出力エンジンの遠心力に耐える引張強度が必須 |
| 特務機主翼桁 | 最高性能の構造材が求められる特務機・試作機 |
| 操縦系統部品 | 慣性重量の低減がレスポンスに直結 |

### 2.4 事業性

製造原価25円/kgはジュラルミン（2円/kg）の12倍以上。しかし：
- 軍の特別会計は性能向上のための高コストを許容できる
- 「航空機の限界性能を引き上げる特殊用途素材」という位置づけ
- 軍事機密として秘密特許出願・非公開維持

## 3. 第二層：メソフェーズピッチ系CF

### 3.1 メソフェーズピッチとは

コールタールピッチを380〜450°Cで加熱すると、炭素分子が液晶的な秩序構造（メソフェーズ）を形成した状態になる。これを紡糸・炭素化すると高弾性率の炭素繊維が得られる。

```
コールタールピッチ
  ↓ 380〜450°C加熱（メソフェーズ化）
メソフェーズピッチ（液晶的秩序構造）
  ↓ 溶融紡糸（300〜350°C）
ピッチ繊維
  ↓ 酸化安定化（200〜300°C・空気中）
  ↓ 炭素化（1000〜1500°C・不活性雰囲気）
高弾性率炭素繊維
```

### 3.2 技術的特性

| 項目 | 値 |
|:---|:---|
| 前駆体 | コールタールピッチ（コークス炉副産物・安価・大量） |
| 炭素化収率 | 80〜85%（レーヨン系の4倍以上） |
| 弾性率 | 150GPa以上という繊維グレード仮定。アルミの6倍という比較は撤回 |
| 引張強度 | 製品グレード・欠陥・工程に依存。前駆体の種類だけでレーヨンより低いとは断定しない |
| 比弾性率 | E=150GPa、密度1.9〜2.0なら75〜79GPa・cc/g（アルミ25の約3倍）。150以上を狙う高グレードはE約285〜300GPa以上が必要で別評価 |
| 比重 | 約1.9〜2.0 |
| 製造原価 | 約3.8円/kg（レーヨン系の1/6以下） |
| 量産性 | 高い（溶融紡糸・張力制御がレーヨン系より容易） |

### 3.3 GFRPの残された問題を解決する

ここで比較する比弾性率は同一グレード・方向・材料単位で揃える。GFRPの参考値20とアルミ25という比だけで、完成構造の重量・剛性や用途の不可能性は決められない。

```
比弾性率の比較：
  GFRP：約20GPa・cc/g（ジュラルミン25を下回る）
  ジュラルミン：25GPa・cc/g（基準）
  レーヨン原繊維：約23.5〜37.5GPa・cc/g（CFRP積層材は別測定）
  ピッチ原繊維：E=150GPaなら75〜79GPa・cc/g、高グレードは別評価

フラッター速度への影響：
  フラッター速度∝√(弾性率×断面2次モーメント/質量)
  ピッチ系CF翼スパー採用で：
  同重量比でフラッター速度が大幅向上
  → 急降下制限速度が構造的に引き上げられる
```

### 3.4 主人公のアリバイ（外形的必然性）

```
フェノール自社合成ライン → 石炭化学との接点
  ↓
コークス炉副産物（コールタールピッチ）へのアクセス
  ↓
炭素電極研究（1936年〜）の中での探索
  ↓
「ピッチを特定条件で処理すると繊維状になる」という発見
  ↓
「これはロータリーキルンで炭素化できる」という接続
```

### 3.5 事業性

| 項目 | 値 |
|:---|:---|
| 製造原価 | 3.8円/kg |
| 翼スパー1機分 | 35〜40kgの全質量×繊維単価という旧152円の見積りは撤回。繊維含有質量、樹脂、加工、検査、歩留りを分けた完成品原価が未算定 |
| 量産機500機への供給コスト | 約76,000円 |
| 軍への提案価格 | ジュラルミン代替として適正利益を乗せて |

ジュラルミン翼スパーとの重量・性能比較で価値を提示できる。量産可能な価格帯であり、広範な採用が現実的。

## 4. 第三層：竹チョップドCF

### 4.1 製造フロー

```
竹生材（孟宗竹・真竹：全国自生・放置すると山林侵食）
  ↓ アルカリ蒸解（苛性ソーダ・既存オートクレーブ転用）
  ↓ ヘミセルロース・リグニンを除去
セルロース繊維（均一な炭素化挙動）
  ＋ 蒸解廃液（フルフラル回収可能）
  ↓ ロータリーキルン（バッチ式・張力制御不要）
  ↓ 炭素化（600〜1200°C・窒素雰囲気）
竹チョップドCF（長さ数mm〜数cm）
```

### 4.2 コスト試算（CF 1kgあたり）

| 項目 | 金額 |
|:---|:---|
| 竹生材（12.5kg分） | 約1.5円 |
| 苛性ソーダ等薬品 | 約1.0円 |
| 電力（炭素化） | 約1.5円 |
| ロータリーキルン保全 | 約1.5円 |
| **合計** | **約5.5円/kg** |

レーヨン系25円/kgの1/4以下。大量生産に向く。

### 4.3 副産物：竹廃液フルフラル

```
アルカリ蒸解廃液にはヘミセルロース分解物が含まれる
  ↓ 希硫酸処理
フルフラル（籾殻ルートと同一品質）

意義：
  竹チョップドCFの生産量に連動したフルフラルが副産物として得られる
  フルフラルラインの稼働率を「年中安定」にする
  （籾殻ルートの農閑期集中を補完）
```

### 4.4 用途

**CFRPコンパウンド成形品**
```
竹チョップドCF + フェノール/エポキシ樹脂
  ↓ 金型プレス成形
高強度・耐熱コンパウンド成形品

木粉入りベークライトとの比較：
  強度：大幅向上
  耐熱性：改善
  精度：寸法安定性が高い

製品例：
  航空機計器盤パネル
  スイッチボックス・リレーハウジング
  耐熱構造ブラケット
  高強度小型歯車

販売価格：10〜15円/kg（木粉ベークライト1〜2円/kgに対して大幅プレミアム）
```

**炭素電極との混合**
```
ピッチ系バインダー + 竹チョップドCF
  ↓ プレス成形→高温焼成
高品質炭素電極

用途：アルミ電解製錬・電気炉製鋼
戦時意義：航空機製造はアルミ需要が爆発的拡大
         → 炭素電極は航空機製造の基盤を支える位置
```

### 4.5 設備稼働率平準化の仕組み

```
レーヨン系炭素化炉の稼働状況：
  精密制御が必要なため常時フル稼働は困難
  炉全体の稼働率：推定60〜70%

空き時間への竹チョップドCFの投入：
  張力制御が不要 → 段取り時間最小
  空き時間をほぼ無駄なく埋められる

経済的効果：
  炉の減価償却費・窒素ガス設備費を竹系と按分
  → レーヨン系CFの実質製造原価が低下
  → 全体の収益性が向上
```

## 5. 炭素電極事業

### 5.1 位置づけ

炭素電極は「CFRPのただ乗り」ではなく「CFRPへの梯子の一段」として機能する。

```
炭素化技術の習熟順序：
  ①木炭・炭焼き知識（1920年代から）
  ②竹チョップドCF（1935〜）← この段階で商業化
  ③炭素電極（1936〜）← ②の直接応用
  ④レーヨン系CFRP（1936〜38）← ①〜③の上に完成
```

### 5.2 市場

| 用途 | 需要の性質 |
|:---|:---|
| アルミニウム電解製錬陽極 | 戦時アルミ増産に直結・大量需要 |
| 電気炉製鋼電極 | 重工業基盤・安定需要 |
| アーク灯炭素電極 | 灯火管制前の照明・逓信用途 |

アルミ電解製錬は特に重要。日本の航空機製造拡大はアルミ需要の爆発的増加を意味し、アルミ製錬に必須の炭素電極の需要も連動して拡大する。

### 5.3 製造

竹チョップドCFをロータリーキルンで製造し、バインダー（コールタールピッチ）と混練→金型プレス→高温焼成（2000〜2500°C）。

高温焼成炉は追加設備が必要だが、炭素化ラインとの相乗で投資効率が高い。

## 6. 活性炭事業

### 6.1 製造

```
竹チョップドCFまたは炭素化品
  ↓ 水蒸気活性化（800〜1000°C）
  　　細孔（マクロ・ミクロ孔）が形成される
活性炭（比表面積500〜1500m²/g）
```

既存炭素化炉の後段に活性化炉を追加するだけで製造可能。追加投資は最小限。

### 6.2 用途と需要

| 用途 | 需要の確実性 | 備考 |
|:---|:---:|:---|
| 防毒マスクフィルター | ★★★ | 毒ガス戦に備えた全軍需要。確実 |
| 水道精製・浄水 | ★★ | 都市部インフラ向け安定需要 |
| 食品精製（砂糖・油脂） | ★★ | 食品工業向け |
| 溶剤回収 | ★ | 化学工場での有機溶剤回収 |
| 医薬・化学分析 | ★ | 精製・クロマトグラフィー |

防毒マスクフィルターは「軍との取引実績の窓口」としても機能する。

## 7. 三層体制の全体統合図

```
【原料・前駆体の多様化】
  籾殻（フルフラル→竹廃液と二重化）
  レーヨン（帝人・東洋レーヨン）
  コールタールピッチ（コークス炉）
  竹生材（全国自生・ほぼ無償）

【三層炭素素材体制】
  強度層：レーヨン系CFRP ─────────→ 特務機プロペラ・最重要構造部
  剛性層：ピッチ系CF ────────────→ 翼スパー・量産機剛性部材
  補完層：竹チョップドCF ──────────→ コンパウンド・炭素電極・稼働調整

【副産物・関連事業】
  炭素電極（竹系炭素化の応用）→ アルミ電解・電気炉向け
  活性炭（炭素化後処理）→ 防毒マスク・精製用途
  竹廃液フルフラル → フルフラルライン二重化
  散布兵器用低グレード品（全層の端材・粉塵・規格外品）→ 導電性繊維散布兵器

【設備共用・固定費分散】
  レーヨン系炉 ─→ 空き時間に竹チョップドを流す
  ロータリーキルン ─→ 竹CF・炭素電極を大量処理
  全炭素化設備 ─→ 固定費を三層で按分
```

| 竹パルプ系 | ◎ | 8%（生材比） | 安価・大量生産向き | 5.5円/kg | チョップド・電極・補完 |
| レーヨン系 | ◎ | 20% | 高引張強度（700〜1000MPa） | 25円/kg | 特務機・プロペラ |
| 酢酸セルロース | ○ | 25〜30% | レーヨン+α（改善幅小） | レーヨン同等 | 保険・代替用 |
| メソフェーズピッチ系 | △ | 80〜85% | 高弾性率（圧倒的） | 3.8円/kg | 翼スパー・量産機 |
| PAN系 | OPTION | 未算定 | 溶液紡糸の代替経路を含む研究候補 | 未算定 | 基準財務には未収録 |

PANを通常の溶融紡糸にそのまま使うのは難しいが、「DMF/DMSOがないから到達不可能」は撤回する。塩水系など別の溶液紡糸経路がある（[1962年公報](https://patents.google.com/patent/US3061402A/en)）。これは1930年代に設備が揃った証拠ではない。前駆体の純度・重合・紡糸・安定化・炭素化・回収設備・品質を検討する追加研究OPTIONとし、レーヨン/ピッチ/竹の既存計画を取り消さない。未来知識による前倒しも史実年だけでは排除しない。

## 9. 派生出力：散布兵器用低グレード品

三層体制の全層から発生する端材・粉塵・規格外品を、導電性散布材として軍事転用する。構造材としての性能は不問であり、導電性のみが求められるため、等方性ピッチからの低温炭素化品（600〜800°C）でも十分。製造原価は0.8〜1.5円/kgであり、構造用CFの副産物として追加コストほぼゼロで得ることも可能。

敵の電力・レーダー・通信系統を非破壊で機能麻痺させる「ソフトキル」兵器の素材となる。詳細はConductive_Fiber_Dispersal.md参照。
