# 台湾バガスからのフルフラル・ABE原料統合

本ドキュメントは、台湾のサトウキビバガスを原料とするフルフラル生産と、台湾のABE発酵事業との物質循環の可能性を記述する。第6期以降の拡張オプションとして位置づける。

---

## 1. 台湾バガスの潜在量

台湾は1895年から日本の領土であり、1930年代には世界有数のサトウキビ産地であった。台湾製糖（三井系）・明治製糖・大日本製糖・塩水港製糖など日本資本の製糖会社が多数操業し、サトウキビの年間圧搾量は数百万トン規模に達した。

圧搾後のバガス（繊維質の搾り粕）は圧搾量の約25〜30%にあたり、年間100万トン以上が発生する。バガスのヘミセルロース含有率は20〜33%であり、フルフラル収率は乾燥重量の約8〜12%。台湾のバガス100万トンからの理論的フルフラル潜在量は8〜12万トン/年であり、これは主人公の全社内需要の50〜100倍に相当する。

バガスの大部分はボイラー燃料として製糖工場内で焼却されるが、全量が焼却に使われるわけではなく、一部は余剰として野積みされる。余剰バガスからフルフラルを抽出し、残渣をボイラーに戻すことで、製糖会社の燃料効率を落とさずにフルフラルを回収できる。

---

## 2. 台湾ABE工場との地理的近接

史実において台湾は日本のABE発酵事業の最大拠点であった。台湾拓殖化学工業が運営する嘉義工場は極東最大のABE発酵施設であり、170,000リットル発酵槽92基を擁した。1943〜44年には年産約5,500トンのソルベント（アセトン＋ブタノール＋エタノール）を生産した。

嘉義工場の原料は当初サツマイモ、1943年以降はサトウキビ搾汁に転換された。つまり台湾のABE発酵はサトウキビ産業と密接に結びついており、バガスフルフラル事業との地理的・原料的な統合が物理的に可能である。

---

## 3. 物質循環の設計

バガスの酸加水分解からは、フルフラルだけでなく複数の有価物が同時に回収できる。

```
サトウキビバガス
  ↓ 希硫酸＋高温高圧
  ├─ フルフラル（ヘミセルロース由来・C5糖の脱水）
  ├─ キシロース（フルフラルに転換しなかった残余C5糖）
  ├─ 酢酸（ヘミセルロースのアセチル基由来）
  └─ セルロース残渣（ボイラー燃料に戻す、またはバガスパルプ化）
```

### キシロースのABE発酵への転用

フルフラル抽出の前段階で得られるキシロース（木糖）は、直接フルフラルに転換せずにABE発酵の原料糖として使用できる。Clostridium acetobutylicumの一部の株はキシロースを発酵可能であり、ABE発酵の主原料（デンプン・スクロース）に補助的に混合する形で利用できる。

この経路の戦略的意義は大きい。ABE発酵の最大の社会的問題は「食料と競合する原料を燃料に使う」ことであり、キシロースの活用はこの競合を構造的に緩和する。バガスは食用にならない廃棄物であり、そこから得られるキシロースでブタノールを作れば「食料を燃料に回していない」と主張できる。

### 酢酸の回収

バガスの加水分解で生じる酢酸はセルロースアセテート（航空機ドープ材）の原料として社内消費可能。台湾で回収した酢酸を本土に輸送する物流が成立すれば、廃材乾留ラインからの酢酸供給を補完する。

## 4. 実装のタイミングと手順

### 前提条件

王子合弁の成功（1935年頃）でフルフラル事業の実績が確立された後に着手する。台湾の製糖会社への打診は第5期後半（1937〜38年頃）に開始し、台湾フルフラル工場の稼働は1939〜40年を目指す。

### 接触先

台湾製糖（三井系）が最も自然な接触先。主人公企業が三共（三井系のフェノール樹脂メーカー）との歴史的な取引関係を持っている場合、三井グループ内の紹介で話が始まる。

### 投資規模

蒸留設備1基の投資額は推定5,000〜10,000円。台湾の低い労賃と原料費ゼロ（バガスは廃棄物）により、年間200〜500トンのフルフラルを生産すれば2〜3年で投資回収が見込まれる。

### 委任

台湾への出張交渉は専務または取締役に委任可能。社長の直接負担は「指示を出す」段階に限定される。

## 5. 王子ルートとの比較

| 項目 | 王子廃液ルート | 台湾バガスルート |
|:---|:---|:---|
| 年間潜在量 | 1〜3万トン | 8〜12万トン |
| 実現速度 | 中（合弁交渉要） | 中（現地設備要） |
| 物流 | 本土内完結 | 台湾→本土の海上輸送要 |
| 副産物 | リグノスルホン酸塩・酢酸・メタノール | キシロース（ABE原料）・酢酸・バガスパルプ |
| リスク | 低 | 中（海上輸送途絶リスク） |
| ABE発酵との接続 | なし | **キシロースの原料転用が可能** |

二大系統を保持することで、いずれかが途絶した場合の供給安全保障が飛躍的に強化される。

---

## 6. 総合評価

台湾バガスルートは「今すぐ必要」ではないが、王子廃液ルートだけでは対応しきれないフルフラル増産圧（合成ゴム需要の爆発・ディーゼル添加剤の量的拡大・鋳造バインダーの軍需）に備える拡張オプションとして、第6期以降の戦略的価値は高い。特にABE発酵のキシロース原料転用による「食料との競合緩和」は、国策としてのABE事業の正当性を強化する波及効果を持つ。
