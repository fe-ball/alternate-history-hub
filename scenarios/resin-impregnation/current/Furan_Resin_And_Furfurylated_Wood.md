## 1. フルフラルから何が作れるか（樹脂の種類と特性）

フルフラル（furfural, C₅H₄O₂）は籾殻などのヘミセルロースから得られるアルデヒドであり、そこから複数の系統の樹脂・化学品を誘導できます。

### フルフラルの全派生経路図

```
フルフラル
  │
  ├──【軽度還元】────────→ フルフリルアルコール（FA）
  │                              ├──→ フラン樹脂（FA自己重合・酸触媒）
  │                              └──→ フルフリル化木材
  │
  ├──【強度還元（完全水素化）】→ テトラヒドロフラン（THF）
  │                              ├──→ 溶剤用途
  │                              └──→ 開環・脱水
  │                                      └──→ 1,4-ブタンジオール
  │                                              └──→ ブタジエン（脱水）
  │                                                      └──→ 合成ゴム（重合・加硫）
  │
  ├──【フェノール共縮合】────→ フルフラル-フェノール共縮合樹脂
  │                              （耐酸性強化・ホルマリン使用量削減）
  │
  └──【ケトン共縮合】──────→ フルフラル-アセトン樹脂
                                 （耐熱バインダー・鋳造用）
```

### A. フルフラル-ホルムアルデヒド共縮合樹脂
*   **合成**: フルフラル＋ホルマリン（ホルムアルデヒド水溶液）を酸触媒で縮合重合。
*   **難易度**: 低。フルフラルさえ手に入れば、フェノール樹脂とほぼ同じ設備・手順で合成可能。
*   **特性**: フェノール樹脂に似た熱硬化性。耐酸性がフェノール樹脂より顕著に高い。
*   **問題**: 硬くて脆い傾向。木材含浸用としては「浸透性」に難あり（分子量の制御が難しい）。

### B. フルフラル-フェノール共縮合樹脂
*   **合成**: フルフラル＋フェノールを酸または塩基触媒で縮合。ホルムアルデヒドの代わりにフルフラルを架橋剤として使用。
*   **難易度**: 低〜中。主人公がフェノール樹脂に慣れていればほぼ直感的に到達可能。
*   **特性**: フェノール樹脂の強度とフランの耐薬品性を兼ね備える。フェノール樹脂より暗色（黒褐色）になる。
*   **戦略的価値**: ホルマリンの使用量を減らせるため、供給の自由度が上がる。三共からホルマリンを買わずに済む可能性がある。フェノール自社合成ラインとの自然な合流として1920年代後半から量産化できる。

### C. フルフリルアルコール樹脂（ポリフルフリルアルコール）
*   **合成**: フルフラルを水素添加（還元）してフルフリルアルコール（FA, C₅H₆O₂）を得る。これを酸触媒で自己縮合重合させる。
*   **難易度**: **高い。ここが最大のボトルネック。**（詳細は後述）
*   **特性**: これが「フルフリル化木材（現代のKebony等）」に使われる本命の樹脂。低粘度の液体として木材に含浸させ、内部で重合・硬化させると、木材の細胞壁成分に化学的に結合して不可逆的に安定化する。耐水性・寸法安定性・耐腐朽性が飛躍的に向上し、外見は深い褐色〜黒色になる。
*   **問題**: フルフリルアルコールの工業的合成が1920年代の主人公にとって容易ではない（後述）。

### D. フルフラル-ケトン（アセトン等）共縮合樹脂
*   **合成**: フルフラル＋アセトンを塩基触媒でアルドール縮合させる。
*   **難易度**: 中。アセトンは当時から入手可能（ABE発酵由来も含む）。
*   **特性**: 耐熱性に優れ、鋳造用のバインダーや耐火煉瓦の接着に適する。木材含浸向きではないが、工業用途として広い。

## 2. フルフリルアルコール（FA）の合成：最大のボトルネック

フルフリル化木材の主役となるFAの合成は、フルフラルの「カルボニル基（C=O）」を「ヒドロキシメチル基（CH₂OH）」に還元する反応であり、これには**水素添加（接触還元）**が必要です。

### 史実の技術到達点
*   **1930年代**: 米国のアドキンズ（Adkins）が銅クロマイト（CuCr₂O₄）触媒によるフルフラルの水素添加法を確立。これが工業標準となった。
*   **1920年代**: 触媒による接触水素添加自体はサバティエ（1912年ノーベル賞）以降の技術だが、フルフラルに対する高効率な触媒は未確立。

### 主人公が1920年代にFAを得るための現実的ルート

1.  **マイスナー＝ポンドルフ＝バーレー（MPV）還元**（1925年頃〜）
    *   アルミニウムイソプロポキシドと2-プロパノール（イソプロピルアルコール）を使い、フルフラルのアルデヒド基を穏やかに還元する手法。水素ガスや高圧装置が不要。
    *   主人公の知識があれば1920年代後半に実行可能。ただし大量生産にはスケール上の課題あり。

2.  **カネッツァーロ反応**
    *   フルフラルを濃い水酸化ナトリウム中で自己還元させる。フルフラル2分子のうち1分子がフルフリルアルコールに、もう1分子が2-フランカルボン酸になる（つまり収率は最大50%）。
    *   低収率だが設備は極めて簡素。初期の実験・少量生産には十分。

3.  **接触水素添加（未来知識）**
    *   主人公が「銅系触媒＋水素ガス＋高圧」の組み合わせを知っていれば、1920年代後半に自作可能。水素ガスは水の電気分解で得られる。銅触媒は自作可能。ただし高圧水素系の設備は危険で高価。

### 現実的な着地点
*   **1920年代前半**: カネッツァーロ反応で少量のFAを実験的に合成し、フルフリル化木材（含浸＋酸触媒硬化）の「原理検証（PoC）」を行う。
*   **1920年代後半〜**: MPV還元またはアドキンズ型触媒の自作により、FA合成をスケールアップ。フルフリル化木材の本格的な量産に移行。

## 3. フルフリル化木材の強み

フルフリルアルコール（FA）を木材に含浸させ、酸触媒（マレイン酸や乳酸等）の存在下で100〜120℃に加熱すると、木材の内部でFAが重合し、セルロースやリグニンと化学的に結合（グラフト重合）します。これにより得られる「フルフリル化木材」は、フェノール樹脂含浸木材（コンプレグ）とは異なる独自の優位性を持ちます。

### フェノールコンプレグとの比較

| 特性 | フェノールコンプレグ | フルフリル化木材 |
|:---|:---|:---|
| **原料供給** | フェノール＋ホルマリン（化学工業品） | 籾殻・製紙廃液・竹廃液→FA |
| **原料の戦時入手性** | 石炭化学に依存。戦局悪化時には優先配分の影響を受ける可能性がある | 三重化されたサプライチェーンにより高い供給安定性 |
| **ホルムアルデヒド毒性** | ホルマリン使用（作業者の健康リスク） | 不使用（FAの自己重合） |
| **耐酸性** | 良好 | **極めて優秀**（化学プラント用途で独壇場） |
| **寸法安定性** | 優秀 | **同等以上**（細胞壁への化学的結合のため） |
| **外観** | 暗褐色〜黒色 | 深い褐色〜黒色（熱帯銘木に類似） |
| **環境・毒性** | フェノール・ホルマリンは有毒 | 比較的低毒性（植物由来） |
| **リバースエンジニアリング** | 「フェノール樹脂が入っている」ことは化学分析で判明 | フランの化学分析自体が当時は未発達なため、**正体の特定が極めて困難** |

### フルフリル化木材の特筆すべき強み

1.  **分析困難な高性能材**
    *   フルフラル自体は公知の工業化学品だが、フルフリルアルコールの木材含浸という用途は主人公の独自到達。フルフリルアルコールの重合体は当時の化学分析（定性分析）では「得体の知れない有機物が木と一体化している」としか判明せず、正体の特定が著しく困難。フルフラルを知っていてもフルフリル化木材には到達できない。
2.  **三重化サプライチェーン**
    *   籾殻（保険・品質基準）・竹廃液（CF連動・通年）・王子製紙廃液（主力量産）の三ルートにより、いずれかが途絶した場合でも供給が継続できる。
3.  **「生きた木」への非破壊的強化**
    *   コンプレグは高圧プレスで木材を潰す（密度を上げる）工程を伴うが、フルフリル化は「含浸して加熱するだけ」で木材の形状やサイズをほぼ変えずに内部を強化できる。プロペラのような複雑な形状の部品や、大型の建築材・船材にも無変形で適用可能。

## 4. フルフラル原料の三重化：籾殻・竹廃液・製紙廃液

### 第一ルート：籾殻（農業廃棄物）

```
籾殻（精米後の廃棄物）
  ↓ 希硫酸＋高温高圧
フルフラル
```

主人公が1922年に着手した最初のルート。フルフラルは1922年の米国クエーカーオーツ社の量産開始以来、完全に公知の工業化学品であり、籾殻からの抽出プロセスに秘密の余地はない。このルートの存在意義は「技術的起源としての独立性」と「蒸留設備の操業訓練・品質基準維持」にある。年産50〜100トン規模。農閑期・精米シーズンへの依存という稼働率の季節変動問題がある。

### 第二ルート：竹蒸解廃液（炭素繊維前駆体の副産物）

竹を炭素繊維原料として利用する工程（竹パルプ化）の蒸解廃液には、ヘミセルロース分解物が豊富に含まれる。

```
竹生材
  ↓ アルカリ蒸解（苛性ソーダ・既存オートクレーブ流用）
セルロース繊維（炭素繊維前駆体として利用）
  ＋
蒸解廃液（ヘミセルロース含有）
  ↓ 希硫酸処理
フルフラル（回収可能）
```

炭素繊維生産ラインに連動して通年稼働。追加コストは竹CF製造原価5.5円/kgの4〜5%（0.2〜0.3円）にすぎず、回収しないと廃液処理コストが別途発生するため回収が合理的。年産50〜150トン規模。

### 第三ルート：王子製紙との廃液連携（主力量産）

亜硫酸パルプ（SP）工場の蒸解廃液からフルフラルを回収する。詳細は `Oji_Paper_Collaboration.md` 参照。

```
SP蒸解廃液（製紙工場から引き取り）
  ├─ ペントース（キシロース等）→ 酸処理 → フルフラル
  ├─ リグノスルホン酸塩 → 外販（コンクリート分散剤・なめし剤）
  └─ 酢酸・メタノール → 社内消費（セルロースアセテート・トランスエステル化）
```

王子製紙は1933年の三社合併後に国内紙生産シェア約80%を占め、SP年産は26万トン（1933年）〜52万トン（1940年）に達する。SP 1トンあたりのフルフラル潜在量は40〜60kgであり、理論的な潜在量は年間1〜3万トン。主人公の処理能力の拡大速度がボトルネックとなるが、前加水分解方式の導入により第5期後半で年産800〜2,000トン、第6期で1,000〜3,000トンが見込まれる。

前加水分解方式は王子側にも明確な利益をもたらす。ヘミセルロースを事前に除去したチップからはアルファセルロース含有率が向上し、レーヨン向けディソルビングパルプ（DP）としての品質が改善される。DPは通常のSPより高値で取引されるため、王子にとって製品の付加価値向上に直結する。

### 三重化の効果

| 原料ルート | 稼働パターン | 年産規模（第5期後半） | 役割 |
|:---|:---|:---|:---|
| 籾殻 | 農閑期・秋〜冬集中 | 80〜120トン | 保険・品質基準 |
| 竹廃液 | 炭素繊維生産に連動・通年 | 50〜150トン | CF連動・稼働調整 |
| 王子廃液 | 製紙工場に連動・通年 | 800〜2,000トン | **主力量産** |

三重化により、フルフラルの年間稼働率の季節変動が構造的に解消されるだけでなく、供給量そのものが桁違いに拡大し、フルフラル派生の全事業（フラン樹脂・フルフリル化木材・THF→ブタジエン・耐蝕ライニング・ディーゼル添加剤・鋳造バインダー）が設備容量に制約されにくくなる。

なお、フルフラル自体は公知の工業化学品であり、製造・使用を秘匿する必要はない。主人公企業がフルフラルを大量に製造・使用していることは公開してよく、王子との合弁が成立すれば当然公知になる。秘匿の対象はフルフラルの「下流の使い方」——フルフリル化木材の含浸プロセス、THF→ブタジエン経路、ディーゼル添加剤——に限られる。

## 5. 合成ゴム原料（ブタジエン）への経路

### フルフラルルート（第一経路）

フルフラルの強度還元（完全水素化）により、合成ゴムの原料であるブタジエンへのアクセスが可能となる。

```
フルフラル
  ↓ 強度水素添加（Ni系触媒・高圧水素）
テトラヒドロフラン（THF）
  ↓ 酸触媒で開環
1,4-ブタンジオール
  ↓ 脱水
ブタジエン
  ↓ 理研等との合弁会社、および自社特殊部門にて重合・加硫
合成ゴム（ブナゴム相当・防振特殊ゴム）
```

### ABE発酵ルート（第二経路）

```
ABE発酵ブタノール
  ↓ 脱水反応（Al₂O₃触媒・約350〜400℃）
ブタジエン
```

## 6. 耐蝕ライニング事業

フラン樹脂の極めて高い耐酸性を化学プラント向けに商業展開する事業。詳細はCorrosion_Resistant_Business.md を参照。

### 事業の本質

```
既存のフラン樹脂（耐酸性が高い）
  ↓ 「化学プラントの容器内張りに使え」という営業指示
耐蝕ライニング事業（技術的新規性なし・即時収益化）
```

主要顧客：化学工場・硫酸工場・発酵工場・火薬工場・電鍍工場
開始時期：1930〜1931年頃（世界恐慌期の収益下支えとして機能）

## 7. 主人公の実行能力（タイムライン別）

### 1920年代前半：フルフラルの抽出と初期応用
*   **確実に可能**: 籾殻＋希硫酸＋オートクレーブ（既存の蒸気釜を流用可能）でフルフラルを蒸留抽出する。この工程は1920年代のアメリカと同等水準。
*   **確実に可能**: フルフラル-フェノール共縮合樹脂の合成（前述B型）。フェノールワニスの代替・補助として積層材に使用開始。ホルマリン依存の軽減。
*   **実験段階**: カネッツァーロ反応で少量のFAを合成し、小さな木材サンプルでフルフリル化の原理検証。

### 1920年代後半：FAの本格合成とフルフリル化木材の開始
*   **可能**: MPV還元またはアドキンズ型銅触媒によるFA合成のスケールアップ。月産数十〜百kg単位のFA供給体制の確立。
*   **可能**: 大型の含浸タンクでのフルフリル化木材の量産開始。プロペラ・軸受・構造材向け。

### 1930〜1931年：事業の多角化
*   **耐蝕ライニング事業の開始**（フラン樹脂の市場展開）
*   **合成ゴム原料ラインの研究開始**（ソ連発表がトリガー）

### 1930年代：フルフリル化＋GFRP/CFRPとの融合
*   **最終形態**: FA樹脂をガラス繊維や炭素繊維のマトリックス（母材）として使用する「フラン系FRP」。フェノール系FRPやエポキシ系FRPと並ぶ第三の選択肢として、特に耐酸性・耐熱性が要求される分野（化学プラント構造材、航空機のエンジン周辺部品）で最高の性能を発揮。
*   **竹廃液フルフラルの確立**（炭素繊維生産との相乗）
*   **国家備蓄インフラへの貢献**: フルフリル化木材やフランFRPの巨大なアドバンテージは、「鉄柱や鋼板を一切使わずに、巨大な耐食性密閉タンク（地下備蓄槽やサイロ）」を建造できることにある。軍需で逼迫する鋼材（鉄）を使わずに、火薬工場の強酸反応槽や航空燃料の地下備蓄タンクを量産・設置する事業は、主人公の企業に「国家の継戦能力を下支えするインフラ特需企業」としての絶対的な地位をもたらす。

## 8. まとめ：物語上の位置づけ

フラン樹脂とフルフリル化木材は、主人公の技術体系において以下の役割を果たす。

1.  **ホルマリン依存の軽減**: フェノール樹脂の架橋成分をホルムアルデヒドからフルフラルに一部代替することで、原料の自給度が上がる。この化学的検討から出発した研究が事業に成長した。
2.  **将来の保険としての生命線**: 石炭化学の供給が逼迫する局面では「最後まで作れる複合材料用樹脂」として決定的な価値を持つ。
3.  **分析困難な高性能材**: フルフラル自体は1922年のクエーカーオーツ社以来の公知工業化学品であり、製造・使用を秘匿する意味はない。しかしフルフリルアルコールの木材含浸という**用途**は主人公の独自到達であり、最終製品の化学分析で原料に辿り着くことは当時の分析技術では極めて困難。秘匿性はフルフラルの秘密ではなく、下流プロセスのノウハウと製品の分析困難性に依拠する。
4.  **コンプレグとの使い分け**: コンプレグ（フェノール系）は高硬度・高圧縮の部品に、フルフリル化木材は形状を維持したまま耐久性を上げたい大型材・構造材に、という棲み分けが可能。
5.  **合成ゴム原料への橋渡し**: フルフラル化学の深化がTHF→ブタジエン経路を生み出し、天然ゴムの代替原料供給という戦略的事業につながる。
6.  **原料三重化による安定供給**: 籾殻（保険・品質基準）・竹廃液（CF連動・通年稼働）・王子製紙廃液（主力量産）の三ルートにより、フルフラルラインの稼働率と供給量が飛躍的に強化される。
