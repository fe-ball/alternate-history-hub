# 合成ゴム原料（ブタジエン上流）供給事業

> 原設定監査 source-audit-2：フルフラル1分子C5からブタジエンC4が1分子得られる理想上限でも54.09/96.08≈0.563トン/フルフラルトン。年産1,000〜3,000トンだけではブタジエン563〜1,689トンが上限で、実際は工程損失と他用途分で減る。ゴム8,000〜30,000トン案にはABE等の別原料・各工程・重合の能力を要する。元の工程表の「容易」は収率・精製・設備を検証した証拠ではない。 根拠・留保は [原設定監査](../audit/SOURCE-AUDIT.md)（SUPPLY-04）。

本ドキュメントでは、フルフラル化学からブタジエンへの経路と、主人公企業が「合成ゴム原料の上流供給者」として事業化する戦略を記述する。

---

## 1. 事業の基本定義

### 二段構えの「内製」と「合弁」の事業構造

巨大なカレンダーロール等を要する量産ゴム事業への無謀な参入は避けつつ、確実な実利を握るため、以下のような機能的な切り分けを行う。

```
【① 理研系スピンオフ企業との合弁・資本参加（汎用・量産向け）】
  理化学研究所（当時、日本最高の科学的権威であり『科学主義工業』を掲げる理研コンツェルン）の高分子研究者を巻き込み、合弁会社（例：理研ゴム等のスピンオフ企業）を設立あるいは資本参加する。
  自社は「ブタジエンを供給・出資するフロント」として立ち回り、消耗戦になりがちな汎用品の価格競争を避けつつ、収益と供給網への関与を確保する。

【② 特殊防振マウント等の自社内製（特殊・高付加価値向け）】
  量産ゴムとは別に、自社工場の「特殊部門建屋（秘密ライン）」にて、航空機・軍用車両用の特殊防振マウント（接着複合部品）や、高オクタン燃料対応の特殊耐油ホース等の重合・加硫を直接内製化する。これにより、三菱等との連携において不可欠な技術的パートナーとしての地位を確保する。
```

## 2. 化学経路の詳細

### 2.1 フルフラルからブタジエンへの全経路

```
籾殻のヘミセルロース
  ↓ 希硫酸＋高温高圧
フルフラル（C₅H₄O₂）
  ↓ 強度水素添加（Ni系触媒・高圧水素）
テトラヒドロフラン（THF, C₄H₈O）
  ↓ 酸触媒（硫酸・リン酸）で開環
1,4-ブタンジオール（C₄H₁₀O₂）
  ↓ 脱水反応（高温・酸触媒）
ブタジエン（C₄H₆）
```

| 段階 | 反応条件 | 主人公時代の実現性 | ボトルネック |
|:---|:---|:---:|:---|
| フルフラル抽出 | 希硫酸・蒸気加熱 | ◎ 1920年代から可能 | なし |
| THF合成（完全水素化） | Ni触媒・高圧水素 | ○ 1920年代後半〜 | 高圧設備・触媒調製 |
| ブタンジオール（開環） | 硫酸・100℃程度 | ◎ 比較的容易 | なし |
| ブタジエン（脱水） | Al₂O₃触媒・300〜400℃ | ○ 1930年代から実用可 | 触媒調製・精製 |

### 2.2 ABE発酵からの補完経路

ABE発酵で得たブタノールは、脱水によりブタジエンに転換できる（第二経路）。フルフラル→THF経路が第一経路、ABE発酵→ブタノール→ブタジエンが第二経路という二本柱体制を構築する。

## 3. 二段構えの戦略

### 第一段階：「広く調べておけ」（1920年代前半〜）

```
発令の外形的根拠：
  1922年：クエーカーオーツ社のフルフラル量産（業界ニュース）
  「日本には籾殻が無尽蔵にある。何が作れるか調べておけ」
  → 特別な未来知識なしに当時の化学者が発せる指示
  → フルフラル全誘導体の探索として自然に包含
```

この段階ではTHF→ブタジエンの経路は「発見された可能性の一つ」として水面下にある。

### 第二段階：「本格化せよ」（1931年）

```
トリガーとなる外部情報の重ね合わせ：

1931年：ソ連SKBの合成ゴム工業生産発表（業界ニュース）
  「工業化できることが証明された」

1931年9月：満州事変
  「これからの戦争では南方の天然ゴムが途絶えるリスクがある」
  「マレー・蘭印のゴムに依存し続けることは戦略的危機だ」

経営判断（想定）：
「ソ連がやったなら我々もできる。
 我々には農業廃棄物のみならず、王子製紙の廃液網からもブタジエン源を量産できる最強の上流基盤（原料三重化）がある。
 理研に話を持っていけ。金も出す。
 ブタジエンから先の巨大な量産製品は理研の権威（スピンオフ）を利用して軍に納入させ、我々は強みの生きる原料上流と、自社複合材に直結する特殊製品（防振マウント等）に注力する。」
```

## 5. 国策としての提案と大義名分

主人公は軍（陸軍軍需局・航空本部等）に対し、「我々は南方に依存しない『純国産のゴム原料（ブタジエン）』を国内資源から安定供給できる基盤がある」という戦略的なプレゼンテーションを行う。

**理研権威の活用**：「原料は我が社が作り、巨大な設備を要する量産製品の大半は理研との合弁会社（エコシステム）が担当する。そして最高難易度の特殊複合コンポーネントのみを自社が手掛ける」と提示することで、軍を信用させる。
軍はこれを「国策の柱」として認定し、主人公企業に対する設備投資の優遇融資や、既存の大手ゴムメーカーに対する購入統制といった強烈な利益に結びつく。

**陸軍・逓信省への情報提供**：ABE発酵由来ブタノールから100オクタン航空燃料原料が得られる可能性についても同様に、「こういうことが可能です、一緒に検討しませんか」という形で1931〜32年頃に提供を開始する。

## 7. 会社・軍・国家への利益

### 会社への直接的利益

```
フルフラルライン稼働率の向上：
  THF・ブタジエン向けの需要がフルフラル消費量を増やす
  → 既存設備の回転率向上・固定費の分散

  理研系合弁企業などへの安定した原料卸売り収益に加えて、
  航空機用防振マウント等の自社製特殊部品による安定した高付加価値分野を獲得できる。
```

### 軍・国家への戦略的価値

```
天然ゴム依存リスクのヘッジと国策貢献：
  マレー半島等からの戦略物資途絶リスクを低減する絶対国防ラインとなる。

航空機・重機開発における最重要ピース：
  「防振マウント」の内製化により、三菱等の新型ディーゼル航空機開発に対して
```

## 9. フルフラルライン全体との接続

```
籾殻（第一ルート：農閑期集中）
  ↓
フルフラル
  ├──→ フラン樹脂・フルフリル化木材（既存事業）
  ├──→ THF → ブタジエン → 合成ゴム原料（本事業）
  └──→ フルフラル-フェノール共縮合樹脂（既存）

竹廃液（第二ルート：通年・炭素繊維生産連動）

  └──→ 同上各経路へ無尽蔵・脱季節的に追加供給
```

フルフラルライン全体の稼働率が向上することで、全誘導体事業の単位コストが下がるという相乗効果がある。

## 10. 合成ゴム事業の3層構造とバランス

本事業は単一企業が量産から特殊品まで担うのではなく、**3層に役割分担した構造**で展開する。各層の年産能力・用途・主要顧客・収益化を以下に整理する。

### 10.1 3層の定義

| 層 | 担い手 | 主用途 | 製品形態 |
|:---|:---|:---|:---|
| **第1層：量産品** | 理研系合弁企業（理研ゴム等のスピンオフ） | 軍用タイヤ・汎用工業用ゴム | 加硫ゴム製品（最終財） |
| **第2層：原料供給** | 主人公企業（フルフラル→THF→ブタジエン） | 合弁先・他社ゴムメーカーへのブタジエン供給 | ブタジエン（中間財） |
| **第3層：特殊高付加価値品** | 主人公企業（自社特殊部門で内製） | 防振マウント・耐油ホース・セルフシーリング用ゴムシート等 | 配合・加硫済の最終部品 |

### 10.2 各層の年産規模と用途バランス

#### 第1層：理研系合弁による量産品

理研系合弁の年産能力は史実日本の合成ゴム工業の規模に概ね沿う。1940年時点で年産数百〜千数百トン規模、1942年以降に戦時統制下で年産2,000〜5,000トン規模に拡大する。主人公企業は出資・原料供給・技術顧問の立場で関与するが、量産工場の運営・販売は合弁主体。

| 期 | 年産能力（合弁全体） | 主用途 |
|:---:|:---:|:---|
| 第4〜5期前半（1934-37） | 試作〜数十トン | 試験品・少量サンプル |
| 第5期後半〜6期前半（1938-41） | 年産数百〜1,500トン | 軍用タイヤ（陸軍）・汎用ゴム製品 |
| 第6期（1942-） | 年産2,000〜5,000トン | 戦時統制下で全軍向け展開・南方天然ゴム途絶リスクのヘッジ |

#### 第2層：主人公企業のブタジエン供給能力

フルフラル→THF→ブタジエン経路（第一経路）と、ABE発酵ブタノール→ブタジエン経路（第二経路）の二本柱。`Furan_Resin_And_Furfurylated_Wood.md §4.4` のフルフラル供給量から、ブタジエンに回せる量を逆算する。

| 期 | フルフラル消費（THF→ブタジエン経由） | ブタジエン年産（推定） |
|:---:|:---:|:---:|
| 第3期後半（1933-34） | 試作（〜10トン） | 試験品レベル |
| 第4〜5期前半（1934-37） | 50〜200トン | 50〜200トン |
| 第5期後半〜6期前半（1938-41） | 300〜800トン | 300〜800トン |
| 第6期（1942-） | 500〜1,500トン | 500〜1,500トン（合弁先供給+自社内製分） |

ブタジエン1トン→ゴム約0.9トンの転換率で、理研系合弁が必要とする原料の過半を主人公企業が供給する形となる。差分は他社（協和会・国産ゴム等）からの調達で補う。

#### 第3層：自社内製の特殊高付加価値品

主人公企業の特殊ライン（秘密ライン）で配合・加硫まで完結する高付加価値品。年産規模は小さいが、技術的には最高難易度。1機あたりの使用量と航空機納入機数から逆算した推定値を示す。

| 製品 | 単価感 | 年間需要 | 年間ゴム消費 | 主要顧客 |
|:---|:---:|:---:|:---:|:---|
| **特殊防振マウント**（航空エンジン用） | 1機分 50〜100円 | 年間500〜2,000機分 | 5〜30トン | 三菱（ディーゼル）・中島 |
| **耐油ホース**（高オクタン燃料対応） | 1機分 30〜50円 | 年間1,000〜3,000機分 | 5〜20トン | 全機体メーカー |
| **セルフシーリング用ゴムシート** | 1機分 200〜500円 | 年間1,000〜2,500機分 | 50〜150トン | 三菱・中島 |
| 油圧シール（萱場向け） | 1機分 10〜30円 | 年間2,000〜4,000機分 | 5〜10トン | 萱場製作所 |
| **小計（第5期後半〜6期前半）** | | | **65〜210トン** | |

第3層の年産規模はECNタグの売上値とも整合する：`REV_P5_RUBBER` (130万円) + `REV_P5_SELFSEAL` (50万円) = 180万円。これに対し第3層の単価合計（特殊ゴム製品全種）から逆算される売上は150〜250万円規模であり、概ね一致する。

### 10.3 主原料（デンプン質）の調達制約

第2層のうち ABE発酵経路は主原料としてデンプン質（糖蜜・サツマイモ・トウモロコシ等）を必要とし、これは食料と競合しうる。本資料群では以下の対策で食料競合を構造的に緩和する：

- **キシロースのABE発酵への転用**（`Taiwan_Bagasse_Furfural.md §3` 参照）：バガス由来のキシロースをABE発酵原料に補助混合。バガスは食用にならない廃棄物のため食料競合なし
- **ABE副産物の物質循環**（`Furan_Resin_And_Furfurylated_Wood.md §4.4` 参照）：ABE残渣を家畜飼料に転用、副産H₂をフルフラル水素添加に転用
- **協和会経由の調達**（`Cooperation_Partners.md` 参照）：寳酒造・合同酒精・大日本酒類醸造の3社網による多様な原料調達ルート

これにより、ABE発酵の年産能力の上限は主原料側ではなく、合弁設備（嘉義工場等）の容量側で律速される設計となる。

### 10.4 軍需消費量との整合性チェック

軍が必要とする合成ゴムの主用途は (a) 軍用タイヤ、(b) セルフシーリング燃料タンク、(c) 防振マウント、(d) 耐油シール の4種。これらの年間総消費量は史実の試算で概ね年産2,000〜5,000トン規模（第6期）。本資料の3層合計（第1層2,000〜5,000+第2層自社内製分+第3層65〜210）はこの規模を概ね充たす。

南方の天然ゴム途絶リスク（1942年以降想定）が現実化した場合、軍は天然ゴム配給の代替として合成ゴムへの依存度を高める。第6期に合弁能力を最大化する設備投資は、軍需省・陸軍燃料部門・逓信省と連携した国策投資として位置づけられる。
