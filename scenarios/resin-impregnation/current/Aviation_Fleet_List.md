# 航空機体一覧と航空部門事業計画

本ドキュメントでは、航空部門開設（1930年）から1942年頃にかけて主人公企業が製作・販売する機体、コンポーネント、および航空部門の事業規模を記述する。

---

## 航空部門の基本方針

航空部門は「売れる機体を売り、使った軍が品質を体感し、引き合いが広がる」という自然な事業成長を軸とする。実証専用機は最小限にとどめ、新素材の飛行実績は販売機種の段階的改良の中で蓄積する。

完成機販売とコンポーネント供給は両輪である。完成機は技術の実証場であると同時に独立した収益源であり、コンポーネント供給は他社の量産ラインに乗ることで自社生産能力以上の市場にアクセスする経路である。いずれかに「徹する」のではなく、技術的優位がある領域で両方を展開する。

公開技術（フェノール/フラン麻FRP＋桐サンドイッチ等）で作る省アルミ機体は、三菱・中島等への技術移転が可能であり、日本全体の航空機生産力に寄与する。昭四号使用品は完成品として機密管理下で納入し、主人公企業のみが製造する高性能版を構成する。

## ■ 原点（1932〜34年）

### DR記録：ディーゼル記録機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1932年 |
| エンジン | Packard DR-980（225hp ディーゼル）|
| 構造 | コンプレグ主桁・麻FRP外板・フェノール紙ハニカムパネル・コンプレグ固定ピッチプロペラ・合成ゴムマウント |
| 機密度 | **低**（素材の製法は非公開、機体は公開） |
| 生産数 | 1〜2機（実証専用） |

航空部門の唯一の純粋な実証機。1933年に1,000km超の記録飛行で「ガソリン機の約1/12」の燃費データを確定。この数字が三菱へのディーゼル本格開発提案と、海軍への長距離哨戒提案の根拠となる。ガソリンエンジンへの換装やフロート装着はこの機体の改修として行い、別型式にしない。

この時期の航空部門は10〜20名の小規模工房。DR記録と並行して、コンプレグ固定ピッチプロペラと昭四号パテの陸海軍への販売が航空部門の実質的な収益を支える。

## ■ 初期販売機種の確立（1934〜37年）

### 初等練習機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1934〜35年 |
| エンジン | 国産ガソリン（150〜200hp 小型） |
| 構造 | コンプレグ主構造・麻FRP外皮。複座 |
| 機密度 | **なし**（公開技術） |
| 単価 | [4.5万円]{{ECN:PRICE_TRAINER_P5}} |
| 生産数 | 年産20〜30機（1937年以降は50〜80機） |

航空部門の起点となる量産販売機種。「腐らない・狂わない・整備が楽」で操縦学校に浸透する。機密がないため報道公開・航空展出品も自由。この機体が「飛んでいる実績」をすべて支える土台になる。

GFRPや昭四号系部品は、販売ロットの改良として段階的に組み込む。非構造部品（フェアリング等）から始め、構造部品（操縦面・外皮パネル等）へ拡大。新型式を起こさずに漸進的に改良する。

### 連絡・偵察機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1934〜35年 |
| エンジン | DR-980（225hp ディーゼル） |
| 構造 | コンプレグ桁・麻FRPサンドイッチ構造。フロート装着版あり |
| 機密度 | **低〜中** |
| 単価 | [12万円]{{ECN:PRICE_LIAISON_P5}} |
| 生産数 | 年産10〜20機 |

DR記録の設計を発展させた実用販売機。師団間連絡、前線偵察に需要。燃費1/12の経済性が訓練・日常連絡飛行で効く。フロート版で海軍にも展開し、水上機部隊との関係構築の窓口になる。「海水に浸かっても重くならないフロート」は水上機運用者にとって革命的であり、海軍が強い関心を示す。

### 中等練習機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1936〜37年 |
| エンジン | 寿系（450〜580hp。第一線から退きつつあるエンジンの再活用） |
| 構造 | コンプレグ桁・麻FRP外皮。公開技術 |
| 機密度 | **なし** |
| 単価 | 要算定 |
| 生産数 | 年産20〜40機 |

操縦学校で初等を終えた学生が実戦機に移る前に飛ぶ機体。九三式中練（赤とんぼ）の複合材版という位置づけ。退役エンジンの再活用と省アルミ構造の二重のメリット。軍の操縦学校から「御社の構造で中等練習機を作れないか」と来るのが自然な動線。パイロット養成の拡大に伴い、需要は安定的に伸びる。

## ■ 双発機への展開と日華事変（1937〜39年）

### 省アルミ双発汎用機

| 項目 | 内容 |
|:---|:---|
| 設計着手 | 1936〜37年 |
| 初飛行 | 1938年 |
| エンジン | 金星（1,000hp）、瑞星（800hp）、または寿系（500hp）の双発。汎用マウント設計により複数エンジンに対応 |

**公開版**

| 項目 | 内容 |
|:---|:---|
| 構造 | フェノール麻FRP外皮・コンプレグ桁・桐サンドイッチ・カゼインまたはユリア接着 |
| 機密度 | **なし**（他社への技術移転可能） |
| 生産数 | 年産20〜40機（自社）＋他社ライセンス生産 |

**昭四号版**

| 項目 | 内容 |
|:---|:---|
| 構造 | 昭四号ハニカムサンドイッチ・麻FRP/GFRP外皮・コンプレグ桁 |
| 機密度 | **中〜高** |
| 生産数 | 年産10〜30機（主人公企業のみ） |

本機は航空部門最大の事業機会。モスキート（1940年初飛行）と同じ思想だが2年早く、より優れた素材（麻FRP＞合板、コンプレグ桁＞スプルース桁）を持つ。

汎用マウント設計が鍵。エンジン供給状況に応じて金星、瑞星、寿系のいずれかを載せ替えられる。用途は基本設計の派生として広がる：
- **軽爆撃型**：陸軍・中華戦線の近接支援
- **偵察型**：高速・長航続距離
- **哨戒型**：海軍沿岸哨戒（後述のディーゼル版に発展）
- **輸送/連絡型**：貨物・人員輸送
- **夜間戦闘型**：GFRP版・レーダー搭載前提（後述）

日華事変（1937年）でアルミ配分が逼迫し始めると、需要が自然に発生する。陸軍は「軽爆と連絡機がもっと欲しいがアルミが足りない」、海軍は「哨戒機が不足している」。

**公開版の他社展開**：1938年頃、主人公企業の生産能力だけでは需要に追いつかなくなる段階で、省アルミ構造の設計図と製造ノウハウを三菱・中島に公開移転する。他社が公開版を量産し、主人公は昭四号版を高性能限定版として維持する二層構造。

### 単発攻撃機（検討候補）

| 項目 | 内容 |
|:---|:---|
| エンジン | 金星または瑞星の単発（800〜1,000hp） |
| 構造 | 省アルミ構造＋複合装甲をコクピット周辺に標準装備 |
| 機密度 | **中** |

複合装甲と機体設計を組み合わせた近接航空支援機。陸軍の地上攻撃需要は日華事変で顕在化する。ただし単発攻撃機が日本軍の運用思想に合うかは別途検討を要する。双発汎用機の軽爆撃型で足りる可能性もある。

### 落下増槽の需要爆発
日華事変で航続距離延長の需要が急増。麻FRP製落下増槽（公開技術）は金属を使わない消耗品。年産数百〜数千個。昭四号版は気密性と耐燃料性に優れる。

## ■ GFRP成熟と高性能機（1939〜41年）

この時期、GFRP（シランカップリング完成後の完全版）が販売機種に投入され、昭四号使用の高性能機が本格的に登場する。

### 双発夜間戦闘機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1940年 |
| エンジン | 金星双発 |
| 構造 | GFRP外皮＋昭四号ハニカム。機体全体がレドームとして機能 |
| 機密度 | **高** |
| 生産数 | 年産10〜20機 |

双発汎用機の基本設計をGFRP化した高性能版。電探搭載を設計段階から前提とし、GFRP機体の電波透過性を最大限に活かす。海軍技研・芝浦との電探開発の接点から「GFRPの機体に電探を組み込めないか」という引き合いが起点。本土防空の夜間迎撃に使う。

### ディーゼル哨戒機

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1940年 |
| エンジン | 三菱ディーゼル双発 |
| 構造 | GFRP外皮＋昭四号ハニカム＋ピッチ系CF翼スパー |
| 機密度 | **高** |
| 生産数 | 年産10〜20機 |

双発汎用機のディーゼル派生。航続距離がガソリン版の倍近くに伸び、ガソリンを消費しない。軽油供給はガソリンより遥かに潤沢であり、セタン価向上剤による低品質軽油の格上げも可能。太平洋の広域哨戒・対潜任務に直結。海軍が飛びつく。

### GFRP飛行艇

| 項目 | 内容 |
|:---|:---|
| 初飛行 | 1940〜41年 |
| エンジン | 三菱ディーゼル双発 |
| 構造 | GFRP艇体（レドーム一体構造）＋昭四号接着 |
| 機密度 | **高** |
| 生産数 | 年産5〜10機 |

自社設計の中型飛行艇。対潜哨戒・沿岸哨戒・救難に最適化。川西の大型飛行艇（二式大艇）とは用途が異なり競合しない。GFRP艇体が海水腐食を構造的に解決し、レドーム一体構造で電探搭載の自由度が高い。ディーゼル搭載により、ガソリンもアルミもほぼ使わない哨戒機。

川西への部材供給（底面パネル・フロート）は別途継続する。

### 高速偵察機（検討候補）

| 項目 | 内容 |
|:---|:---|
| エンジン | 金星単発（1,000hp） |
| 構造 | GFRP＋昭四号。軽量構造により金星の出力で既存全金属偵察機より速い |
| 機密度 | **高** |

モスキートPR型と同コンセプト。「速すぎて捕まらない偵察機」。ただし双発汎用機の偵察版で代替可能かもしれず、独立型式として必要かは要検討。

## ■ 戦時全面展開（1941年〜）

### 公開版省アルミ機の他社量産
1938〜39年に技術移転した省アルミ構造を、三菱・中島が自社工場で量産。退役エンジンの再利用で練習機・連絡機・輸送機を増産し、新型エンジンは戦闘機に集中配分。

### 昭四号版高性能機の独占製造
夜戦・哨戒・飛行艇・偵察など、少数だが戦略的価値の高い機体を主人公企業が製造。

### CFRP部品の限定投入
レーヨン系CFRPは量産能力が限られるため、量産機の翼スパーや操縦面ヒンジ周りなど、構造上最も効く箇所にピッチ系CFを入れて全体のキルレシオを底上げする。

### CFRP特務機

| 項目 | 内容 |
|:---|:---|
| 試作 | 1941〜42年 |
| エンジン | 大出力ガソリン（1,500〜2,000hp級） |
| 構造 | レーヨン系CFRPプロペラ・ピッチ系CF翼桁・GFRPスキン・昭四号全接合 |
| 機密度 | **最高** |
| 生産数 | 数機（コスト度外視） |

量産機底上げの副産物として到達した技術の結晶。限定的な特務・局地用途。
