# 耐蝕ライニング事業

本ドキュメントでは、フラン樹脂の耐酸性を活かした化学プラント向け内張り（ライニング）事業を詳述する。

---

## 1. 事業の本質

### 一行要約

「酸にも負けない構造材」の化学産業向け展開。

### 技術的新規性

**ゼロ**。この事業はフラン樹脂の既存特性を、別の市場に展開するだけである。主人公が「やれ」と言えば、既存の技術者・設備で実行できる。R&D投資は不要。

### なぜ「取り逃していた」か

フラン樹脂文書（Furan_Resin_And_Furfurylated_Wood.md）では「国家備蓄インフラへの貢献」として終盤に言及されているが、**独立した事業としての収益試算・顧客分析・開始時期**が明示されていなかった。この空白を埋める。

---

## 2. フラン樹脂の耐蝕性能

フラン樹脂（ポリフルフリルアルコール）の耐薬品性はフェノール樹脂を大幅に上回る。

| 薬品 | フェノール樹脂 | フラン樹脂 |
|:---|:---:|:---:|
| 塩酸（10%） | 良好 | 優秀 |
| 硫酸（10〜50%） | 可 | 優秀 |
| 酢酸 | 可 | 優秀 |
| 水酸化ナトリウム（10%） | 良好 | 良好 |
| 有機溶剤（アセトン・アルコール等） | 良好 | 優秀 |
| 高温蒸気（120°C以下） | 可 | 良好 |

この性能差が、化学プラントという市場での「独壇場」を生む。

## 3. 競合比較

### 当時の耐蝕ライニング市場

| ライニング種類 | 耐酸性 | 施工性 | コスト | 寿命 |
|:---|:---:|:---:|:---:|:---:|
| 天然ゴムライニング | 中〜高 | 良好 | 中 | 3〜7年 |
| 鉛ライニング | 高（硫酸系） | 難 | 高 | 10年以上 |
| ガラスライニング | 優秀 | 困難・割れリスク | 高 | 長寿命だが脆弱 |
| タイルライニング | 高 | 手間がかかる | 高 | 長い |
| **フラン樹脂ライニング（主人公）** | **優秀** | **良好** | **中** | **長い** |

フラン樹脂ライニングの優位性：
- ゴムライニングより耐薬品性が高く、温度範囲が広い
- 鉛・ガラスより施工が容易
- 鋼材節約（外殻を薄くできる、または木製タンクにも適用可能）

## 4. 顧客分析

### 4.1 主要顧客業種

**最優先：火薬・爆薬工場**
```
具体的用途：
  硫酸・硝酸の反応槽・輸送管・貯蔵タンク
  ニトログリセリン・TNT製造ラインの腐食問題
  
需要の確実性：★★★
軍との接点：直接的（軍の火薬廠・民間火薬会社とも）
価格交渉力：高い（代替が少ない特殊用途）
```

**高優先：化学工業（硫酸・染料・肥料）**
```
具体的用途：
  硫酸工場の反応槽・冷却塔
  染料工場の酸性浴槽
  硫酸アンモニウム（肥料）製造ライン
  
需要の確実性：★★★
軍との接点：間接的（農業生産性に影響）
規模：大きい（工場数・タンク数が多い）
```

**中優先：発酵・醸造工業**
```
具体的用途：
  ABE発酵（アセトン・ブタノール製造）の発酵タンク
  酒類・食酢の醸造タンク
  乳酸・酢酸生産ライン
  
需要の確実性：★★
軍との接点：ABE発酵がアセトン（火薬・溶剤原料）を生産
特記：合成ゴム原料事業との顧客重複が生まれる
```

**中優先：電鍍（メッキ）・電解工業**
```
具体的用途：
  酸性めっき浴槽
  電解精製槽（銅・亜鉛）
  
需要の確実性：★★
```

**中優先：石油精製・クラッキング**
```
具体的用途：
  酸性廃液処理槽
  一部の反応塔内張り
  
需要の確実性：★（まだ小さい市場）
```

### 4.2 顧客へのアプローチ方針

```
火薬工場：
  「鉛ライニングより軽量・安価で同等以上の耐酸性」
  「鋼材を節約できる（戦時における重要な訴求点）」

化学工場：
  「ゴムライニングより耐熱性が高く、高温酸に対応できる」
  「寿命が長く交換頻度が低下」

発酵工場：
  「清潔性（フラン樹脂はゴムより衛生的）」
  「酢酸・乳酸に対する優れた耐性」
```

## 5. 事業化の詳細

### 5.1 開始時期と理由

**開始：1930〜1931年頃（世界恐慌期）**

```
理由：
  フラン樹脂の量産能力が確立している（第3期）
  R&D投資不要 → 恐慌期の低投資で起動できる
  化学工場は不況でも稼働する（基礎素材産業）
  「鋼材節約」という訴求点は不況期でも有効

恐慌期での効果：
  シャトル需要が底堅くても全体収益は圧縮される時期
  耐蝕ライニングという新収益柱が下支えになる
```

### 5.2 施工方法と技術要件

```
【鋼製タンクへの内張り施工】
①表面処理（サンドブラスト・酸洗い）
②プライマー塗布（接着性向上）
③フラン樹脂溶液の塗布・積層（3〜5層）
④各層の酸触媒硬化（加熱または常温硬化）
⑤品質検査（ピンホール検査・厚み確認）

技術要件：
  特殊技能は不要
  フラン樹脂の取り扱いに習熟した施工員で対応可能
  主人公企業の既存技術者で十分
```

```
【大型タンク（地下備蓄）の構造材としての利用】
木製骨格 + フラン樹脂ライニング：
  鉄骨不使用で巨大耐酸タンクの建造が可能
  航空燃料の地下備蓄槽として特に価値が高い
  
フランFRP（ガラス繊維強化）：
  GFRPの開発以降は、より強度の高い構造タンクが可能
```

### 5.3 収益モデル

```
受注形態：
  A）設計・施工一括請負（利益率高）
  B）材料供給のみ（販売は容易だが利益率低）
  → Aを基本として、施工部門の人材育成を並行

単価感（推定）：
  タンク内張り施工（中型・5000L程度）：
    材料費：約200〜300円
    施工費：約100〜200円
    計：300〜500円/件
    
  年間施工件数（事業確立後）：100〜200件
  年間売上（推定）：3万〜10万円

コンプレグ・シャトルと比較した位置づけ：
  規模は中程度だが恐慌期でも安定
  顧客基盤は化学工業・軍に広がる
  → 新規の軍需顧客開拓の窓口として機能
```

## 6. 戦時における価値の変化

### 6.1 鋼材節約という訴求点の強化

```
1931年以降の軍需拡大期：
  「鋼材は銃砲・艦船・航空機に使え」という圧力
  化学プラントの耐蝕タンクに鉄を使うな、という方向性
  
フラン樹脂ライニング（または構造タンク）の優位性：
  木製骨格＋フラン樹脂 → 鉄をほぼ使わない耐酸タンク
  → 戦時の鉄鋼節約という国家目標と完全に整合
```

### 6.2 国家備蓄インフラとの接続

```
1937年〜の戦時経済下での大型需要：
  航空燃料の地下備蓄タンク（防空観点から重要）
  火薬原料（硫酸等）の国家備蓄施設
  化学工業の軍需向け生産ライン増強
  
これらはいずれも：
  大型の耐酸タンク・反応槽を必要とする
  鋼材節約が求められる
  → フラン樹脂ライニングの最大需要期
```

### 6.3 「インフラ特需企業」という地位の確立

```
主人公企業が耐蝕ライニング事業を持つことで：
  火薬工場との直接取引
  化学工業の基盤整備への貢献
  航空燃料備蓄インフラの構築への参与

「国家の継戦能力を下支えするインフラ特需企業」という
位置づけが強化される。

これは：
  軍からの優遇（原料配給の優先）につながる
  次世代素材（GFRP・CFRP）の採用交渉を有利にする
  主要研究施設との協力関係構築を促進する
```

## 7. 事業としての総合評価

| 評価項目 | 評価 | 理由 |
|:---|:---:|:---|
| R&D必要性 | ◎不要 | 既存技術の市場展開 |
| 起動コスト | ◎低い | 施工員の教育だけで可能 |
| 収益性 | ○中程度 | 案件単価は小さいが安定 |
| 戦略的価値 | ★★★高い | 軍需顧客との接点・鋼材節約 |
| 開始タイミング | ◎即時可能 | 1930〜31年から開始可 |
| リスク | ◎低い | 技術的失敗のリスクがない |

**優先順位評価：★★★ 早期実装すべき最優先事業**

耐蝕ライニング事業は「技術的困難がなく・即時収益化可能で・戦略的接点が多い」という三拍子が揃った事業であり、資料群に明示されていなかったことが惜しまれる。
