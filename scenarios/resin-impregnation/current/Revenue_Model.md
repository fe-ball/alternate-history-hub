# 売上規模の時期別推定（Revenue Model）

> 修正版 2026-10-06。計算・参照・根拠不足を監査し、確定できない条件はOPENとした。変更根拠は [監査記録](../audit/DECISION-REGISTER.md)。

本資料は、主人公企業の各時期における主要事業別売上を概算し、設備投資・白金購入・人員拡大等の大型支出の実現可能性を検証するための基準値を提供する。他の資料で売上規模に言及する際は、本資料の数値を参照すること。根拠なき概算を各資料に独立して書かないこと。

> **本資料の期区分は `Phase_Analysis.md §0`（期区分の正典定義）に従う。**
> **財務期のラベルは §0 の財務マッピング規約に従う。** 本資料中で使用する「第4〜5期前半（1934〜1937年）」「第5期後半〜第6期前半（1937〜1941年）」等のハイブリッド命名は、概念フェーズ（F1〜F6）と財務期のずれを吸収するための正規表記である（F3とF4は財務上合算、F5とF6は1936-40年でオーバーラップ）。

> **本資料は `Master_Parameters.md §0.1`（ECNタグ運用ルール）に従う。** 本資料は `Master_Parameters.md` と並ぶ財務正典であり、役割分担は以下のとおり：
> - `Master_Parameters.md` = タグ・数値の**定義**（タグ一覧・暫定値・命名規則・運用ルール・参照箇所索引）
> - `Revenue_Model.md`（本資料）= 数値の**根拠**（積み上げ計算・単価×数量・利益率の前提・物価補正の論理）
>
> 両者の数値が一致することを保証する責任は、双方の編集者にある。新規ECNタグを導入する場合は `Master_Parameters.md §0.1 原則5` の手順に従う。

## 前提：物価の基準

昭和初期〜戦時期の物価は年代によって大きく異なる。以下の基準値を用いる。

| 品目 | 昭和5年（1930年）頃 | 昭和10年（1935年）頃 | 昭和15年（1940年）頃 |

| 大卒初任給（月額） | 約50円 | 約70円 | 約75円 |
| 熟練工（月額） | 約40〜60円 | 約50〜80円 | 約60〜100円 |
| 米1升（1.5kg） | 約0.30円 | 約0.35円 | 約0.45円 |
| 大口工業電力（kWh） | 約2銭 | 約2銭 | 約2銭 |

| レーヨン糸（kg） | — | 約1.5円 | 約1.5円 |

従業員1人あたりの年間人件費（福利厚生含む）は概ね600〜1,000円/人（職種による）。

## 売上構成比の推移

財務内訳が重複なく照合できるP5・P6を示す。完成機には補用品・整備支援を含む。分類は比較用であり、企業の事業範囲を制限しない。

| 財務時点 | 素材・化学品 | 航空コンポーネント | 完成機・支援 | 装甲・戦略物資・その他 | 合計 |
|:---|---:|---:|---:|---:|---:|
| P5（1941年） | 3,000万円／35.3% | 3,660万円／43.1% | 940万円／11.1% | 900万円／10.6% | 8,500万円／100% |

## 利益率の推定

事業別の利益率は製品の性格によって大きく異なる。

| 事業カテゴリ | 売上利益率（推定） | 根拠 |
|:---|:---:|:---|
| シャトル（独占期） | 30〜40% | 代替品がなく価格交渉力が強い |
| シャトル（競合出現後） | 15〜25% | 規模で優位だが価格競争に移行 |
| コンプレグ板材 | 20〜30% | 品質プレミアムが維持できる期間は高い |
| エポキシ系製品 | 25〜40% | 技術障壁・付加価値による価格交渉力を想定。成分非公開による統制免除は仮定しない |
| 完成機（練習機） | 8〜12% | 機体製造は利益率が低い（材料費＋人件費が大きい） |
| プロペラ | 20〜35% | 高い技術障壁・交換需要で安定 |
| 増槽（消耗品） | 12〜18% | 価格競争力はあるが大量生産でのコスト低減が必要 |
| 耐蝕ライニング（施工込み） | 15〜25% | 施工費込みのため利益率は安定 |
| GFRPレドーム | 25〜35% | 独占供給。GFRP以外に代替素材がない |
| セルフシーリング用ゴムシート | 15〜25% | 合成ゴムの内製による原価優位 |
| 噴進弾構造部品 | 15〜20% | 軍需消耗品。量産効果あり |
| 炭素電極 | 15〜20% | 戦略物資指定で安定だが価格統制の影響も |
| 軍需品全般（戦時統制後） | 10〜18% | 価格統制の影響で利益率は圧縮される傾向 |

全事業平均の税引前利益率は**16〜18%**程度。1939年の価格等統制令以降は、価格認可・原価査定による利益率への影響を検討する。年間利益額は以下のように推移する。

## ドキュメント運用規定

1.  **数値の性質**：本資料の数値はすべてオーダー推定（概算）であり、技術的リアリティを検証するための論理的バッファとして機能する。
2.  **整合性の維持**：他の資料において売上規模や投資額に言及する際は、必ず本資料および `Master_Parameters.md` の数値を参照し、独立した根拠なき数値を記述しないこと。
3.  **品目管理の原則**：シナリオ内で事業記述が存在する売上品目は、本資料またはMaster_Parametersに必ず明示的なコードを持つこと。「OTHER」や「STRATEGIC」に暗黙的に含有させず、サブコードとして分離すること。
