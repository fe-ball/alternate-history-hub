# CFRP（炭素繊維強化プラスチック）総合資料

> 原設定監査 source-audit-2：繊維E/密度と複合材の物性を区別。GFRPの比弾性率だけで構造用途を一律排除せず、同じ形状・荷重・環境で比較する。ピッチ系はE=150GPaの場合75〜79GPa・cc/gであり150ではない。高弾性グレードの研究は維持するが、3.8円/kgは限定費目の小計で認定長繊維の全原価ではない。25円/kgも歩留りに依存する。電極・活性炭・絶縁用途は別品質で、炭素化炉の共用時間・洗浄・歩留り・加工を二重に使わない。 根拠・留保は [原設定監査](../audit/SOURCE-AUDIT.md)（TECH-04、TECH-06）。

本ドキュメントでは、CFRPの史実的起源、主人公のナラティヴ候補の選定、製造プロセスの技術分析、および炭素素材の三層体制を一貫して記述する。

> **2026-10-07 追補（優先）**：航空用高強度長繊維の主経路はPAN系へ変更した。旧本文のレーヨン第一・偶然発見ルートは比較/橋渡し用のREFERENCEとし、現行の主開発順序には使わない。主人公は未来知識からPAN前駆体を意図的に設計し、繊維会社の湿式紡糸技術と自社の安定化・炭素化・表面処理・CFRP化を接続する。詳細は [active/Aviation_Composite_Integration_1933_1942.md](active/Aviation_Composite_Integration_1933_1942.md) と [Carbon_Material_Hierarchy.md](Carbon_Material_Hierarchy.md) を優先する。

## 1. 史実における炭素繊維の起源

### エジソンの竹フィラメント（1880年代）
*   炭素繊維の概念的祖先。竹（セルロース）を炭化して電球のフィラメントとした。
*   しかしこれは「繊維を構造材として使う」発想ではなく、「電気を通す細い糸」としての利用。炭素繊維はタングステンフィラメントに置き換えられて歴史から消えた。
*   **このシナリオとの接続（追補）**: 木材屋出身の主人公は炭焼き知識を持つ。「エジソンが竹を炭化してフィラメントにした」という発想と、自身の炭焼き経験が接続することで、「炭素化の温度管理ノウハウを繊維に応用する」という発想への橋渡しが自然に生まれる。

### ロジャー・ベーコン（1958年、米クリーブランド）
*   レーヨン繊維を不活性雰囲気中で2800°C以上に加熱し、**グラファイト・ウィスカー**を作成。ヤング率が鋼鉄の10倍以上であることを実証。
*   これが「炭素繊維は構造材になる」という認識を世界で初めて確立した瞬間。

### 進藤昭男（1961年、大阪工業技術試験所）
*   **PAN（ポリアクリロニトリル）繊維**を前駆体として、200〜300°Cの空気中酸化（安定化）→1000°C以上の不活性雰囲気中加熱（炭素化）で高強度炭素繊維を製造。
*   PAN系炭素繊維は後にレーヨン系を完全に駆逐し、現代のCFRPの主流となる。

### ウィリアム・ワット（1963年、英RAE）
*   PAN系炭素繊維の製造プロセスを工業的に確立。「延伸しながら焼く」ことで繊維の配向性を高め、引張強度を飛躍的に向上させた。

### 本シナリオのCFRP前駆体と三層体制

PANを通常の溶融紡糸にそのまま使うのは難しいが、「DMF/DMSOがないから到達不可能」は撤回する。塩水系など別の溶液紡糸経路がある（[1962年公報](https://patents.google.com/patent/US3061402A/en)）。これは1930年代に設備が揃った証拠ではない。前駆体の純度・重合・紡糸・安定化・炭素化・回収設備・品質を検討する追加研究OPTIONとし、レーヨン/ピッチ/竹の既存計画を取り消さない。未来知識による前倒しも史実年だけでは排除しない。

その代わり、以下の三層体制が成立する：

| 層 | 前駆体・製法 | 特性 | 用途 |
|:---:|:---|:---|:---|
| **強度層** | レーヨン系（張力下炭素化） | 高引張強度（700〜1000MPa） | プロペラ・特務機最重要部 |
| **剛性層** | メソフェーズピッチ系 | 高弾性率（ヤング率重視） | 翼スパー・量産機剛性部材 |
| **量産補完層** | 竹パルプ系（チョップド） | 低コスト・大量生産 | コンパウンド・炭素電極 |

### 推奨ルート（候補8）の詳細

1.  航空機の翼前縁の着氷防止（デアイシング）のために、軽量な電気加熱体が欲しい。
2.  レーヨン布にカーボン粉末を塗し焼結した「抵抗発熱体」を試作する（これ自体は既存技術の延長）。
3.  試作中、管状炉の温度が予定（300〜400°C）より大幅に高く上がってしまうインシデントが発生。
4.  取り出すと布は灰ではなく**黒い柔軟なシートに変わっている**。一部が管状炉の引き出し金具に引っかかり、**張力が掛かった状態で炭素化された**部分だけが異常に硬く強いことに気づく。
5.  社長（主人公）がこれを見て「カン」で「張力と温度の関係を系統的に調べろ」と指示。
6.  レーヨンを管状炉に連続的に通すために、レーヨン紡績の巻取り機を流用。リールの回転速度と炉の加熱速度のバランスで、自然に繊維に張力が掛かった。「巻取り速度を速くすると強度が上がる」ことに気づく。

### 炭素化技術習熟の段階的背景（追補）

レーヨン系CFRPへの到達は突然の発明ではなく、以下の段階的習熟の末に生まれる：

```
①木炭・備長炭の知識（1920年代から）
  炭焼き職人の温度管理ノウハウ
  「良い炭は温度制御で決まる」という認識

②竹チョップドCFの生産（1935年頃〜）
  ロータリーキルンによる大量炭素化
  温度プロファイル・雰囲気ガス管理の実践的習熟
  「チョップドなら張力不要で済む」の経験

③炭素電極の本格製造（1936年頃〜）
  電極品質のための炭素化条件の精緻化
  高温維持・均熱技術の向上

④レーヨン系CFRP（1936〜38年）
  ①〜③の蓄積の上に「張力下炭素化」という
  最後のピースが組み合わさって完成
```

この順序により、CFRPの発見は「突然のひらめき」ではなく「蓄積が閾値を超えた瞬間」として描ける。

## 3. 製造プロセスの技術分析

### 3.1 前駆体としてのレーヨン

*   レーヨン（再生セルロース）の分子式は(C₆H₁₀O₅)ₙ。炭素含有率は約44%。
*   レーヨンはPANに比べて炭素収率が著しく低い（**約20% vs PAN系の50-55%**）。これはセルロースの分解反応で大量のCO₂、H₂O、タール状物質が揮発するため。
* 本計画の初期長繊維はレーヨンを優先する。ピッチ系も並行候補であり、PANを含む他経路を「選択の余地なし」とは扱わない。

### 3.2 安定化工程（200〜300°C、空気中）

*   レーヨンをいきなり高温（800°C以上）に入れると、急激な分解で繊維が消失する（灰になる）。
*   低温の空気中酸化で**酸素架橋**を導入し、分子を安定化（不融化）させることで、以後の高温処理に耐えられるようにする。
*   この工程は数時間〜十数時間を要する。温度プロファイル（昇温速度）が品質を決定する。

### 3.3 炭素化工程（800〜1500°C、不活性雰囲気）

*   窒素またはアルゴン雰囲気中で加熱し、炭素以外の元素（H, O, N）を揮発させて炭素骨格のみを残す。
*   **張力下炭素化が性能の鍵**: 無張力で炭素化すると、炭素のグラファイト面がランダムに配向し、引張強度は低い。張力を掛けながら炭素化すると、グラファイト面が繊維軸方向に配向し（ターボストラティック構造）、引張強度が大幅に向上する。
*   典型的なレーヨン系炭素繊維の物性（張力下炭素化の場合）:
    *   引張強度: 約700〜1000 MPa（当時としては異常な値。超々ジュラルミンの約400 MPaを超える）
    * ヤング率40〜60 GPa、密度1.6〜1.7なら比弾性率は約23.5〜37.5 GPa・cc/g。鋼200/7.8≈25.6に対し約0.92〜1.46倍であり、「約5倍」は誤算。これは原繊維の仮定値で、積層CFRPの値ではない。
    *   比重: 約1.6〜1.7（鋼鉄の約7.8、ジュラルミンの約2.8に対して大幅に軽い）

### 3.4 表面処理

*   炭素繊維表面はそのままでは化学的に不活性であり、エポキシ樹脂との接着性が不十分。
*   **希硝酸による表面酸化処理**で、繊維表面にカルボキシル基(-COOH)やヒドロキシル基(-OH)を導入し、エポキシのグリシジル基との化学結合を形成可能にする。
*   これはGFRPにおけるシランカップリング剤と同じ「界面問題の解決」の系譜に属する。

### 3.5 「完成品から製法が推測できない」究極のブラックボックス

*   CFRPの完成品がどれほど優れていても、その製法（レーヨン繊維を「適切な張力で引っ張りながら綺麗に焼成して炭素繊維にする」というプロセス）は完全に直感に反しており、初見の人間にとっては意味不明。
*   「できるとわかっても、どうやって作ったのか見当もつかないし、真似しにくい」という点で、技術的優位性の確保において最適である。
*   張力下炭素化の最適条件（張力、昇温レート、保持温度、雰囲気ガス流量）は完全にプロセスパラメータであり、完成品の分析では得られない。

## 4. 炭素素材の三層体制【追補・重要】

CFRPが完成した時点で、主人公企業の炭素素材ラインナップは三層体制として整理される。

### 4.1 三層の定義と役割

```
【第一層：強度層】レーヨン系CFRP（長繊維）
  前駆体：レーヨン（帝人・東洋レーヨン国産品）
  製法：張力下炭素化（精密制御）
  収率：20%
  製造原価：25円/kg
  引張強度：700〜1000MPa
  比重：1.6〜1.7
  用途：プロペラブレード・特務機最重要構造部位
  性格：少数精鋭・高付加価値・軍事機密

【第二層：剛性層】メソフェーズピッチ系CF
  前駆体：コールタールピッチ（コークス炉副産物・安価・大量）
  製法：ピッチのメソフェーズ化→紡糸→炭素化（ロータリーキルン応用）
  収率：80〜85%
  製造原価：3.8円/kg（レーヨン系の1/6以下）
  弾性率：ヤング率がレーヨン系を大きく上回る
  用途：翼スパー・水平尾翼桁・量産機剛性部材
  性格：量産・経済的・GFRPが解決できなかった問題を解決

【第三層：量産補完層】竹チョップドCF
  前駆体：竹生材（全国自生・ほぼ無償）
  製法：竹パルプ化→ロータリーキルン炭素化（既存設備転用）
  収率：8%（生材比）
  製造原価：5.5円/kg
  用途：CFRPコンパウンド成形品・炭素電極混合・設備稼働調整弁
  性格：廉価・量産・固定費分散の担い手
```

### 4.2 三層体制が解決する問題

**GFRPの残された問題**：
GFRPの参考比弾性率20とアルミ25だけで完成構造の採否・軽量化・動特性は確定しない。断面・積層・接合・試験条件を同じ基準で比較し、用途別に認定する。

**ピッチ系CFによる解決**：
メソフェーズピッチ系CFのE=150GPa仮定なら比弾性率は75〜79GPa・cc/g。高弾性グレードも検討できるが、積層材の認定、完成構造の動特性、良品原価を別に評価する。3.8円/kgの小計から量産完成品の経済性を即断しない。

**統合的な設計自由度の変化**：
```
GFRP時代：翼スパーがボトルネック、フラッター制約が残る
↓
ピッチ系CF導入後：翼スパーの剛性問題が解決
→ 急降下制限速度が構造的に向上
→ フラッター心配なく高速域の設計が可能に
```

### 4.3 経済的な相互補完

```
設備共用による固定費分散：
  レーヨン系炉の稼働率：精密制御のため常時フル稼働困難
  空き時間に竹チョップドCFを投入
  → 炉の減価償却費・窒素ガス費を按分
  → 実質的なレーヨン系CFの製造原価が下がる

原料多様化：
  レーヨン：帝人・東洋レーヨンへの依存（リスクあり）
  ピッチ：コークス炉（製鉄所と連動・国内供給）
  竹：全国自生・ほぼ無償（リスクなし）
  → 三前駆体の分散でサプライチェーンが強靭化
```

## 5. ピッチ系CF製造プロセス詳細【追補】

### 5.1 メソフェーズピッチとは

コールタールピッチを380〜450°Cで加熱すると、液晶的な秩序構造（メソフェーズ）を持つ相が生成される。この「メソフェーズピッチ」は、炭素分子が規則的に配列した状態であり、これを紡糸して炭素化すると高弾性率の炭素繊維になる。

### 5.2 主人公のアリバイ

```
フェノール自社合成ライン → 石炭化学との接点あり
↓
コークス炉副産物（コールタールピッチ）へのアクセス
↓
「炭素電極研究の延長として、ピッチの炭素化特性を調べろ」
という指示が自然に発せられる
```

炭素電極研究（1936年頃から）の中で、「ピッチを特定条件で処理すると繊維状に引き延ばせる」という発見が生まれる流れとして自然。

### 5.3 コスト試算（CF 1kgあたり）

| 項目 | 金額 |
|:---|:---|
| コールタールピッチ（1.2kg分） | 約0.3円 |
| 電力（炭素化） | 約1.5円 |
| ロータリーキルン保全・窒素ガス | 約2.0円 |
| **合計** | **約3.8円/kg** |

レーヨン系（25円/kg）の1/6以下という圧倒的な経済性。

## 6. 竹チョップドCF製造プロセス詳細【追補】

### 6.1 製造フロー

```
竹生材（孟宗竹・真竹等：ほぼ無償入手可能）
  ↓ アルカリ蒸解（苛性ソーダ水溶液・既存オートクレーブ転用）
  ↓ ヘミセルロース・リグニン除去
セルロース繊維（均一な炭素化挙動）
  ＋ 蒸解廃液（フルフラル回収→フルフラルラインへ）
  ↓ ロータリーキルン（チョップドのため張力制御不要）
  ↓ 炭素化（600〜1200°C・窒素雰囲気）
竹チョップドCF
```

### 6.2 コスト試算（CF 1kgあたり）

| 項目 | 金額 |
|:---|:---|
| 竹生材（12.5kg分） | 約1.5円 |
| 苛性ソーダ等薬品 | 約1.0円 |
| 電力（炭素化） | 約1.5円 |
| ロータリーキルン保全 | 約1.5円 |
| **合計** | **約5.5円/kg** |

### 6.3 事業としての役割

*   単体では性能限界があるが「高収益の量産素材」として機能する
*   CFRPコンパウンド（樹脂＋チョップドCF）は木粉入りベークライトを性能・価格ともに上回り、10〜15円/kgで販売可能
*   炭素電極への混合材として使用すると電極品質が向上しプレミアム価格での販売が可能

## 7. CFRPの適正価格と事業モデル（収率・電気代の再計算）

CFRPの製造に関する「莫大なコスト」の実態を、昭和15年（1940年）前後の物価水準で具体的に試算し、どのように事業として成立（黒字化）するかを定義する。

### 7.1 昭和15年水準でのコスト試算（1kgあたり）

*   **前提物価**: 大口水力電力＝2銭/kWh、レーヨン糸卸売＝1.5円/kg、ジュラルミン＝2.0円/kg
*   **レーヨン収率の低さ**: レーヨン系CFの炭素化収率は**約20%**。1kgの炭素を得るため、5kgのレーヨン白糸（7.5円分）が必要。
*   **高温電気炉のランニングコスト**: 1000℃以上の均熱・張力制御付不活性ガス炉を稼働させるため、CF1kgあたり約100kWh（2.0円）の電力を消費。加えて、大量の窒素ガス代と炉の減価償却費（約3.0円）が発生。
*   **タール地獄と清掃保全**: 5kgのレーヨンから1kgのCFが残る時、**消えた4kgは水蒸気と大量の腐食性タールガスとなる**。炉心管や排気系は猛烈な勢いで汚染されるため、頻繁なライン停止と人海戦術による清掃（保全費・人件費約5.0円）が必要。
*   **歩留まりと習熟度**: 稼働初期は糸切れが多発し、長繊維として完走できるのは全体の60%程度（ロス40%）。職人が張力制御に習熟するにつれ、ロス率は20%前後まで改善する。

**【試算結果】列挙費目の小計は7.5＋2＋3＋5＝17.5円/炭素化kg。長繊維良品率60〜80%なら21.875〜29.167円/良品kg。25円は良品率70%の中間ケース（端材収入を控除しない場合）。検査・後加工など未収録費目を加え、販売価格・納入量と別に照合する。**

ジュラルミン（2円/kg）の10倍以上という超高価な素材だが、「航空機の最重要部品（プロペラ・主翼桁など数kg〜数十kg）の重量と遠心力を大幅に減らし、限界を引き上げる特殊繊維」としては、軍の特別会計が十分許容できる「リアルな高級兵器価格」に収まる。

### 7.2 三層体制による歩留まりの補完

| グレード | 前駆体 | 原価 | 用途 | 量産性 |
|:---|:---|:---:|:---|:---:|
| 長繊維（特務機） | レーヨン系 | 25円/kg | プロペラ・翼桁最高強度部 | 限定的 |
| 高弾性率（量産機） | メソフェーズピッチ系 | 3.8円/kg | 翼スパー・量産機剛性部材 | 高い |
| チョップド（補完） | 竹パルプ系 | 5.5円/kg | コンパウンド・炭素電極 | 大量 |

ロスとして発生したレーヨン系切断糸・端材は引き続きチョップドとして活用。ただし本体のチョップドライン（竹系）とは独立して管理し、「レーヨン系端材チョップド」は特別グレードとして区別される。

## 8. 実用化のタイムラインと制約

### CFRPとピッチ系CF投入が「戦時に間に合う」タイミング

*   **竹チョップドCF**：1935〜36年頃から量産。炭素電極・コンパウンド向け供給開始。
*   **炭素電極**：1936年頃から本格製造。アルミ電解・電気炉向け。
*   **レーヨン系CFRP（長繊維）**：1938〜39年頃に試作成功。1940〜41年頃に実用化。
*   **メソフェーズピッチ系CF**：1937〜38年頃に試作成功。1939〜40年頃に量産体制。
*   1941年12月の太平洋戦争開戦時に三層体制がほぼ整っている。

### どのような部品に適用されるか（優先順位）

| 優先度 | 部品 | 適用素材 | 理由・効果 |
|:---:|:---|:---:|:---|
| 最高 | **プロペラブレード** | レーヨン系CFRP | エンジン周辺重量の大幅減。高出力エンジン対応 |
| 最高 | **翼スパー（主翼桁）** | **ピッチ系CF** | 高弾性用途の候補。完成構造の動特性・量産適性は別評価 |
| 高 | **水平尾翼桁** | ピッチ系CF | 高速域でのピッチ操舵精度向上 |
| 高 | **操縦桿・各種プーリー** | レーヨン系CFRP | 操縦系統の慣性重量低減 |
| 中 | **エンジンカウリング骨格** | レーヨン系CFRP | シリコーン樹脂と組み合わせた耐熱・高強度部材 |
| 中 | **計器盤・構造部品** | 竹チョップドCFコンパウンド | 既存ベークライト部品の高性能代替 |
| 低 | **冷却ファンブレード等** | ピッチ系CF or GFRP | 用途に応じて選択 |

### 秘匿体制
*   レーヨン系CFRPは最高機密として秘密特許を出願。製造は直属チームのみが行い、外部には一切公開しない。
*   ピッチ系CF・竹チョップドCFは秘匿レベルを下げて量産展開する。ただし製造プロセスの詳細は非公開。
*   軍事機密特許制度により、公開されることなく権利が保護される。

## 9. 炭素電極・活性炭の事業化【追補】

### 炭素電極

**用途**：アルミニウム電解製錬（電解槽陽極・陰極）・電気炉製鋼用電極

```
アルミ電解製錬との直結：
  太平洋戦争期の航空機製造はアルミ需要が爆発的に拡大
  アルミ製錬には大量の炭素電極が必要
  → 主人公企業がアルミ生産の基盤を支える位置に立てる
```

**製造**：竹チョップドCFをロータリーキルンで製造し、バインダーで固めてプレス成形→高温焼成。ロータリーキルンへの投資は炭素繊維ラインと共用。

### 活性炭

**製造**：炭素化後に水蒸気活性化（400〜900°C）で細孔を形成。既存炭素化炉の応用で対応可能。

**用途**：
- 防毒マスクフィルター（確実な軍需・毒ガス戦に備えた全軍的需要）
- 水道・食品精製
- 溶剤回収（工業用）

防毒マスクフィルターは軍との取引実績を積む窓口としても機能する。
