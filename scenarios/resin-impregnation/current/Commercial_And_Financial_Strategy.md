# 主人公企業の商業・金融戦略

> 修正版 2026-10-06。計算・参照・根拠不足を監査し、確定できない条件はOPENとした。変更根拠は [監査記録](../audit/DECISION-REGISTER.md)。

> 取り込み監査：財務数値は [マスタ](Master_Parameters.md) と [売上モデル](Revenue_Model.md) の修正版を優先。1939年の価格等統制以降、成分非公開だけで統制免除を認定しない。資金残高・認可価格・内訳未配賦はOPEN。[監査記録](../audit/DECISION-REGISTER.md)。

本資料は、シナリオ全体を通じた「商業慣行・金融方針・宣伝方針」の設計原則を整理したものだ。技術フィージビリティ資料群（コンプレグ・エポキシ等）が「何を作るか」を定義するのに対し、本資料は「どう売るか・どう資金を調達するか・どう認知を作るか」を定義する。

## 1. 金融方針

### 基本方針：機動的な設備融資の活用

```
目安：
  平時の借入残高は手元現金の30%程度を目安とする（硬直的な上限ではない）
  借入目的は「設備・R&D投資」が基本（運転資金への借入は原則なし）
  返済期間は最長5年

  主人公は未来を知る人間であり、確信に基づく局面では目安を超えた
  レバレッジも合理的な経営判断である。特に軍需拡大が確実な昭和6年以降、
  および日中戦争後の軍需産業融資拡大期には、積極的な借入が正当化される。

銀行関係の確立（大正14〜昭和元年）：
  名古屋の有力地方銀行（東海銀行・名古屋銀行系）との正式な当座取引
  コミットメントライン的な枠を大正14〜15年頃に設定
  借入自体は使わなくても「使える関係を持つ」ことが主目的
  → 昭和金融恐慌（昭和2年）の預金リスク分散にも効果

実際の借入使用例：
  昭和6年：DR-980購入等の大型投資の一部を銀行設備融資として借入
  昭和10年：追加出資などを銀行設備融資で借入
  → これらで同額の現金が研究費・人材投資に回せた
```

### 時期別の借入活用判断

| 時期 | 方針 | 理由 |
|:---|:---:|:---|
| 明治末〜大正13年 | 無借入 | 事業規模が小さく設備投資額も小さい。自己資本で十分 |
| 大正14〜昭和元年 | 銀行関係確立（借入はまだなし） | 株式会社化に合わせた信用基盤の整備 |
| 昭和2〜5年 | 必要に応じて小規模借入可 | 昭和金融恐慌後の景気収縮期。設備投資を前倒しする局面に活用 |
| 昭和6〜11年 | 積極的設備融資の活用 | 軍需拡大局面。陸軍・海軍への納入実績は融資優遇の根拠になる |
| 昭和12年〜 | 融資枠の拡大 | 日中戦争後は「軍需産業への融資」として銀行側も積極的 |

## 2. 宣伝・認知形成方針

### 基本設計：「何を見せ、何を見せないか」——公開技術と昭四号使用品の区分

製品はすべて「公開技術」と「昭四号使用品（機密）」に二分される。判断基準は「昭四号が使われているか否か」の一点のみ。詳細な区分と機密クリアランスの階層はUser_Narrative_Constraints.mdの秘匿戦略セクションを参照。

公開技術（制限なし）：コンプレグ、フェノール/フラン麻FRP、キャンバスベークライト、フラン樹脂製品など。物性データ・採用実績の公開はアメリカに対する秘匿に影響しない。他社への技術移転も可能。

昭四号使用品（機密）：昭四号接着材・封止材・パテ・シーラント、ハニカムサンドイッチパネル、GFRP製品全般、CFRP製品。完成品として軍の機密物資調達ルートで流通。「昭四号」は1929年の秘密特許出願時に軍と共同で定めた機密名であり、化学名（エポキシ）は軍内文書にも一切使用しない。

**対アメリカ情報漏洩フィルター**：出品物や掲載内容を検討する際は、「アメリカの情報収集者（駐在武官・技術偵察員）が見た場合に何がわかるか」というフィルターを通す。公開技術製品の物性データ・採用実績は自由に公開してよい。昭四号使用品の存在が推測される内容は排除する。

---

### 柱①：博覧会・展示会への出品（昭和5〜8年に集中）

**最適タイミング**：コンプレグ独占期の末尾（昭和5〜8年）。この窓でしか「元祖」としてのブランドを確立できない。昭和9年以降は競合が追随し始め、博覧会出品の差別化効果が薄れる。

| 展示会 | 時期 | 目的 |
|:---|:---:|:---|
| 名古屋開府300年記念博覧会 | 昭和5年 | 地元での認知形成・農業機械・船舶用途への横展開 |
| 鉄道省系技術展示会 | 昭和6〜7年 | 全国の鉄道管理局担当者への直接訴求 |
| 商工省系工業品評会 | 昭和7〜8年 | 「国産工業素材」としての権威付け |

**出品物と説明の設計**：

```
出品物：
  ①「鉄道省採用・コンプレグ絶縁継目材」
    説明書き：「鐵道省採用。従来品の3〜4倍の耐久性（18ヶ月交換不要の実績）」
    断面カット見本：樹脂が中心まで均一に入っていることを視覚で示す
    
  ②「陸軍航空工廠採用・コンプレグ製プロペラ素材」
    説明書き：「陸軍航空工廠採用。雨中飛行後もバランスが変わらない」
    ※採用事実のみ提示。傾斜密度技術の詳細は一切触れない

見せないもの：
  製造工程の詳細（含浸プロファイル・樹脂配合）
  昭四号系接着材の存在
  プロペラの「傾斜密度」という概念
  （「特殊な処理を施している」という説明で処理）
```

**想定される新規市場開拓効果**：農業機械部品（脱穀機・製粉機の歯車）、船舶・港湾設備、建築型枠材、精密機器の台座・筐体。推算では、恐慌期においても事業を支える一定の新規売上基盤の形成に寄与する。

### 柱②：業界誌への技術論文（昭和8〜10年から）

**対象媒体**：日本電気学会誌、航空技術誌、工業材料、工業化学雑誌

**著者設定**：架空の技術者名義。主人公の名前は出さない。「自社の宣伝」ではなく「技術者による独立した研究報告」として業界内の信頼を得る。

**掲載内容のルール**：

```
掲載可能なもの：
  コンプレグの物性データ（公知の内容のみ）
  絶縁板の高温耐性データ
  鉄道継目材の耐久試験結果（18ヶ月実績）
  航空工廠でのプロペラ採用後の「整備頻度低下」の統計的報告

掲載不可のもの：
  製造プロセスの任意の詳細
  エポキシ・フラン樹脂の存在を示唆する記述
  プロペラの傾斜密度設計の詳細
```

**効果**：三菱・石川島との交渉において「業界で検証済みの数字を持っている」という立場になれる。交渉開始の半年〜1年前倒しが見込まれる。

---

### 柱③：軍技術将校との非公式接点（昭和7〜8年から）

**形式**：陸軍航空技術研究所（立川）の定期技術報告会への「整備部品サプライヤー」としての招待参加。年1〜2回程度。

**目的**：エポキシパテとコンプレグプロペラの「現場での声（整備士のフィードバック）」がサードパーティ評価として軍技術者層に広まる経路を作る。

**姿勢**：主人公側から積極的に売り込む形は取らず、引き合いに応える形を基本とする。ただし、整備現場の好評や技術データが軍技術者の強い関心を引き、向こうから詳細を求めてくることは自然な展開であり、それに応じることは「売り込み」ではない。1930年代の日本軍、特に航空関係は新技術に対して貪欲であり、優れた素材の評判が技術報告会で共有されれば、技術将校が直接接触してくるのが実態に近い。

---

### 柱④：海軍航空本部との接点構築（昭和6〜7年から）

**形式**：陸軍への素材供給と並行して、海軍航空本部・横須賀航空隊にもプロペラブランクとエポキシパテのサンプルを提出。「海軍機のプロペラにも同じ品質のものを」という直接的な提案。

**水上機への展開**：昭和8年以降、DR記録フロート装着版の水上離着水実証データを海軍に共有。コンプレグフロートの「海水に浸かっても重量が変わらない」特性を軸に、長距離水上哨戒用途への提案を行う。詳細はSeaplane_Strategy.md参照。

**目的**：陸軍偏重の顧客基盤を是正し、海軍という巨大な市場（水上機1,000機超の稼働体制）への参入を果たす。

## 3. 出品物・公開物の一覧

### 絶対に出品・公開してよいもの
1. 鉄道省採用実績付き絶縁継目材（「18ヶ月交換不要」という実績を明示）
2. 陸軍航空工廠採用実績付きプロペラ素材（採用事実のみ・製法詳細は不可）
3. 公開・初練（練習機）の公開飛行・航空展出品（機密なし）

### 絶対に出品しないもの
昭四号使用品全般（昭四号パテ・封止材・シーラント含む）、ハニカムサンドイッチ構造品、GFRP製品。機密度「中」以上の機体（四号・双汎以降）。

## 4. 価格設定の原則

技術的優位性が存在する独占期において、適正なプレミアム価格を維持することは「強欲」ではなく「技術開発の資金調達」として正当化される。各事業の単価・数量・売上の詳細はRevenue_Model.mdを参照。

```
シャトル：競合比20〜30%高（交換頻度低減という顧客メリットで正当化）
コンプレグプロペラ：競合比30〜40%高（梅雨・台風時稼働率維持で正当化）
コンプレグ継目材：競合比2〜3倍（18ヶ月耐久 vs 3〜6ヶ月で正当化）
耐蝕ライニング：標準単価300〜500円（施工一括請負。継続契約セット提案）
エポキシ系製品（昭四号）：技術障壁による交渉力を想定。利益率25〜40%は価格認可・原価査定を照合するまでWORKING
プロペラ：技術障壁＋交換需要で安定。利益率20〜35%
完成練習機：P5財務基準の単価 [45,000円]{{ECN:PRICE_TRAINER_P5}}。利益率8〜12%（WORKING）（機体製造は利益率が低い）
```

## 5. 継続的な関係構築の原則

主人公企業の強みは「製品を売った後も顧客との関係が続く」ことにある。

- **耐蝕ライニング**：初回施工時に「定期点検契約＋再施工優先権」をセット提案
- **コンプレグ絶縁材**：保守部品の定期供給契約
- **重電向け絶縁板**：芝浦・日立との「新機種開発への素材相談窓口」的な関係
- **昭四号系消耗品**：接着剤キット・シーラント缶は使い切りの消耗品であり、一度採用されれば継続的に受注が発生する

「1回の取引を長期関係に変える」ことが、恐慌期の収益安定と平時の設計発言権の両方をもたらす。

## 7. コンポーネント販売戦略（昭和10年以降）

航空部門の大きな収益柱。完成機の生産数には設備上の天井があるが、コンポーネントは他社の量産ラインに乗ることで自社生産能力以上の市場にアクセスできる。詳細はAviation_Fleet_List.mdの「コンポーネント販売事業」セクション参照。

**自社で完成品を作る場合**：他社では作れない（技術的に主人公企業しか製造能力がない）、または設計段階から素材特性を織り込む必要がある場合。プロペラ（特にGFRP/CFRPブレード）、フロート、航空機体（練習機・連絡機・他社エンジン搭載の汎用機）、装甲パネル。完成機製造は利益率が低くとも、素材・コンポーネント供給の信頼性を担保し、技術の実証場として機能する。

**素材・コンポーネント供給が主となる場合**：完成品の製造に必要な設備投資が膨大、または他社が既に量産体制を持っている場合。戦闘機・爆撃機の機体（三菱・中島）、大型飛行艇（川西）、戦車車体。ただしこれは現時点の設備制約に基づく経営判断であり、恒久的な方針ではない。

**国内メーカーへの供給形態**：昭四号系製品は「二液混合型特殊接着材キット」として缶入りで完成品供給。合成経路・硬化剤配合は非公開。軍事機密指定により成分分析を法的に抑制。使い方の教育（混合比・養生条件）は主人公企業から技術指導要員を派遣して実施。

**公開技術の他社展開**：フェノール/フランベースのFRP（麻布・綿布との組み合わせ）は公開技術であり、三菱・中島等への製造技術の移転が可能。省アルミ機体構造として日本全体の航空機生産能力向上に寄与する。昭四号を使わないサンドイッチ構造（バルサ＋合板＋カゼイン/ユリア接着）も同様に公開技術として展開できる。
