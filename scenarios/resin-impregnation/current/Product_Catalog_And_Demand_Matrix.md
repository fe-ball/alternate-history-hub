# 商品カタログ＋需要マトリクス

本資料は、主人公企業が第1期（1910年代）から第6期（1942年頃）にかけて扱うすべての商品を、発注主導性・取引形態・素材・用途領域・時期の多軸で体系化した鳥瞰図である。各資料に分散していた商品情報をひとつのカタログに再編し、シナリオシミュレーション実行時に「どの商品が、誰の主導で、どの形態で、どの時期から流れるか」を一覧で参照できるようにする。

---

## 1. 本資料の性質と使い方

### 1.1 発注主導性スペクトルの定義

同じ素材から生まれる商品でも、「誰がその用途を着想するか」は商品ごとに異なる。本カタログは以下の5区分で発注主導性を示す。

- **軍主導（自明置換）**：素材の物性と実績を見れば、軍側が自力で用途を着想できる。技術的な先進性は不要であり、既存用途の素材置換として発注が来る。例：運搬用橋梁、砲車車輪、弾薬箱、工廠加工用の生材ブランク。
- **相談型**：主人公側が可能性を示し、軍が具体的用途を提案する、あるいはその逆。両者の技術・運用知識がかみ合って形になる。例：コンプレグプロペラ、水上機フロート、落下増槽。
- **主人公主導（先進提案）**：軍が単独では着想できない技術を主人公が提案する。未来知識か、複数領域の交差点にいるポジションからしか生まれない発想。例：GFRP翼パネル、GFRPレドーム、昭四号接着による複合装甲。
- **交差点発想型**：主人公企業が複数の軍部門に同時に部品を供給している立場から生まれる発想。単一部門の視点では成立しない。例：電波感応噴進弾（電探部門×噴進弾部門の交差点）、導電性繊維散布兵器（炭素素材の副産物×敵電気系統の脆弱性）。
- **シム裁量**：上記いずれでもよく、シナリオシミュレーション実行時の状況に応じて実行者が決めてよい。

発注主導性は「誰が最初に着想したか」の区分であり、「採用の確度」を示すものではない。軍主導で引き合いが来た商品でも性能・コスト・予算配分により採用が遅れることはあり、主人公主導の提案でも軍側の強い関心で急速に展開することはある。採用の速度感については `Military_Applications.md §12`「軍側の期待される反応温度」を参照する。

### 1.2 取引形態の進化動線

同じ素材でも、主人公企業との関係が進むにつれて取引形態が進化する。生材購入で始まった顧客が、後にコンポーネント発注、さらにはドクトリン相談へと関係を深める動線が、本カタログの第二の軸である。

- **生材**：板・ブロック・織物・液缶など、加工前の素材。受領側が自前で切削・成形する。工廠・他社工場が主な顧客。
- **キット**：缶入りの二液接着剤、シーラント缶、ポッティング材などの消耗品。施工説明書と技術指導員の派遣がセットになる。主に昭四号系で使われる形態。
- **コンポーネント**：主人公企業が最終形状まで加工した部品。プロペラ・フロート・翼パネル・レドーム等。受領側はボルト止めで組み込む。
- **完成品**：機体・装置として完成した形態。練習機・連絡機・飛行艇・装甲パネル。
- **ライニング施工**：施工員を派遣しての一括請負。耐蝕ライニングが典型。
- **原料供給**：合弁や他社向けに出荷する化学原料。フルフラル、ブタジエン原料、アセトン・ブタノール、リグノスルホン酸塩等。

取引形態の進化動線の典型例：工廠が麻FRP板材を生材として購入（生材）→現場補修キットを定期発注（キット）→プリカット済み翼パネルの大口発注（コンポーネント）→省アルミ機体全体の受注（完成品）。この動線はコンプレグ・麻FRP・GFRPの各素材で繰り返し現れる。

### 1.3 「シム現場での裁量範囲」の定義

各商品は、シナリオシミュレーション実行時にどこまで実行者の裁量で決めてよいかという性質を持つ。以下の4段階で示す。

- **主人公提案必須**：未来知識に基づく先進提案であり、主人公が直接関与しないと着想されない。シム実行者はこの提案動線を省略できない。
- **社内提案として自然**：主人公企業の技術者が自発的に提案できる範囲。主人公の明示的指示は不要で、社内研究の延長として生まれる。シム実行者は提案者を主人公以外の社内人物に設定してよい。
- **軍・他社からの引き合い**：製品の性能データや実績を見た軍・他社が自発的に要求する。シム実行者は引き合い元の部署・人物を状況に応じて設定する。
- **シム実行者裁量**：上記いずれでもよく、状況に応じて決める。

### 1.4 素材バリエーションの併記方針

実際の製品は単一素材で構成されるとは限らない。複合装甲はセラミック＋接着剤＋裏打ち層の三層、ハニカムサンドイッチはコア＋面材＋ノード接着剤の組合せ、GFRP翼パネルはマトリックス樹脂＋強化繊維＋サンドイッチコアの複合体である。金属部品との組み合わせ（コンプレグブレード＋金属スリーブのプロペラ、昭四号接着によるアルミ板ジョイント）も多い。

本カタログでは各商品行の「素材バリエーション」列に、主素材だけでなく副素材・金属部品・接着剤系も併記する。これにより、同じ「プロペラ」でも「コンプレグ固定ピッチ・金属ハブ」「コンプレグ＋GFRPスキン中空」「GFRP/CFRPブレード＋金属ハブ・可変ピッチ（萱場協業）」のように、構成が進化する軌跡が一覧できる。

### 1.5 数値の出典とECNコード参照

本カタログの各商品行の「単価帯」「年間規模」列は、`Revenue_Model.md` および `Master_Parameters.md` の該当コード（`ECN:PRICE_〜` / `ECN:REV_〜`）を参照する形で記述する。数値そのものは単一のソース（経済パラメータ群）で管理され、カタログはその索引として機能する。

数値の中央値化方針は `User_Narrative_Constraints.md` の該当節に従う。シミュレーション実行時は中立ケースを標準とし、悲観・楽観への調整にはシナリオ固有の具体的根拠を要する。`GFRP需要シミュレーション草案.md` の「キャップは主人公企業の生産能力ベースで設定しており、需要側に人為的な上限を設けない」方針も同様に遵守する。

### 1.6 機密度の記法

各商品には機密度を併記する。判断基準は「昭四号が使われているか否か」の一点であり、`User_Narrative_Constraints.md` の秘匿戦略節で定義される4階層と連動する。

- **公開**：他社への技術移転可。博覧会・業界誌で物性データ・採用実績を公開してよい。
- **機密（昭四号使用品）**：完成品またはクリアランス管理下のキットとして供給。化学名は使用せず「昭四号」で統一。
- **最高機密**：CFRP、および構造材としての炭素繊維の製造プロセス。秘密特許で保護し、外部には一切公開しない。

## 2. 素材体系の一覧

主人公企業が保有する全素材を系統別に整理する。各素材の技術詳細は参照先のファイルに従う。

### 2.1 木材加工系

- **キルンドライ材**（公開）：第1期からの基盤。科学的含水率管理による高品質銘木材。参照：`02_基幹技術データ集.md §1`。
- **耐水合板**（公開）：カゼイン接着（1913〜）・豚血アルブミン調合。1917年以降はフェノール樹脂接着に置換。参照：`02_基幹技術データ集.md §2`。
- **コンプレグ（フェノール含浸強化木）**（公開）：初期の積層型（1917〜）と、自社合成レゾール＋真空加圧による真のコンプレグ（1926〜）の二段階。参照：`02_基幹技術データ集.md §3,§4`、`Compreg_Markets_And_Lifecycle.md`。
  - **傾斜密度コンプレグ**（公開だが概念は営業秘密）：含水率プロファイル操作による密度傾斜。第2期（1920年代前半）に粗い実装、第3期（1926〜）に精密量産化。プロペラブランク向け。
- **フルフリル化木材**（公開・ただし分析困難）：フルフリルアルコールの含浸＋酸触媒硬化。形状保持型で、コンプレグ（圧縮型）とは棲み分ける。参照：`Furan_Resin_And_Furfurylated_Wood.md §3`。

### 2.2 樹脂系

- **フェノール樹脂（レゾール／ノボラック）**（公開）：1917〜26年は三共購入、1926年以降は自社合成。超低粘度レゾールはコンプレグ専用で他社に供給しない。参照：`Sankyo_Amicable_Relationship.md`。
- **フラン樹脂（ポリフルフリルアルコール）**（公開）：フルフラルの下流プロセスは秘匿対象だが、樹脂の存在と基本物性は公知。参照：`Furan_Resin_And_Furfurylated_Wood.md`。
- **フェノール-フルフラル共縮合樹脂**（公開）：ホルマリン依存の軽減、耐酸性強化を両立。1920年代後半から量産。
- **尿素樹脂**（公開）：民生品（ボタン・食器・接着剤）向け。「幅広く樹脂化学を手がける普通の会社」という外形の維持にも機能する。
- **昭四号（エポキシ樹脂）**（機密）：1929年秘密特許出願。化学名はエポキシ、軍内文書では昭四号。形態別に派生（接着材、封止材、パテ、シーラント）。参照：`Epoxy_Strategy.md`、`02_基幹技術データ集.md §6,§7`。
- **シリコーン樹脂**（公開）：耐熱研究の副産物。耐熱塗料・潤滑油・電気絶縁ワニスとして展開。参照：`Interface_Solution.md §2,§5`。

### 2.3 繊維強化系（FRP）

- **麻FRP（フェノール／フラン系）**（公開）：1929年試作、1937年以降量産。公知の樹脂×公知の繊維。省アルミ機体の外皮・落下増槽などに使われる。
- **麻FRP（昭四号版）**（機密）：同じ麻繊維でもマトリックスが昭四号の場合は機密扱い。気密性・耐燃料性に優れる。
- **GFRP（昭四号＋ガラス繊維）**（機密）：1935〜36年試作、シランカップリング完成（1938〜39年）で完全版。プロペラ、フロート、レドーム、翼パネル、噴進弾モーターケース、飛行艇艇体に展開。参照：`GFRP_Development.md`、`Interface_Solution.md`、`GFRP_Mass_Production_Feasibility_Analysis.md`。
- **CFRP-レーヨン系（昭四号＋レーヨンCF）**（最高機密）：張力下炭素化、1940〜41年完成。特務機・最重要部位限定。参照：`CFRP_Complete.md`、`Carbon_Material_Hierarchy.md §2`。
- **CFRP-ピッチ系（昭四号＋ピッチCF）**（機密）：量産機翼スパー向け。GFRPでは解決できなかった比弾性率問題を解決。参照：`Carbon_Material_Hierarchy.md §3`。

### 2.4 炭素素材系

- **竹チョップドCF**（機密・ただし製造プロセスのみ）：1935年量産開始。コンパウンド成形、炭素電極混合に使用。参照：`Carbon_Material_Hierarchy.md §4`。
- **ピッチ系長繊維CF**（機密）：メソフェーズピッチ→紡糸→炭素化。量産機の剛性部材。
- **レーヨン系長繊維CF**（最高機密）：特務機プロペラ・翼桁向け。
- **炭素電極**（公開）：アルミ電解・電気炉製鋼用。1936年以降本格製造。戦略物資指定に準じる扱い。
- **活性炭**（公開）：防毒マスクフィルター、水道精製、溶剤回収。軍需・民需両用。
- **チョップドCFコンパウンド**（機密・ただし製品自体は公開）：竹チョップドCF＋フェノール／昭四号樹脂の金型成形品。計器盤、ブラケット、小型歯車。

### 2.5 ゴム系

- **合成ゴム（ブタジエン系・汎用）**（公開）：理研系合弁経由で展開。主人公企業は原料供給と資本参加のポジション。参照：`Synthetic_Rubber_Route.md`、`Furan_Resin_And_Furfurylated_Wood.md §5`。
- **防振ゴム（特殊配合）**（機密に準じる）：航空機・戦車・艦船のエンジンマウント用。自社内製。
- **耐油ゴム（特殊配合）**（機密に準じる）：油圧シール・耐油ホース。萱場との協業で航空機油圧系統に供給。
- **セルフシーリングゴムシート**（機密）：燃料タンク外面貼付用。燃料との接触で膨潤して貫通孔を塞ぐ。昭四号接着とセットで三菱・中島に供給。参照：`Cooperation_Partners.md §5`。

### 2.6 セラミック系（調達・接着加工が主）

- **高温焼成磁器タイル**（公開）：瀬戸・常滑の窯元から調達、主人公企業で昭四号接着。複合装甲グレードⅡ用（磁器8mm）、グレードⅢ用（磁器15mm）。
- **高アルミナ磁器**（公開）：NGKとの共同開発（1939〜）。複合装甲グレードⅢ上位向け。
- **SiC（炭化ケイ素）**（公開だが製造プロセスは独自）：自社電気炉（炭素電極事業の転用）で焼結。複合装甲グレードⅣ、噴進弾ノズル用。1939〜40年に開発着手。

### 2.7 接着・封止・コーティング系

- **昭四号接着材（二液缶）**（機密）：三菱・中島等の工場にキット形態で供給。
- **昭四号封止材**（機密）：通信機・電探の真空管ポッティング。
- **昭四号パテ（空力平滑化）**（機密）：1931〜32年から航空工廠向け。成分不問で「特殊充填材」として展開。
- **昭四号シーラント（燃料タンク用）**（機密）：1934〜35年から。1938〜40年に陸海軍標準採用。
- **フラン樹脂ライニング材**（公開）：化学プラント内張り。施工込み一括請負で展開。参照：`Corrosion_Resistant_Business.md`。
- **シリコーン塗料・潤滑油**（公開）：耐熱研究の副産物。重電・軍需に供給。
- **アルキド塗料**（公開）：無水フタル酸・グリセリンを原料とする塗料。エポキシ硬化剤の外形的理由（原料備蓄の口実）としても機能。
- **電気絶縁ワニス**（公開）：重電向けマグネットワイヤー用。1933年〜、芝浦・日立・三菱電機との協業。
- **セルロースアセテートドープ**（公開）：廃材乾留酢酸の下流。航空機布張り用。第1期から第6期まで継続商材。

### 2.8 透明素材系

- **PMMA（アクリル板）**（公開）：1934年事業化。計器窓、照明カバー、航空機風防、義歯。ABE発酵アセトンが原料。
- **PVB（合わせガラス中間膜）**（公開）：1935〜36年研究開始。艦艇舷窓の飛散防止、合わせガラス用。少量高付加価値。

### 2.9 サンドイッチ・複合構造系

- **フェノール紙ハニカム＋麻FRP外皮**（公開）：公知の素材のみで構成される省アルミサンドイッチ。他社への技術移転が可能。省アルミ双発汎用機（公開版）の基本構造。
- **昭四号ハニカム＋FRP外皮**（機密）：ノード接着に昭四号を使用するため機密扱い。省アルミ双発汎用機（昭四号版）、夜戦、哨戒機、飛行艇。
- **桐コア＋合板／FRP外皮**（公開）：バルサ相当の軽量コアを国産桐で代替。カゼイン／ユリア接着。省アルミ構造の一部として三菱・中島に技術移転可能。
- **複合装甲**（昭四号接着のため機密、グレードによる）：グレードⅠ（既存鋼板裏打ちGFRP）／グレードⅡ（磁器タイル＋GFRP）／グレードⅢ（磁器＋鋼板＋GFRP）／グレードⅣ（SiC＋鋼板＋GFRP）。参照：`Composite_Armor.md §4`。

### 2.10 化学原料系（他社・合弁向け供給）

- **フルフラル**（公開）：籾殻・竹廃液・王子廃液の三重化体制で量産。合成ゴム原料として理研系合弁に出荷、ディーゼル添加剤（フルフリルエーテル）原料、耐蝕ライニング原料、共縮合樹脂原料として社内消費も並行。参照：`Oji_Paper_Collaboration.md`、`Taiwan_Bagasse_Furfural.md`。
- **ブタジエン原料**（公開）：THF経路（フルフラル由来）とブタノール経路（ABE発酵由来）の二本柱。理研系合弁に供給。
- **アセトン**（公開）：ABE発酵副産物。社内（PMMA原料、BPA合成）と外部両方に供給。
- **ブタノール**（公開）：ABE発酵主産物。合成ゴム原料、100オクタン航空燃料原料として打診。
- **リグノスルホン酸塩**（公開）：王子合弁の副産物。コンクリート分散剤・なめし剤として外販。
- **酢酸・メタノール**（公開）：廃材乾留、王子廃液、バガスから回収。社内消費が中心（ドープ原料、バイオディーゼル）。

## 3. 民需カタログ

民需は第1期からの事業基盤であり、第3期末までは売上の大部分を占める。戦時経済下（第5期後半以降）でも、民需由来の既存取引関係が軍需への信頼基盤として機能し続ける。

## 5. 海軍カタログ

海軍向け商品は、陸軍より遅れて本格化する。陸軍航空工廠との関係が第3期（1928〜）から確立しているのに対し、海軍航空本部・横須賀航空隊との関係構築は第3期末（1931〜32年）の昭四号パテ・プロペラブランクのサンプル提出から始まる。水上機・飛行艇への展開、電探関連部品、噴進弾と発展するにつれ海軍は最大級の顧客となり、第6期（1942年頃）には陸軍と並ぶ収益柱となる。

海軍特有の訴求点は、陸軍の「アルミ節約・整備頻度低下」に加えて、**塩害耐性・機雷浮遊物への耐衝撃性・電波透過性**の三点である。塩害は金属フロートの慢性問題、電波透過性はGFRPレドームと噴進弾の二部門が同時に要求する特性であり、これが主人公企業の「交差点にいるポジション」を形成する（`Radar_Proximity_Rocket.md §1`）。

噴進弾分野は、通常のGFRPモーターケース供給（素材改良提案）から始まり、主人公企業が電探部門にも部品を供給している「交差点にいる唯一の民間企業」という立場から電波感応噴進弾の着想に至る。1939年後半〜1940年前半の自社工場内での概念実証（GFRP管耐圧・エポキシ封止真空管の耐G試験・ノーズコーン電波透過試験）を経て、噴進弾担当者への提案時には「電波を通す弾体です」という素材特性の提示にとどめ、兵器化の発想は海軍技研電波部門側から自発的に出てくる動線が取られる（`Radar_Proximity_Rocket.md §2`）。

電感噴進弾は三者協業（海軍技研電波部門＋芝浦＋主人公企業）で試作・実用化される。主人公企業は弾体構造・封止材・レドーム・基板という広範な部品を供給する一方、火薬・推進薬は海軍火薬廠、回路設計は芝浦、最終組立は海軍工廠という分業が成立する。

提案先は海軍技研電波部門。レドーム・高周波基板の納品打ち合わせの場で「自社工場での導電性粉塵による電気障害」を技術報告として持ち出す形式をとる。電波・電気の専門家にとって、目の前で碍子がアーク放電を起こす実演は即座に兵器化の可能性を確信させ、「これは使える」という判断が実演の場で下される（`Conductive_Fiber_Dispersal.md §9`）。

本兵器の戦略的性質は「人を殺すのではなく機械を止める」ソフトキルであり、直接的な売上は小さい（素材コスト極小）が、**敵の電力・レーダー・通信系統を非破壊で麻痺させる**という他に代替のない効果が戦略的価値を生む。開戦劈頭からの使用を想定した備蓄が開戦前に完成する。

## 6. 軍主導ドクトリン展開カタログ

本節は商品そのものではなく、**主人公企業の素材・製品の性能データを見た軍側が自発的に着想するドクトリン・運用法**を記録する。これは `User_Narrative_Constraints.md` §シミュレーション実行時のデフォルト姿勢の 5（軍・他社・社会の反応）および観測済みアンチパターン集のパターン5（軍の創造的展開の欠落）に対応する積極的記述である。

ドクトリン展開は商品の発注を駆動する要因として機能するが、シナリオシミュレーションにおいては「構想されて即座に採用される」とは限らない。構想段階で終わる、派閥抗争で潰れる、予算がつかない、別のドクトリンに吸収される——こうした展開も史実的に自然であり、本節の記述はドクトリンが**提起される**ことを保証するものであって、**採用される**ことを保証するものではない。

### 6.1 水上機前進基地ドクトリン

**ドクトリンの内容**：コンプレグ／GFRPフロートの塩害耐性と軽量性能、ディーゼル哨戒機（四号・D哨）の航続距離、GFRP飛行艇（四号・飛艇）のレドーム一体性能を前提に、滑走路を持たない太平洋島嶼群を水上機基地として展開する構想。「島嶼点在環境での分散配置による機動運用」。

**着想の契機と主導者**：
- 連絡・偵察機フロート装着版（メタ呼称「DR連絡・水」）の水上離着水実証（1935〜36年）
- コンプレグフロート海軍制式採用提案（1936年）
- GFRPフロート供給開始（1938〜39年）
これらを受けた海軍航空本部・横須賀航空隊の水上機運用部門が、「海水で腐らないフロート」「燃料1/12」「艇体レドーム一体」という技術的前提から、**島嶼分散配置のドクトリン**を発想する動線が自然。

**駆動される商品**：
- コンプレグフロート・GFRPフロート（§5.1）
- 港湾桟橋踏板・係船柱カバー・水上機基地スロープ板（§5.5）
- ディーゼル哨戒機・GFRP飛行艇（§5.1）
- 水上機係留ブイ・水上機基地設営資材（§5.5）

**シム実行者裁量**：本ドクトリンは主人公が直接提案せず、海軍側が自発的に発想する経路のほうが自然。ただしシナリオの展開により、提案経路・採用判断・採用後の実効性は実行者が決める。

### 6.2 機甲歩兵運用

**ドクトリンの内容**：複合装甲（グレードⅡ〜Ⅳ）の軽量性（RHA比1/3〜1/4）を前提に、従来は装甲車の運搬が必要だった重装備歩兵に、個人で担いで展開できる防護装備を配備する構想。野戦指揮所パネル（7.6 kg/50cm角・1人運搬可能）、胸部防弾板（2.4 kg）、鉄帽インサート（+0.3 kg）を組み合わせた「機甲歩兵」の構想。

**着想の契機と主導者**：
- 複合装甲グレードⅡの射撃試験（1935〜36年）での「RHA比1/3で同等防御」データ
- 日華事変での戦闘機パイロット背面装甲の実戦投入（1937年〜）
陸軍歩兵科・陸軍技術本部が、「軽量装甲が個人単位まで降りてきた」という認識から機甲歩兵ドクトリンを着想する動線が自然。

**駆動される商品**：
- 胸部防弾板・鉄帽インサート・野戦指揮所用防護パネル（§4.3, §4.5）
- 複合装甲グレードⅡ（§4.5）
- 歩兵装備樹脂化との組み合わせ（§4.6）

### 6.3 移動式電探

**ドクトリンの内容**：GFRPレドームの軽量性と電波透過性を前提に、従来は固定設置だった電探を車載化・船載化する構想。「電探の稼働率と配備密度を、固定設置では不可能な水準へ引き上げる」。

**着想の契機と主導者**：
- GFRPレドーム（航空機搭載用小型）の供給開始（1939年〜）
- 艦載用大型レドームの供給開始（1940年〜）
海軍技研電波部門・芝浦の電探開発チームが、「レドームが小型化可能」「アンテナ保護で塩害劣化が防げる」という前提から、艦載・車載電探の展開を発想する動線が自然。

**駆動される商品**：
- GFRPレドーム・GFRP製電探アンテナ支持構造（§5.3）
- 高周波エポキシ-ガラス積層板・マグネトロン封止材（§5.3）
- 双発夜間戦闘機（四号・夜戦）のような機体全体がレドームとなる完成品（§5.1）

### 6.4 艦隊防空思想の転換

**ドクトリンの内容**：電感噴進弾の近接起爆能力（「10〜30発で1機撃墜」）を前提に、高角砲・機銃による弾幕防空から、近接信管噴進弾による命中率重視防空へ思想を転換する構想。機動部隊直衛艦・要地防空・本土防空で順次展開。

**着想の契機と主導者**：
- GFRP弾体の電波透過性データ提示（1940年、海軍技研噴進弾担当者への素材改良提案の中で）
- 自社工場内での概念実証実験（1939年後半、GFRP管耐圧・封止真空管の耐G・ノーズコーン電波透過）
海軍技研電波部門が、「電波を通す弾体」という素材特性から**近接信管への応用**を自発的に発想し、三者協業（海軍技研＋芝浦＋主人公企業）を立ち上げる動線（`Radar_Proximity_Rocket.md §2`）。

**駆動される商品**：
- 電感噴進弾構造部品一式（§5.4）
- 噴進弾GFRPモーターケース・SiCノズル・GFRP安定翼（§5.4）
- GFRPレドーム・高周波基板（§5.3。母艦レーダー側）

**配備順序**：機動部隊直衛艦（1942〜）→主要前進基地の要地防空（1942〜）→本土要地防空（1943〜）→迎撃戦闘機搭載（1943〜、方式A完成後）（`Radar_Proximity_Rocket.md §10`）。

### 6.5 ソフトキル先行攻撃ドクトリン

**ドクトリンの内容**：導電性繊維散布兵器の「目を潰すが足は止めない」性質を前提に、通常兵器による本格攻撃の前段として敵の電探・通信・電力を麻痺させる「盲目化の窓」を作り、後続攻撃の損耗率を大幅に下げる構想。

**着想の契機と主導者**：
- 自社工場内での概念実証実験（1937〜38年、高圧碍子の模擬セットへの散布→アーク放電再現）
- 海軍技研電波部門への技術報告（1938〜39年）
海軍技研電波部門・電波研究者が、碍子汚損と沿面放電のメカニズムを即座に理解し、兵器化可能性を自発的に上層部へ提言する動線（`Conductive_Fiber_Dispersal.md §9`）。

**駆動される商品**：
- 一号型（航空投下式）〜五号型（戦略攻撃用）散布弾（§5.6）
- 導電性繊維低グレード品（§5.6）
- ロケット散布弾（三号型）用のGFRP管（噴進弾技術の転用）

**運用局面の例**：
- 攻撃隊先頭の制圧機が三号型ロケットで風上から散布→30秒〜2分で繊維雲が艦上に沈降→本隊が突入（対艦攻撃）
- 第一波で散布弾投下→防空レーダー・通信麻痺→第二波で通常爆弾による物理破壊（飛行場攻撃）

### 6.6 その他のドクトリン展開

上記5つの主要ドクトリン以外にも、主人公企業の素材・製品から軍側が自発的に着想しうる展開として以下がある。いずれも`User_Narrative_Constraints.md`パターン5の積極的記述に対応し、シム実行者の判断で採用・不採用・部分採用を決めてよい。

- **鋼材節約パッケージ**：耐蝕ライニング（航空燃料備蓄タンク）＋複合装甲（RHA代替）＋コンプレグ（構造材・容器代替）を「鋼材を使わない軍需設備構築」として統合提案する陸軍技術本部の構想（`Composite_Armor.md §9`、`Corrosion_Resistant_Business.md §6.1`）。

- **対潜哨戒思想の高度化**：GFRP飛行艇（艇体レドーム一体）＋ディーゼル哨戒機＋GFRP弾体の電感噴進弾の組み合わせにより、太平洋広域の対潜哨戒・攻撃能力を高度化する海軍航空本部の構想。

- **整備工数削減ドクトリン**：コンプレグ・GFRP構造の「腐らない・狂わない・整備頻度が低い」特性から、同じ機数で実効飛行時間を延ばす運用思想。パイロット訓練回転率・前線稼働率の改善を目的とする陸海軍共通の運用改善（`GFRP需要シミュレーション草案.md §6`）。

- **軍工廠による自前GFRP加工の拡大**：ガラス繊維織物と昭四号キットの供給を受けた陸海軍航空工廠が、自前で成形・補修を行う体制の構築。主人公企業の生産能力制約を補完する構想。

- **連続訓練体系の構築**：公開・初練→公開・中練→実戦機という段階的訓練機体の供給安定により、パイロット大量養成を支える陸海軍操縦学校の構想。退役エンジンの再活用（中練の寿系エンジン搭載など）と連動する。

## 7. 事業動線マップ

本節は、主人公企業が顧客・取引形態・商品の各軸でどのように関係を深化させていくかの典型パターンを記録する。これにより、カタログの個別商品行が「どの関係のどの段階で供給されるか」を動線として一覧できる。

### 7.1 生材→キット→コンポーネント→完成品の進化パス

主人公企業と顧客の関係は、取引形態の進化を伴って深まっていく。典型的な進化パスを3例示す。

**パス1：陸軍航空工廠との関係（1928〜1942年）**

```
第3期（1928〜）：コンプレグプロペラブランク（生材）
  ↓ 「工廠で切削加工して自前のプロペラを作る」体制
第3期末（1931〜32）：コンプレグプロペラ完成品の納入開始
  ↓ 工廠加工と並行して、主人公企業の完成品も入る
第3期末（1932〜33）：昭四号パテ供給開始（キット）
  ↓ 「特殊充填材」として成分不問で採用、空力平滑化用途
第4期（1934〜35）：昭四号シーラント・接着剤キットの供給拡大
  ↓ 燃料タンクシーリング・金属構造接着の実機展開
第5期後半（1937〜）：翼外皮パネル（プリカット）大口供給
  ↓ 三菱・中島の量産ラインに乗る形態
第5期後半（1938〜）：省アルミ双発汎用機の技術移転
  ↓ 公開版の他社量産開始、昭四号版は自社独占
第6期（1940〜）：可変ピッチプロペラ協業（萱場＋主人公）
```

この動線の特徴は、**生材で始まった取引が最終的に完成機の技術移転にまで達する**点にある。工廠が「自前で加工したい」というプライドを満たしつつ、徐々にキット・コンポーネント・完成品へと取引形態を進化させる。

**パス2：芝浦（東芝）との関係（1933〜1942年）**

```
第3期末（1933〜）：電気絶縁ワニス（原料供給）
  ↓ マグネットワイヤー用含浸ワニス
第4期（1934〜）：フェノール積層板（生材）
  ↓ 配電盤・絶縁板の継続供給
第5期後半（1938〜）：昭四号-ガラス高周波基板（コンポーネント）
  ↓ マイクロ波損失問題の解決として提案
第5期後半（1939〜）：GFRPレドーム（コンポーネント）
  ↓ 電探アンテナ保護
第5期後半（1939〜）：マグネトロン封止材（キット）
  ↓ 通信機封止の延長
第6期（1940〜41）：電感噴進弾三者協業（回路設計は芝浦、弾体構造と封止材は主人公）
  ↓ 「交差点にいる立場」から生まれる協業の到達点
```

この動線の特徴は、**「既存顧客の新しい困り事を解決する」横展開の連鎖**である。絶縁ワニスという地味な原料供給から始まり、電探・噴進弾という最先端兵器の共同開発にまで至る。

**パス3：三菱・中島との関係（1930年代〜1942年）**

```
第3期末〜第4期：昭四号パテ・接着剤キット（機体塗装平滑化・リベット補助）
  ↓ 既存のジュラルミン機体への補助的採用
第5期前半：翼外皮パネル（GFRP）の一部型式採用
  ↓ 新型機への段階的組込み
第5期後半：セルフシーリング燃料タンク用ゴムシート供給
  ↓ 被弾時の生存性向上
第5期後半：省アルミ双発汎用機（公開版）の技術移転
  ↓ アルミ逼迫期の量産代替
第6期：他社量産ラインへの大口翼パネル供給
  ↓ 主人公企業の生産能力を超える需要への対応
```

この動線の特徴は、**対等な技術パートナーへの進化**である。初期はアクセサリ部品の供給から始まり、最終的に主人公企業が他社機体の中核構造素材を供給する関係に至る。

### 7.2 顧客関係構築→信頼→大型受注の因果パス

取引形態の進化だけでなく、「どう信頼が積み上がって大型受注に至るか」の因果パスも、カタログの各商品が置かれる文脈として重要である。以下に3典型を示す。

**因果パスA：実証→実演→データ提示→採用**

複合装甲、コンプレグフロート、電感噴進弾など、軍側の懐疑を伴う新技術が採用に至るパス。

```
1. 自社工場内での概念実証（自費で実施。成功するまで外部に出さない）
2. 軍関係者を招いた実演（射撃試験・水上離着水・碍子アーク放電再現）
3. 実測データ提示（「RHA比1/3の重量」「燃料1/12」など）
4. 制式採用または三者協業の開始
```

実演の場で懐疑が消えることが決定的であり、以後は仕様の詰めに移行する（`Composite_Armor.md §9`、`Military_Applications.md §12`、`Conductive_Fiber_Dispersal.md §9`）。

**因果パスB：小口納入→現場評価→口コミ→大口引き合い**

コンプレグ弾薬箱、通信機封止材、航空機補修キットなど、現場の慢性的困り事を解決する商品のパス。

```
1. 小ロットでの試験納入（無償または原価供給）
2. 現場担当者の使用→「これは使える」との評価
3. 前線整備隊・現場部隊からの口コミ
4. 軍上層部への制式採用要望
5. 大口契約化
```

満州の過酷な気候で木箱が割れる・通信機が故障するという既知の問題に対して、解決策を持ち込まれれば現場が飛びつき、制度的プロセスを押し上げる動線。

**因果パスC：横展開→関連部門への自然な浸透**

昭四号系消耗品、防振マウント、PMMA計器窓など、当初の用途から隣接分野へ拡大する商品のパス。

```
1. 特定用途での採用（例：航空機用の昭四号シーラント）
2. 性能実績の確立
3. 隣接部門・他軍種での類似需要の発生（例：艦船の燃料タンク、戦車の油圧系）
4. 「あの部門で使われているなら、うちでも」という横展開の引き合い
5. 複数部門横断の標準採用
```

この動線は主人公企業の「素材のハブ」性質を最大限活用する。一つの用途で実績が立てば、同じ素材が複数の軍種・部門・他社に広がり、追跡不能なほど多様な商品カテゴリを生む。

### 7.3 動線の反対方向：技術的陳腐化と収益構造の移行

進化パスと因果パスは右肩上がりだけではない。コンプレグのような技術は、時間とともに競合追随により陳腐化し、収益構造が変化する（`Compreg_Markets_And_Lifecycle.md §5`）。

```
第1フェーズ（独占）：1928〜33年。秘密製法による高利益率。
  ↓
第2フェーズ（追随と競争）：1934〜38年。スケールメリットによるコスト競争へ移行。
  ↓
第3フェーズ（コモディティ化）：1939〜。安定したベース収益源（キャッシュカウ）として維持。
```

陳腐化こそが次世代技術（エポキシ・GFRP・CFRP）への推進力となるという構造があり、カタログの商品群は常に「新素材への移行と旧素材のコモディティ化」の二層で推移する。この二層構造は、主人公企業の年商拡大の中で、構成比率の変化として現れる（`Revenue_Model.md §売上構成比の推移`）。
