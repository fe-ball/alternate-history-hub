# 樹脂含浸シナリオ

1910年代の日本で、歴史・化学等の未来知識を持つ転生者が、木材商家を基盤に木材加工・樹脂化学・複合材料の事業を段階的に構築するシミュレーション。

技術・特許・原料・需要・資金の制約を検討し、日本を有利にして敗戦を避けることを主人公の上位目標とする。小説・仮想戦記のテンプレートで展開を先に決めず、資料に基づくシミュレーションを優先する。
